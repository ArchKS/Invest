# 原始问题

1. 最近一直在想佛教里的无我，他把人的念头、思想、身体、感受、意识比作一辆车的零部件，比如轮胎、方向盘、车身、座椅。轮胎是车吗？其实不是。座椅是车吗？也不是。所以人的念头、思想、身体是我吗？不是。所以并没有一个特定的“我”存在，所有一切都是缘起，是一种结构。我觉得这种论述可能有点问题。虽然轮胎、座椅、方向盘都不能单独成为一辆车，但它们组合起来就可以成为一辆车。局部不是一辆车，但不代表整体不是一辆车。比如，我的身体不是我，但不代表由这所有部分组成的最后的一个整体不是我。

   这类现象在现实中也有。比如我们用人眼去看一个宏观现实中的物体，比如一张桌子，它肯定是连续的。你用手去摸它，一个平整的木板，你是可以从头摸到尾的。但是如果你把它放大、放大再放大，它最后都是一些带空隙的基本粒子组成的，它其实是离散的。但你能说从我们的角度去看这个桌子的时候，它是离散的吗？

   以前有一篇很有名的论文叫《More is Different》，当层级变高的时候，它会继承一些低层级的特征，但是高层级也会演变出一些自身的特性来。

   所以，当我去追问佛教里面的那个“我”，真的没有“我”吗？我还是觉得有个“我”。

2. 佛教认为，在记忆、身体延续的同一性中，存在一个连续性的身心过程，它就是“我”，而不存在一个独立的意识是我吗

3. 我们以游戏人物来举例，比如一个游戏人物初始总有一些默认值，身体的素质属性，人物的性格偏好、专长，当初始的等级为一级的时候，这些都是默认的。随着我们走出这个世界，环境也一点一点影响着我们。我们和这个世界的交互的过程中，逐渐提高自己的能力，这种是缘起。那么我的问题是在这个游戏人物中。它有它初始的值这属于我的一部分吗？在佛教的理解里

4. 我常常感叹这个世界生生灭灭，循环往复，一切都在兴起，而一切又在消逝，感觉人生的幻灭如大梦一场。没有什么是恒定的东西，佛教又说“无我”，那么我们这个世界还有什么可以把握的恒在的东西

5. 虽说事物不必永恒，也能具有真实性，但人总对过去的美好加以怀念，对未来的求而不得抱有遗憾。倘若我们生活的不幸福，却又没有永恒的东西加以慰藉，莫非要沉湎于过去的回忆中才行吗？亦或是对未来的幻想中

6. 我们如何不要求幸福能永远存在下去？要求幸福永远能存在下去是人的本能，倘若去压制这种念头，并不是一种和谐的解决方式

7. 我会想构造一个恒定的我来尝试，即使外界干扰不断，我依旧能够幸福。倘若不能幸福，退而求其次，就是一种宁静祥和地活着。我想要把握这种永恒的、不受外界干扰的内心的精神世界，它会是真实存在的吗

8. 但是我看到佛学有说，通过修行可以达到一种常乐我净的境界

9. 有些人说， 修行可以使自己意识到自己本身就是圆满，无需假借外物，此时外部世界就成了一种体验，你不用从中获得对你自身存在的证明，只需要享受每种体验。但我又疑心，是他们的生活本就无忧且安逸，所以便觉得意识圆满，若是他们处于战乱，妻离子散，朝不保夕，还能做到称自身圆满，外部世界处处是体验吗？

10. 人常有些痛苦，是认知不够造成的。比如投资，若只能看到股价波动带来的账户的波动，就不可避免的患得患失，若能看到背后企业的经营，就会心里有个锚。看待世界的角度不同，心里感受也就不同。我想知道，是否有种角度，可以让人圆满幸福，倘若不能幸福，至少也是平静祥和

11. 释迦摩尼当时出家的时候，想着离苦得乐，最后是如何实现的

12. 想要获得永恒的平静、圆满的状态、没有痛苦的认知，是不是本身也是一种脆弱





# 进一步思考



1. 幸福来自哪里？内 或 外
2. 圆满是幸福吗？
3. 圆满/幸福 是否依托于外在价值？
4. 可靠的精神根基是否真的存在
5. 认知。我们希望通透，以适应一切痛苦，把一切痛苦都解释为认知不足







# 一些结论

1. 部分不是整体 ≠整体不存在

2. 无我（经验的我、整体的我、恒常的我）：整体没有一个独立不变的、不依赖身体、感受、记忆和意识而存在内在主体（恒常的我）

   如果有一个独立的“我”，你可以通过修行去修，以达到平静祥和，但我如果没有，我们修什么？

3. 没有独立于外界的实体，即没有不受外界影响的恒定的精神，即无恒久可保证的幸福，一切皆是无常

4. 在幸福的当下去考虑失去幸福后的场景，本质上是降低当前的幸福以降低未来失去后心理落差的冲击，是不可取的

5. 害怕无常，是害怕世界不按照我们的预期运行，但我们不是世界的中心，其本身就 不安我们的预期运行

6. 当思想不能解决所有问题的时候，我才能看到一个完整的人，而非纯粹意识的人
