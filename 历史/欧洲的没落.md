## 欧洲各国面临的主要问题

### 共同挑战

**经济与通胀压力** 2022年以来，欧洲经历了数十年来最严峻的通胀，主要由俄乌战争导致的能源危机驱动。德国尤为突出——作为欧洲最大经济体，它高度依赖俄罗斯天然气，能源转型的代价极大，制造业竞争力持续下滑。

**移民与社会撕裂** 这是当前欧洲最具爆炸性的政治议题。大量来自中东、非洲、南亚的移民涌入，引发了文化融合难题、社会资源分配矛盾，以及本土居民的身份焦虑。右翼民粹政党借此崛起——法国国民联盟、意大利兄弟党、德国选择党均大幅扩张。

**人口老龄化** 几乎所有欧洲国家都面临出生率低、人口老龄化的结构性困境，养老金、医疗系统压力巨大，而劳动力短缺又形成内在矛盾——既需要移民补充劳动力，又排斥移民带来的文化冲击。

**对美依赖与战略自主** 特朗普的回归让欧洲深刻意识到长期依赖美国安全保障的脆弱性。北约承诺动摇、乌克兰援助的不确定性，迫使欧洲重新讨论自主防御——但各国利益分歧明显。

------

### 英国为何频繁换首相？

2016年至今，英国换了**七位首相**（卡梅伦、梅、约翰逊、特拉斯、苏纳克、斯塔默……），这背后是系统性矛盾，而非个人能力问题。

**根本原因：脱欧撕裂了保守党**

脱欧本质上是一场发生在保守党内部的内战。留欧派和脱欧派长期相互否决，任何首相都很难在党内形成稳定多数。卡梅伦因公投失败辞职，梅因脱欧协议三次被议会否决而辞职，约翰逊因丑闻被党内逼宫，特拉斯则仅执政45天——因激进减税方案引发金融市场崩溃而辞职，创下英国史上最短任期记录。

**英国体制的特点加剧了不稳定**

英国首相的权力来源于议会党团的信任，而非固定任期。一旦失去党内支持，随时可被"逼宫"，不需要等到大选。这与法国总统制或德国的稳定联合政府机制截然不同。

**深层社会矛盾**

- **脱欧的代价**：贸易摩擦增加、外资减少、北爱尔兰边界问题至今未彻底解决，经济损失是客观存在的，但承认这一点在政治上又极为敏感。
- **地区分裂**：苏格兰独立诉求持续存在，苏格兰民族党长期执政，与伦敦中央政府摩擦不断。
- **生活成本危机**：房价畸高（尤其伦敦）、公共服务（NHS医疗系统）严重超负荷，年轻一代对未来普遍悲观。
- **身份认同混乱**：脱欧后的英国究竟是什么？"全球化英国"的愿景与实际处境之间的落差，让国家缺乏清晰叙事。

------

### 各国具体矛盾

| 国家            | 核心矛盾                                                     |
| --------------- | ------------------------------------------------------------ |
| **法国**        | 马克龙的中间道路失去民心，极右与极左两极化；退休制度改革引发大规模罢工；海外领土治理危机 |
| **德国**        | 传统工业模式（汽车、制造业）面临中国竞争与绿色转型双重冲击；联合政府内讧，政治碎片化 |
| **意大利**      | 经济长期低增长、高债务；南北发展严重不均；政府频繁更迭是传统 |
| **波兰/匈牙利** | 与欧盟在法治、司法独立问题上的结构性冲突；民族主义与欧洲一体化的张力 |

------

总体来看，欧洲面临的是**全球化红利消退、内部凝聚力下降、外部安全威胁上升**三重压力叠加的历史性困境。英国的乱局是这一大背景下最极端的个案，折射出当民粹情绪遭遇现实约束时，政治体制承受的巨大张力。







## 欧洲的未来：几种可能的走向

这是当今世界最复杂的地缘政治问题之一。欧洲的未来并非单一线条，而是多种力量博弈的结果。

------

### 一、结构性压力——无论哪条路都绕不开

**人口危机是慢动作的定时炸弹**

欧洲的出生率普遍在1.2–1.6之间，远低于维持人口所需的2.1。这意味着未来20–30年，劳动人口持续萎缩，养老金体系面临根本性挑战。没有大规模移民，经济增长几乎无解；但移民又带来社会撕裂——这个矛盾没有轻松的出口。

**经济竞争力的结构性衰退**

欧洲夹在美国（科技创新）和中国（制造规模）之间，正在失去独特优势。前欧洲央行行长德拉吉2024年的报告直接警告：欧洲若不大幅改革，将面临"慢性衰退"。能源成本高、监管繁琐、资本市场分散，这些都是深层病根。

**安全依赖的终结**

冷战后欧洲享受了几十年"和平红利"，将防务外包给美国，把钱花在福利上。俄乌战争和特朗普的回归彻底打破了这一幻觉。欧洲必须重建自主防御能力，但这需要大量资金和政治意志——两者目前都不充裕。

------

### 二、三种可能的未来

**① 渐进整合——欧盟走向更紧密的联邦**

乐观情景：俄乌战争的外部压力迫使欧洲国家搁置分歧，加速政治整合。欧盟发行共同债券（已有先例）、建立真正的欧洲军队、统一能源市场。法德轴心重新激活，欧洲形成一个有实质影响力的"第三极"。

这条路的障碍在于：各国选民的民族主义情绪、南北欧的经济利益分歧（德国不愿为意大利债务买单）、以及匈牙利等国的结构性阻挠。

**② 碎片化——民粹浪潮重塑欧洲版图**

现实情景：极右政党在多国持续执政或扩大影响，各国优先本国利益，欧盟沦为松散协调机构。匈牙利模式蔓延，"主权民主"成为新叙事。欧洲在对华、对俄政策上无法形成统一立场，影响力大幅下降。

这并非欧洲解体，而是欧盟"空心化"——壳还在，但凝聚力大不如前。

**③ 双速欧洲——核心圈与外围圈分化**

最可能的情景：法、德、荷、北欧等国形成更紧密的核心整合圈，推进防务、财政、数字化协作；而南欧、东欧部分国家则保持更松散的联系，各走各路。欧盟不会崩溃，但内部分层会越来越明显。

------

### 三、几个关键变量

**乌克兰战争的结局** 这是决定欧洲未来十年走向的最重要单一变量。若乌克兰维持主权完整，欧洲的安全架构将重建；若俄罗斯实现实质性领土目标，欧洲的震慑逻辑将根本动摇，波罗的海三国、波兰的恐惧将主导整个欧洲政治。

**德国的转型能否成功** 德国是欧洲的经济引擎。它能否在汽车工业衰退的同时，成功转型为数字经济和绿色能源强国，将决定整个欧洲的经济底色。目前信号喜忧参半。

**与中国的关系如何定位** 欧洲在对华问题上极度撕裂：需要中国市场，又担忧技术依赖和价值观冲突。"去风险"还是"脱钩"，各国立场差异巨大。这个问题的答案将塑造欧洲未来的贸易格局和战略选择。

**极右翼能否真正执政并兑现承诺** 民粹政党善于批判，执政后的现实往往比口号复杂得多。意大利梅洛尼政府的案例颇具启示：上台后在欧盟框架内相当务实，并未如预期般"掀桌子"。极右翼执政的实际效果，将检验民粹浪潮的真实边界。

------

### 四、一个更长远的视角

历史上，欧洲每次最深刻的整合，都发生在最严重的危机之后——两次世界大战催生了欧共体，2008年金融危机推动了欧元区改革，新冠疫情促成了欧盟共同举债。

从这个意义上说，当前的多重危机也可能成为欧洲深化整合的历史契机。但这需要政治领袖有能力将危机感转化为制度建设，而不是被民粹情绪消耗殆尽。

**欧洲最大的资产**，是几百年积累的法治传统、公民社会、科学文化遗产，以及相对成熟的民主制度。这些软实力不会在一代人内消失。

**欧洲最大的风险**，不是某一场战争或某一次选举，而是在焦虑中逐渐丧失改革意志，陷入"知道问题在哪里，但什么都做不了"的政治瘫痪。

欧洲的未来，在很大程度上取决于它能否找回叙事——一个既诚实面对困难、又能激励人心的共同故事。目前这个故事还没有写完。







欧洲如今的情况在整个欧洲历史上算差吗，历史上什么情况和当下的处境类似？

## 欧洲当下的处境：历史坐标在哪里？

先给一个直接判断：**以欧洲历史的整体尺度来看，当下远不算最差，甚至算相当好。** 但如果以"二战后黄金时代"作为参照，当下确实是1945年以来最充满不确定性的时期之一。

这个区别很重要——用什么基准来衡量，结论截然不同。

------

### 一、历史上真正的至暗时刻

要理解当下，先要看欧洲历史上真正的深渊是什么级别。

**三十年战争（1618–1648）** 这场战争几乎摧毁了中欧。德意志地区人口损失30%–40%，部分地区高达60%。军队所到之处烧杀抢掠，饥荒和瘟疫随之而来。整整一代人生活在彻底的无序和暴力中。战后签订的《威斯特伐利亚和约》奠定了现代主权国家体系——代价是欧洲用了一个世纪才缓过来。

**黑死病（1347–1351）** 四年间欧洲死亡人口约三分之一，部分地区超过一半。整个社会结构——封建制度、教会权威、劳动力关系——都被这场生物冲击彻底改写。这种级别的文明震荡，当代欧洲完全无法相比。

**两次世界大战** 这是现代欧洲最深的创伤。一战死亡约1700万人，二战欧洲战场死亡超过4000万，其中包括600万犹太人被系统性屠杀。大陆主要城市化为废墟，整个文明的道德基础被动摇——"启蒙理性带来进步"的信念在奥斯维辛之后几乎崩塌。

**与这些相比，今日欧洲的处境是：和平、富裕、自由。** 这不是小事。

------

### 二、哪些历史时期与当下最相似

**最接近的类比：19世纪末的"美好年代"向一战前夜的转变（1890–1914）**

这个类比是目前历史学界讨论最多的，也是最发人深省的。

那个时代的特征和今天惊人地相似：

- 全球化达到高峰，贸易、资本、人员跨境流动空前繁荣
- 技术革命（电力、铁路、电报）带来财富，也带来社会失序和焦虑
- 民族主义情绪高涨，各国内部阶级矛盾激化
- 大国之间表面维持秩序，背后军备竞赛暗流汹涌
- 精英阶层普遍认为"大国之间不可能爆发全面战争，代价太高了"

然后1914年来了。

今天令人不安的对应：全球化红利见顶、民粹民族主义兴起、中美博弈类似英德竞争、俄乌战争打破了"欧洲永久和平"的幻觉。当年没有人预料到一场萨拉热窝的刺杀会引爆整个体系——今天同样存在类似的系统性脆弱性。

------

**第二个类比：罗马帝国晚期的"三世纪危机"（235–284年）**

这个类比更长远，但结构性相似度很高。

罗马在这50年间换了近50位皇帝，大多数死于政变——这和英国频繁换首相、欧洲政府不稳定有某种回响。更深的相似在于：

- 边疆压力持续增大（日耳曼人、波斯人），对应今天俄罗斯的压力和移民潮
- 内部经济通胀严重，货币贬值
- 精英阶层和普通民众之间的信任断裂
- 帝国意识形态（"罗马普世主义"）开始失去感召力，对应今天"欧洲自由主义普世价值"的退潮

罗马最终没有在三世纪危机中崩溃——戴克里先实施改革，帝国又延续了两百年。但它从此变成了一个不同的东西。这或许暗示欧洲也会转型，而非崩溃。

------

**第三个类比：宗教改革后的欧洲分裂（16世纪）**

马丁·路德1517年的95条论纲，撕裂了欧洲一千年的精神统一体。之后一个世纪，欧洲陷入宗教战争、政治重组、价值观冲突的漩涡。

今天的对应：互联网和社交媒体打破了精英阶层对信息和叙事的垄断，类似印刷术当年打破教会对知识的垄断。结果是：共识崩塌、极端思想蔓延、社会分裂加剧。那个时代也有人以为世界末日到了——最终欧洲在撕裂和战争之后，重建了一套新的政治秩序（主权国家体系）。

------

**第四个类比：19世纪40年代的"革命之春"（1848年）**

1848年，革命几乎同时席卷法国、奥地利、普鲁士、意大利诸邦。民族主义、自由主义、社会主义三股力量交织，旧秩序摇摇欲坠。

今天的相似之处：多国同时经历政治动荡，传统中左和中右政党双双衰退，新的政治力量（极左、极右、绿党、民粹运动）重组政治版图。1848年的革命最终大多失败，但它播下的种子在此后几十年里重塑了欧洲。

------

### 三、当下有什么是历史上没有过的

尽管历史类比有启发性，当代欧洲也面临一些**真正前所未有的挑战**，没有现成历史剧本：

**核武器的存在改变了大国冲突的逻辑**。历史上欧洲大国打烂了重来，今天这条路不再开放。这既是约束（防止了常规大战），也是压力（核威慑下如何回应俄罗斯？）。

**气候变化是文明尺度的威胁**，欧洲南部的干旱化、极端天气将在本世纪深刻改变农业、移民、能源格局。这没有历史先例可循。

**人口下降叠加老龄化**，在人类历史上，人口减少通常是战争、瘟疫的结果。今天欧洲在和平繁荣中出现生育率崩溃，这是全新现象，历史没有给出"软着陆"的案例。

------

### 四、一个总体判断

如果把欧洲两千年历史铺开来看，今天的欧洲人是有史以来**最不可能死于战争、饥荒、瘟疫**的一代。这是真实的文明进步，不该被轻易否定。

但历史也反复告诉我们：繁荣和稳定往往会制造自满，而自满是最危险的前提。1913年的欧洲人也觉得自己生活在有史以来最好的时代——他们说得没错，但他们不知道那是悬崖边上的好时代。

当下欧洲的处境，用一句话概括大概是：**站在历史的高点上，面对结构性的下坡路，争论要不要走、怎么走。** 既不是深渊，也不是坦途。

## 欧洲、中国、美国能源竞争力详细对比

------

### 一、最核心的数字：工业电价与天然气价格

能源竞争力最直接的体现是**企业实际支付的能源价格**，这直接决定了制造业的生存空间。

**工业电价对比（2023年，美元/千瓦时）**

| 地区     | 工业电价    | 相对美国倍数 |
| -------- | ----------- | ------------ |
| 美国     | 约0.07–0.08 | 1×           |
| 中国     | 约0.08–0.10 | 1.1–1.3×     |
| 德国     | 约0.20–0.22 | 2.7–3×       |
| 法国     | 约0.15–0.17 | 2–2.2×       |
| 意大利   | 约0.22–0.25 | 3–3.2×       |
| 欧盟平均 | 约0.17–0.19 | 2.3–2.5×     |

**工业天然气价格对比（2023年，美元/百万英热单位）**

| 地区                 | 气价    | 相对美国倍数 |
| -------------------- | ------- | ------------ |
| 美国                 | 约2–4   | 1×           |
| 中国                 | 约8–12  | 3–4×         |
| 欧洲（战前）         | 约6–10  | 2–3×         |
| 欧洲（2022年峰值）   | 约70–80 | 20–25×       |
| 欧洲（2023年回落后） | 约12–18 | 4–5×         |

关键在于：即使俄乌战争的冲击高峰过去，欧洲天然气价格**永久性地抬升了**——因为从管道气切换到LNG（液化天然气），结构性成本就是更高。

------

### 二、为什么会有这么大的差距？根源分析

**美国：得天独厚的页岩革命**

2008年前后，水力压裂技术（页岩气开采）彻底改变了美国的能源版图。

- 美国天然气产量从2008年的约5600亿立方米飙升至2023年的约10000亿立方米，翻了将近一倍
- 美国从天然气进口国变成全球最大LNG出口国
- 国内气价因供应过剩长期低迷，形成制造业的天然补贴
- 电价低廉直接支撑了美国"再工业化"——芯片厂、电池厂、化工厂纷纷选址美国

本质上，美国的低能源价格**不是政策的结果，而是地质的馈赠加技术的变现**。这是欧洲无法复制的。

**中国：规模优势加政策补贴**

中国能源价格能维持竞争力，来自几个叠加因素：

煤炭是中国工业能源的压舱石。中国是全球最大煤炭生产国和消费国，2023年煤炭仍占发电量的约60%。煤炭价格虽然波动，但中国对国内煤价有行政管控能力，能源价格受国际市场冲击相对较小。

同时，中国在可再生能源上的规模投入带来了显著的成本优势——中国光伏组件产量占全球约80%，风电装机约占全球45%，规模效应使得可再生能源的度电成本持续下降。在某些省份，工业用电已经出现低价绿电时段。

此外还有隐性补贴：国有能源企业的政策性亏损由财政托底，地方政府为吸引投资往往给重点企业提供优惠电价。这些不完全反映在官方数据中。

**欧洲：多重劣势叠加**

欧洲高能源价格是结构性的，原因层层叠加：

*地质层面*：欧洲本土化石燃料储量有限。北海油气田已过峰值，产量持续下降。欧洲无法复制美国的页岩革命——地质条件不同，且人口稠密地区的开采面临强烈的社会阻力。

*政策层面*：欧洲碳排放交易体系（EU ETS）给化石燃料发电和高碳工业强制加价，2023年碳价一度超过每吨100欧元。这是有意为之的政策设计，目的是推动脱碳，但代价是直接抬高了工业能源成本。

*能源税*：欧洲各国普遍对能源征收高额税费。德国工业电价中，税费和附加费一度占到40%以上（虽然近年对部分工业有豁免）。

*可再生能源补贴的历史包袱*：2000年代欧洲大规模补贴光伏和风电，补贴成本通过电价附加费由用户承担，持续了十几年。这笔账已经还得差不多了，但留下了电网改造的成本。

*俄罗斯依赖的历史债*：欧洲过去20年将廉价俄罗斯管道气作为能源政策的核心，放弃了能源多元化。2022年这条路被切断，欧洲被迫在全球LNG市场上高价抢购，且LNG再气化的基础设施也要重新建设。

------

### 三、对工业竞争力的实际冲击

**化工行业：最直接的受害者**

化工行业既用天然气作燃料，又用它作原料（乙烯、氨等基础化学品的原料就是天然气）。能源价格翻倍对化工企业是双重打击。

巴斯夫（BASF）是全球最大化工企业，总部在德国路德维希港。2022–2023年，巴斯夫明确宣布：

- 永久性裁减欧洲员工约2600人
- 关闭路德维希港部分产能
- 将增量投资转向美国和中国
- CEO公开表示"欧洲作为化工生产基地的竞争力已经动摇"

这不是个案。欧洲化工产业协会的数据显示，2022年欧洲化学品产量下降了约8%，而同期美国增长约4%，中国增长约5%。

**钢铁与铝：高耗能行业的空心化**

炼铝是极度耗电的行业，电价直接决定生死。2022年能源危机期间，欧洲约一半的铝冶炼产能被迫减产或停产。即使危机过后，部分产能也没有恢复——因为重启需要重新签订长期电力合同，而当前的价格水平使重启无利可图。

欧洲铝产量从2000年代峰值约400万吨/年，下降至2023年约200万吨/年，几乎腰斩。缺口由进口（主要来自中国、中东、俄罗斯）填补。

**汽车业：能源成本推高制造成本**

欧洲汽车业的困境是多重因素叠加，但能源成本是其中之一。德国大众、宝马、奔驰的制造成本中，能源占比约3–5%，看起来不高，但当竞争对手（中国车企）的能源成本只有一半时，这个差距在薄利润的汽车行业就是决定性的。

2023–2024年，大众宣布考虑关闭德国本土工厂，这在大众的历史上从未发生过。能源成本是原因之一，但绝非全部。

------

### 四、中美欧的能源战略对比

**美国的战略逻辑：低价能源作为再工业化武器**

拜登政府的《通胀削减法案》（IRA，2022年）本质上是用低价能源加巨额补贴，吸引全球清洁能源制造业向美国集中。结果是：

- 2022–2024年，美国新宣布的芯片、电池、清洁能源制造投资超过5000亿美元
- 大量原本考虑在欧洲投资的项目转向美国
- 欧洲称之为"不公平补贴"，但拿出的应对方案远不如IRA有力

美国能源战略的核心是：**让便宜的本土能源成为吸引制造业回流的护城河**。

**中国的战略逻辑：两条腿走路**

中国同时在走两条路，表面上看似矛盾，实则互补：

一方面，维持煤炭主导的低成本能源供应，保障现有制造业的竞争力，不允许能源转型的代价影响工业产出——这是短期竞争力的保障。

另一方面，以无可匹敌的规模投资可再生能源，2023年新增光伏装机超过200GW（超过全球其他国家总和），目标是掌握下一代能源技术的产业链主导权——光伏组件、风机、电池、电解槽，中国在这些领域的全球市占率均超过60%甚至80%。

中国的赌注是：**先用煤炭赢得现在，再用可再生能源赢得未来**，且把可再生能源本身做成出口产业。

**欧洲的战略困境：两头不到岸**

欧洲的两难在于：

它想要快速脱碳（碳中和目标2050年），所以不愿大规模开采本土化石燃料；但它又没有中国那样的规模来把可再生能源成本压到足够低；同时还要承受转型期的高能源价格。

本质上，欧洲在以牺牲当下竞争力为代价，赌一个绿色未来——但这个赌注能否兑现，时间表能否跟上，存在巨大不确定性。

德国的能源转型（Energiewende）是这个困境的缩影：以2000亿欧元以上的补贴推动可再生能源，退出核电，结果是电价反而成为欧洲最贵之一，工业外流，而碳排放下降的速度并不比保留核电的法国更快。

------

### 五、一个结构性的不对称

最后有一点值得单独拿出来说：

**能源价格差距对不同行业的影响是不对称的。**

对金融、软件、奢侈品、制药等行业，能源价格几乎无关紧要。但对化工、钢铁、铝、水泥、玻璃、造纸、化肥这些"基础工业"，能源成本往往占总成本的30–60%。能源价格翻倍，直接意味着这些行业在欧洲失去生存空间。

这些基础工业看起来不光鲜，但它们是制造业供应链的底层。没有本土化工，就没有本土材料；没有本土材料，高端制造业的供应链就是悬空的。

欧洲正在失去的，是制造业生态系统的**根系**——而不只是某几家具体的企业。这种损失是隐性的、缓慢的，但一旦形成，重建的代价远比维持要高得多。



## 2025年最新数据：三方能源竞争力对比

### 一、工业电价：差距扩大，且比历史更严重

**IEA（国际能源署）2025年数据**

| 地区 | 2025年工业电价（大型用户） | 与美国的倍数 |
| ---- | -------------------------- | ------------ |
| 美国 | 基准                       | 1×           |
| 中国 | 约为美国的50%              | 约0.5×       |
| 欧盟 | 约为美国的2倍以上          | 2×+          |

更值得关注的是**差距的变化轨迹**：

- 2019年，欧盟工业电价比美国高约50%，比中国高约20%
- 2025年，欧盟工业电价比美国高超过100%，比中国高近50%

也就是说，短短六年间，欧洲对美国的劣势**翻了一番**，对中国的劣势**扩大了两倍**。这不是缓慢的漂移，是加速的发散。

**2025年欧盟批发电价**：约95美元/兆瓦时，同比再涨约10%，与荷兰TTF天然气基准价上涨9%基本同步——说明欧洲电价仍高度依赖天然气价格。

**一个值得注意的反转**：2025年上半年，美国电价同比上涨约40%（主要因为AI数据中心爆发式增长带来的用电需求暴增），欧盟同期上涨约30%。这是多年来少见的美国电价涨幅超过欧盟的情况。但绝对水平的差距仍然巨大——美国从低基数涨，欧洲从高基数涨。

------

### 二、天然气价格：结构性高价已固化

2022年前欧洲依赖俄罗斯管道气，价格相对可控。切断之后，欧洲被迫转向全球LNG现货市场，结构性成本抬升。

**2022年至今的对比**

自2022年能源危机以来，欧洲工业用天然气平均价格：

- 是**中国的约1.3倍**
- 是**美国的约5倍**

这个5倍差距在2025年没有根本改变。美国天然气价格受益于本土页岩气充裕供应，长期维持在每百万英热单位2–4美元的低位；欧洲TTF气价在2025年约为12–18美元区间，是美国的4–5倍。

**有一个潜在的缓解因素**：2026年全球预计新增5400万吨LNG产能（主要来自美国、卡塔尔），加上需求端疲软，分析师预测欧洲气价有下行空间。但这能否真正缩小竞争力差距，还要看降幅是否足够大、是否持续。

------

### 三、去工业化：2025年的实际伤亡

数据不只停留在价格层面，已经在产业层面变成了真实的损失。

**就业**：2024年欧洲制造业单年流失约12万个工作岗位，至2025年初制造业就业总人数约降至667万，趋势持续。

**巴斯夫（BASF）**：宣布在欧洲推行超过20亿欧元的年度成本削减计划，直接原因是德国工业形势恶化，同时加大在美国和中国的投资。BASF CEO公开表示，欧盟碳排放交易体系正在"摧毁欧洲工业基础"。

**蒂森克虏伯（ThyssenKrupp）**：宣布关闭德国Kreuztal-Eichen钢铁厂，理由是高能源成本加上中国廉价进口钢铁的双重夹击。

**安赛乐米塔尔（ArcelorMittal）**：推迟或缩减多项欧洲投资计划，理由是监管环境不确定和成本过高。

一个有意思的细节：Bloomberg在2025年底报道，即便欧洲天然气价格相对2022年高峰有所回落，欧洲受伤的工业也**难以跟上经济复苏的节奏**——因为部分产能已经永久关闭，市场份额已经被亚洲竞争对手占据，不是价格一降就能自动恢复的。

------

### 四、横向小结：三方的2025年位置

| 维度         | 美国                   | 中国                      | 欧洲                          |
| ------------ | ---------------------- | ------------------------- | ----------------------------- |
| 工业电价     | 最低，但2025年涨幅最大 | 最低（与美接近或更低）    | 最高，约为美国2倍             |
| 工业气价     | 最低（页岩气红利持续） | 中等                      | 高，约美国4–5倍               |
| 能源价格趋势 | 上行（AI用电需求）     | 相对稳定                  | 小幅上行                      |

| 政策应对     | IRA补贴+本土能源优势   | 煤炭保底+大规模可再生能源 | 碳市场+转型成本叠加，应对乏力 |

------

### 五、2025年一个新变量：AI用电需求的分化影响

这是2025年新出现的、值得单独提的因素。

美国AI数据中心爆发式建设，带动电力需求大幅增长，推高了美国电价——但同时也创造了大量高附加值就业和投资。欧洲在AI基础设施投资上远落后于美国和中国，用电需求的AI增量也小得多。

这意味着美国电价上涨的背后是**产业升级带来的需求拉动**，而欧洲电价维持高位的背后是**能源结构成本推动**——性质完全不同，同样是电价高，对竞争力的含义截然相反。

------

总体判断：2025年的数据没有给欧洲带来根本性改善。差距从2019年到2025年持续扩大，产业外流从趋势变成了现实的关厂和裁员。最大的变数是2026年以后LNG新产能投产能否带来持久降价，但即便如此，欧洲需要弥补的结构性差距已经积累了太多年。



## 中美电价

![image-20260522183406704](./img/image-20260522183406704.png)



为什么我在别的地方看到的中国电价是小于美国的

这是一个很好的质疑，我应该直接承认：**我图表中的中国数据存在不确定性，而且这个问题本身确实没有单一答案**，取决于你看的是哪种数据口径。让我解释为什么会出现这种矛盾。你的质疑完全合理，这里有真实的数据矛盾，需要解释清楚。

------

### 核心原因：你们看的是不同的"电价"

中国电价有一个极其复杂的分类体系，不同口径的数字差距极大，这是混乱的根源。

**居民用电 vs. 工业用电——方向完全相反**

中国长期实行"工业补贴居民"的交叉补贴政策。居民电价被人为压低，工商业用电则被要求承担更高价格来弥补差额。这和大多数西方国家恰好相反——美国是居民电价高、工业电价低。

结果就是：

| 用电类型         | 中国                    | 美国     | 谁更贵      |
| ---------------- | ----------------------- | -------- | ----------- |
| 居民用电         | 约0.5–0.6元（≈7–8¢）    | 约13–14¢ | 美国贵约1倍 |
| 工业用电（均值） | 约0.63–0.80元（≈9–11¢） | 约7–9¢   | 中国贵      |

**所以"中国电价比美国便宜"这个印象，通常来自居民电价或全口径平均价的比较，而不是工业口径。**

------

### 第二个原因：中国地区差异极大

中国各省的工业电价差距在2–3倍之间，而你看到的数据可能来自低价地区：

- 云南（水电过剩）：工业电价可低至0.3元/度 ≈ 4¢，确实远低于美国
- 四川、内蒙古：也有大量廉价工业用电
- 广东、上海、浙江：工业电价0.7–0.9元/度 ≈ 10–12¢，比美国贵不少

铝冶炼、多晶硅等高耗能产业之所以大量落地云南、内蒙古，正是为了利用这些地方的廉价电力。但这不代表中国工业用电整体比美国便宜。

------

### 第三个原因：部分来源引用的是"大工业直购电"价格

中国允许大型工业用户通过"电力直接交易"绕过电网，直接和发电企业签合同，价格往往低于目录价20–30%。如果某个来源引用的是这个价格，当然会显得很低。

------

### 我的图表有多准确？

坦白说，我图表里的中国数据存在高估的可能性，尤其是2021–2025年的部分数值。不同来源给出的数字差距本身就有1–3¢之多。**可以确定的是**：

- 中国工业电价**整体上接近美国，并非显著低于美国**（这和欧洲的情况不同）
- 中国廉价电力主要集中在特定省份和特定用电规模，不代表全国水平
- 如果你看到"中国电价是美国一半"，那几乎肯定是在比较居民用电

这也解释了一个矛盾：中国制造业的能源竞争力优势，对欧洲企业来说是真实的，但对美国企业来说并不明显——美国工业用电其实相当便宜，是欧洲才处于真正的劣势位置。





## 为什么中国制造业成本比美国低

这是一个很好的追问，直接触及了制造业竞争力的本质。

**电费在制造业成本里占多少？**

这是理解问题的关键。对绝大多数制造业而言，电费只是总成本的一个小项：

| 行业       | 能源占总成本比例 | 劳动力占总成本比例 |
| ---------- | ---------------- | ------------------ |
| 铝冶炼     | 35–45%           | 5–8%               |
| 钢铁       | 20–30%           | 10–15%             |
| 化工       | 25–40%           | 8–12%              |
| 汽车零部件 | 3–5%             | 25–35%             |
| 电子组装   | 1–3%             | 40–60%             |
| 纺织服装   | 3–6%             | 50–70%             |

能源成本对铝、化工、钢铁这类"高耗能"行业至关重要，所以欧洲这些行业在能源贵的情况下会大规模外流。但对大多数制造业，电价根本不是决定性因素，**劳动力成本才是**。

------

### 真正让中国制造成本低的因素

**一、劳动力成本：差距仍然巨大**

这是最核心的因素，没有之一。

- 中国制造业工人平均工资：约6–8美元/小时（2023年）
- 美国制造业工人平均工资：约25–30美元/小时

即便加上社保、管理成本，中国劳动力综合成本仍然是美国的1/4左右。对电子组装、服装、家具这类劳动密集型行业，这个差距直接决定了竞争力的全部。

值得注意的是，这个差距在缩小。2000年中国工资约是美国的1/30，现在是1/4左右。这也是为什么低端制造业在过去十年开始向越南、孟加拉国转移。

**二、供应链集群：这是中国最被低估的优势**

这可能是比劳动力更难被复制的优势。中国在过去30年里形成了密度极高的产业集群：

- 深圳：全球最密集的电子零部件供应链，几乎所有电子元器件都能在方圆100公里内采购到
- 义乌：小商品，任何日用品的零件都能当天找到
- 佛山：家具、陶瓷、铝材
- 宁波-绍兴：纺织、化纤

这意味着什么？一家在深圳的手机工厂，下午发现缺某个零件，当天就能从隔壁工厂拿货，第二天继续生产。同样的工厂如果建在美国，可能需要等待从亚洲空运，耽误一两周，成本不可比拟。

苹果公司的供应链负责人曾内部解释为何不能把iPhone生产移回美国，核心理由不是工人工资，而是：**美国根本没有足够多的工具和模具工人，而且缺乏整个零部件生态系统。**

**三、政府补贴：隐性成本的系统性转移**

中国各级政府对制造业的补贴是全面性的：

- 工业用地：地方政府以极低价格甚至免费提供土地，有时相当于直接补贴了厂房建设成本的30–50%
- 国有银行贷款：利率低于市场，且对战略性产业有更宽松的风险容忍度
- 出口退税：制造商出口产品可退还部分增值税，相当于降低了出口商品的价格
- 专项补贴：新能源、半导体、高铁等战略行业有大量直接财政补贴

这些补贴往往不直接体现在电价或工资里，但实际上降低了企业的综合成本。WTO框架下许多属于"灰色地带"，美欧多次提出诉讼，但难以完全量化和制止。

**四、监管成本：环保、安全、合规的代价差异**

美国制造业要遵守的环境法规、劳工安全标准、产品合规要求极为严格，执行也相对到位。这些合规成本是真实的——一个美国钢铁厂处理工业废水的成本，可能比同规模中国工厂高出数倍。

这不是说中国完全不管，而是执行力度、标准高度和追溯机制存在系统性差异。近年来中国环保执法有所加强，但差距依然存在。

**五、规模效应：中国工厂的体量无可比拟**

郑州富士康高峰期有30万工人在同一个园区组装iPhone。这种规模在美国从物理上就很难复现——土地获取、城市规划、劳动力聚集都不支持。

规模带来的固定成本摊薄、采购议价能力、物流效率，本身就是一种竞争优势。

------

### 一个反直觉的结论

"中国制造便宜"的原因，按重要性大致排序：

1. **劳动力成本**（最重要，但差距在收窄）
2. **供应链集群密度**（最难被复制，长期优势）
3. **政府补贴和土地成本**（显著但难量化）
4. **监管合规成本差异**（真实存在，逐渐收窄）
5. **规模效应**（与集群密度相互强化）
6. **能源成本**（对高耗能行业重要，对大多数制造业影响有限）

电价在这个列表里排在末位。这也是为什么美国即便页岩气给了工业廉价能源，也没能自动复活制造业——工厂回流面临的真正障碍是供应链的缺失和劳动力成本，不是电价。
