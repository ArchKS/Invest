# 旅游场景口语卡

每次选一张，只看“你的任务”，先用英语说。下方句型只在卡住时参考。陪练选一个变化加入对话，不要提前说出。你可以带着地图、订单、菜单练习，使用旅行现场正常能看到的信息。

## 通用规则

一次只交流一轮；别背完整对话。完成一个任务后，说一句确认结果的话，例如 “So the bus leaves at nine twenty from stop four, right?”。

练习结束只记最影响理解的三处问题，再换条件重做。场景中的价格、规则和时间均为练习设定，实际旅行以现场信息为准。

## C1：机场与入境

**你的任务**：说明旅行目的和停留时间；机场柜台核对行李条件、座位、登机口和起飞时间。每次选入境或值机其中一个子场景练。

**可用句型**：I'm here on holiday. / I'm staying for ten days. / Is one checked bag included? / Could I have an aisle seat? / Which gate should I go to?

**给陪练的变化**：原座位没有了；随身行李超过限制；登机口改了；追问住哪里或下一站去哪里。

**结束标准**：入境时能清楚回答自己的实际行程；值机时确认下一步地点与时间，听清行李限制。

## C2：交通与问路

**你的任务**：从机场去酒店；比较巴士与火车，询问票价、路线和行李；请对方在地图上指出站点。

**可用句型**：What's the easiest way to get to this address? / Do I need to change trains? / Is this a single or a return ticket? / Could you show me on the map?

**给陪练的变化**：原路线停运；站台改变；某段需要步行；票价没有包含全部路段。

**结束标准**：能复述交通方式、上车地点、时间、费用和是否换乘。

## C3：酒店

**你的任务**：入住两晚，拼姓名并给出预订号；问早餐、退房、押金；房间太吵，申请换房。

**可用句型**：I have a booking under the name Chen. / Is breakfast included? / Is the deposit refundable? / My room is quite noisy. Could I move to a quieter room?

**给陪练的变化**：暂时查不到订单；还不能入住；只有明天能换房；有额外费用。

**结束标准**：确认入住或换房的具体安排，并问清费用与时间。

## C4：餐厅

**你的任务**：两个人用餐；询问一道菜的食材与口味；提出自己的真实饮食要求；核对账单和付款方式。

**可用句型**：Could we have a table for two? / What would you recommend? / Does this contain nuts? / Could I have the sauce on the side? / Is service included? / Could we pay separately?

**给陪练的变化**：想点的菜卖完；需要等位；厨房无法满足某项要求；账单里多了一项。

**结束标准**：确认点了什么、重要饮食要求是否能满足、账单与付款结果。涉及严重过敏时，明确告知并请工作人员确认。

## C5：购物与退换

**你的任务**：买衣服，询问尺码、颜色与试衣间；问退换条件；之后发现尺码不合适，申请换货。

**可用句型**：Do you have this in a larger size? / Could I try it on? / What's your return policy? / I bought this yesterday. Could I exchange it?

**给陪练的变化**：原尺码缺货；只能换货；需要收据；替代商品价格不同。

**结束标准**：问清可行选择、价格差额和办理条件。

## C6：改订与取消

**你的任务**：原定明天的活动无法参加；询问改到后天、换时间或退款的可能性。

**可用句型**：Something has come up. / Would it be possible to move my booking to Friday? / Is there a fee to change it? / What other options do I have?

**给陪练的变化**：后天满了；改订有费用；退款有期限；只有另一个时段。

**结束标准**：确认新日期、新费用和需要自己完成的操作。

## C7：遗失物品

**你的任务**：包可能落在巴士上；描述颜色、大小、明显特征、乘车时间和下车站点；留下联系方式。

**可用句型**：I think I left my bag on the bus. / It's a small black backpack with a red tag. / Where can I report it? / How will you contact me if it's found?

**给陪练的变化**：需要路线编号；包的描述不够具体；需要填写表格；物品被送往另一个服务点。

**结束标准**：对方能够记录信息；你知道下一步联系谁、如何查询。

## C8：药房与求助

**你的任务**：说明不适、开始时间和真实的过敏信息；请专业人员解释建议，确认不明白的限制；需要时询问就医地点。

**可用句型**：I've had a sore throat since yesterday. / I'm allergic to ... / Could you explain how to use it? / Are there any precautions? / Could you help me find a doctor?

**给陪练的变化**：出现陌生词；某项产品需要处方；建议就医；没听清使用说明。

**结束标准**：能说明情况、向专业人员确认建议和下一步。角色卡只练表达，不提供诊断或用药建议。

## C9：闲聊与当地推荐

**你的任务**：聊家乡、兴趣和这次旅行；请对方推荐当地食物或地方；对回答追问两次。

**可用句型**：What do you like most about living here? / What do you usually do for fun? / What would you recommend nearby? / How did you find that place?

**给陪练的变化**：对方推荐一个陌生项目；突然问你的工作；问为什么喜欢你的家乡；问明天的计划。

**结束标准**：持续约 3 分钟，每次回答尽量加一个细节，再把话题递回去。

## C10：讲旅行经历

**你的任务**：讲一次旅行的小故事，依次说地点、发生什么、怎么处理、感受；听完对方故事后追问。

**可用句型**：Last year, I visited ... / At first, ... / Then ... / In the end, ... / The best part was ... / How did you feel about it?

**给陪练的变化**：追问某个细节；没听懂你的一句话；讲一个与你不同的经历；问你的下一次计划。

**结束标准**：连续聊 3–5 分钟，能换简单说法解释卡住的词。

## C11：完整抵达日

**你的任务**：串联机场询问 → 交通买票 → 酒店入住 → 餐厅点餐。练习全程约 10–15 分钟，可以查看模拟订单、地图和菜单。

**给陪练的变化**：从 C1–C4 中选两项变化，中途加入；所有关键信息前后一致。

**结束标准**：四件事都推进到明确结果；每个场景至少主动确认一项时间、地点、金额或要求。

## C12：随机验收

**你的任务**：请陪练从 C1–C10 中随机抽三项，再加入一次时间或金额更正。你只知道场景标题，不看示范句。

**给陪练的变化**：使用学习者尚未练过的具体问题；至少出现一个需要解释的词；结束后反馈最影响理解的三处。

**结束标准**：把需求说清楚、听准关键细节、能追问并确认结果。没通过的场景再练一周，用不同条件重新验收。

## 随时可用的五句

| 目的 | 英语 |
|---|---|
| 重复 | Sorry, could you say that again? |
| 慢一点 | Could you say that a little more slowly? |
| 解释 | What do you mean by “…”? |
| 核对 | Did you say thirteen or thirty? |
| 写下来 | Could you write that down for me? |
