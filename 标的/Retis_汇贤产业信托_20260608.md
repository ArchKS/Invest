# 汇贤产业信托（HK.87001）投资分析报告

> 报告日期：2026年6月8日 
> 数据来源：朝夕投研 IMA 知识库（831条内容精华汇总） 
> 分析框架：烟蒂股策略 + 龟龟投资策略  

---

汇贤产业信托自2011年上市以来，股价从高位跌去约90%，核心原因是三重结构性打击：

第一重：政策冲击（《外商投资法》2020年实施）
- 废止"外资三法"，切断了以折旧方式提前归还投资成本的跨境汇款通道
- 此前每年约2.64亿元折旧资金可合法汇出分派，2020年起归零
- 2020年全年分派同比暴跌56.7%

第二重：疫情+租金下行周期
- 核心资产北京东方广场租金持续下滑
- 东方新天地零售租金从约1000元/㎡跌至559元/㎡（跌幅44%）
- 以价换量策略尚未见底

第三重：法定公积金新规（2025年起）
- 外商投资企业统一按《公司法》执行
- 需提取税后利润10%作为法定公积金方可分配
- 每年减少可分派金额约7000-8000万元

## 一、财务表现与分派能力分析

### 3.1 历年分派金额变化（核心指标）

| 年份 | 可供分派金额 | 每基金单位分派（DPU） | 同比变化 | 重大事件 |
|------|--------------|---------------------|----------|---------|
| 2019 | ~13亿 | ~0.20元 | — | 《外商投资法》实施前最后一年 |
| 2020 | 5.77亿 | ~0.09元 | -56.7% | 政策冲击+疫情 |
| 2021 | 小幅回升 | — | — | 疫情后短暂复苏 |
| 2022 | 再次下滑 | — | -30% | 疫情反复+租金下行 |
| 2023 | 进一步恶化 | — | — | 港元汇兑巨额亏损 |
| 2025 | 2800万 | 0.0043元 | -90%+ | 法定公积金新规实施 |

2025年分派几乎归零的构成：
- 基本分派：0元（利润不足以覆盖法定公积金）
- 额外分派：2800万元（全部为资本性质，即"吃本金"）

### 3.2 利润生成能力分析

2025年财报关键数据（来自"点一"投资备忘录）：

```
收入：22.09亿元
公允价值变动损失：-12.9亿元（物业估值下调）
折旧：-3.18亿元
税前亏损：-6.8亿元
所得税：0.61亿元
税后利润：-7.4亿元

【现金利润口径】（剔除公允价值变动）
税后利润 + 折旧 + 公允价值变动 = 9.6亿元
获取经营现金能力：9.6亿元
折旧减去维护支出后自由现金流：~8.6亿元
```

关键发现：
1. 会计利润失真：公允值变动是纸面亏损，不影响现金流
2. 真实现金产生能力：每年约8-9亿元自由现金流
3. 但跨境传导效率极低：8.6亿自由现金流 → 仅2800万元实际分派（传导效率约3.3%）

### 3.3 跨境现金流传导路径与损耗

```
北京东方广场（BOP）生成现金流
    ↓ 缴纳企业所得税25%
    ↓ 提取法定公积金10%（2025年起）
    ↓ 汇出预提税5%
    ↓ 港元汇兑损失（每年约1.6亿）
    ↓ 管理人费用（基本费+浮动费）
    ↓ 物业管理费
    ↓ 融资成本（港元贷款汇兑亏损）
    ↓ 
香港汇贤信托层面可分派金额
    ↓ 分派比例90-100%
    ↓
实际分派给基金单位持有人
```

传导损耗总结：
- BOP产生现金流：~7.8亿元/年
- 实际分派：2800万元/年（2025年）
- 损耗率：96%

## 二、债务结构与汇兑风险

### 4.1 债务规模变化

| 年份 | 总债务（人民币） | 港币债务 | 人民币债务 | 债务/资产净值 | 人民币贷款占比 |
|------|----------------|--------------|----------------|----------------|----------------|
| 2020 | 108.71亿元 | 88.76 |  | 高 | <30% |
| 2023 | 66.01亿元 | 66.01 |  | 29.9% | ~40% |
| 2025 | 50.38亿元 | 24.2 | 26.2 | 27.0% | >50% |

积极变化：
1. 债务规模大幅下降（从108亿降至50亿）
2. 人民币贷款占比提升（降低汇兑风险）
3. 债务/资产净值比率改善

### 4.2 汇兑亏损——"出血点"

汇贤产业信托的功能货币为人民币，但大量债务以港元计价。

汇兑亏损机制：

- 每年报告期末，所有港元贷款本金及利息按期末汇率重新换算
- 人民币汇率变动直接产生汇兑差额，计入当期损益

历年汇兑亏损估算：
```
2020-2023年：每年汇兑亏损约1.5-2.0亿港元
2023年7月提前还贷15亿港元：一次性汇兑亏损1.926亿元
```

关键判断：
- 随着人民币贷款占比提升至>50%，未来汇兑亏损将显著收窄
- 但仍有约50%债务为港元计价，人民币若继续贬值仍会产生亏损

## 三、信托契约修订与分派政策变迁



### 5.1 历次修订对分派的影响

| 修订时间 | 核心修订内容 | 对分派影响 |
|---------|-------------|-----------|
| 2013年5月 | 引入"可分配折旧及摊销"概念，仅允许中国法律允许汇回香港的折旧部分加回可分派收入 | 显著下降（第一次切断折旧汇款） |
| 2014年5月 | 分派比例从固定90%改为"不低于90%但不高于100%" | 中性（增加灵活性） |
| 2015年5月 | 允许投资金融工具（上限5%） | 间接影响 |
| 2025年12月 | 将法定公积金提取纳入"调整"项，在计算可分派收入时予以撇除 | 显著减少（每年约7100万元） |

### 5.2 当前分派公式

```
实际分派金额 = (分派比例 × 可供分派收入) + 管理人厘定的额外金额 - 中期已分派金额

其中：
可供分派收入 = 信托集团除税后纯利 + 调整因素
调整因素包括：
  - 加回：收购公允价值调整产生的折旧及摊销（仅限于可汇回部分）
  - 加回/减去：未变现汇兑亏损/收益净额
  - 减去：中国法定公积金提取
  - 减去：不可分派支出
```



### 信托契约经典版本整理

### A组：初始信托契约基础条款（2011年4月1日生效）

> 这是汇贤产业信托上市时的"宪法性文件"，规定了REIT运作的根本规则。

#### A1. 分派政策（最核心条款）

原始公式（第11.4.2条）：

```
实际分派金额 = (分派比例 × 可供分派收入) + 管理人厘定的额外金额 - 当期已分派金额
```

其中各项原始定义：

| 项目               | 2011年原始定义                       |
| ------------------ | ------------------------------------ |
| 分派比例           | 固定不低于90%                        |
| 可供分派收入 =     | 除税后纯利 + 调整因素                |
| 调整因素（加回项） | 全部折旧及摊销（无条件全额加回）     |
| 额外金额           | 管理人酌情决定是否分派的资本性质金额 |

#### A2. 投资范围限制

| 限制类别       | 2011年原始规定       |
| -------------- | -------------------- |
| 地域限制       | 仅限中国境内商用物业 |
| 借贷上限       | 总资产值的45%        |
| 物业发展投资   | 不允许               |
| 金融工具投资   | 不允许               |
| 单一地区集中度 | 无明确限制           |

#### A3. 管理人费用结构

| 费用类型       | 2011年原始规定             |
| -------------- | -------------------------- |
| 基本费用       | 物业总价值的0.3%/年        |
| 浮动费用       | 物业收入净额的3%/年        |
| 物业管理人费用 | 包含在上述费用中或另行约定 |
| 支付频率       | 每季度支付一次             |

#### A4. 其他重要基础条款

| 条款类别     | 内容摘要                                              |
| ------------ | ----------------------------------------------------- |
| 功能货币     | 人民币（全球首只人民币计价港股REIT）                  |
| 报告货币     | 人民币                                                |
| 基金单位类别 | 单一类（人民币计价）                                  |
| 上市地点     | 香港联交所主板                                        |
| 持有人大会   | 至少每年一次，审批重大事项需特别决议案（75%以上赞成） |
| 回购机制     | 管理人可在市场上回购基金单位（需授权）                |
| 关联交易限制 | 与关联方的交易需独立董事批准                          |

## 四、核心资产

汇贤产业信托是典型的"单一资产依赖型"REIT：

```
汇贤产业信托资产组合
├── 北京东方广场（核心，贡献~90%收入）
│   ├── 购物中心：132,584㎡（东方新天地）

├── 重庆大都会广场（2014年收购）

└── 成都物业
```

三、费用变化的关键发现

📉 基本费用呈下降趋势

| 对比期          | 基本费用变化                                         | 原因             |
| --------------- | ---------------------------------------------------- | ---------------- |
| 2021H2 → 2023H2 | 5595万 → 5159万                                      | -7.8%            |
| 原因            | 物业估值下调导致GAV降低 → 按0.3%计算的基本费相应减少 | 公允价值减值传导 |

📉 浮动费用大幅下降

| 对比期                        | 浮动费用变化 | 原因                            |
| ----------------------------- | ------------ | ------------------------------- |
| 2021H2(847万) → 2023H2(701万) | -17.3%       | NPI下降导致按3%计算的浮动费减少 |

💡 核心结论

1. 费用总额在下降：从2021年的~1.3亿/年降至2023年的~1.16亿/年（两年降约10%）
2. 下降原因是被动而非主动：费用减少完全是因为物业估值下降和收入下滑，不是管理人主动降费
3. "资产值税"本质：基本费用与物业估值挂钩（0.3% of GAV），无论盈亏都照收不误，被投资者批评为"资产值税"
4. 支付方式稀释股权：70%的费用以发行基金单位形式支付，意味着管理人持股比例逐年上升（从最初的~0.7%升至当前的~1.8%）
5. 与其他REITs对比：领展等优质REIT的管理费通常在0.1-0.2%且与业绩挂钩更紧密；汇贤的0.3%+3%双重收费模式偏贵

二、站在李嘉诚角度：为什么要设立这个REIT？

动机一： 时机精准——"高点套现"

| 分析维度     | 详情                                                   |
| ------------ | ------------------------------------------------------ |
| 时间窗口     | 2011年正值人民币升值预期强烈 + 内地房地产泡沫初现      |
| 东方广场状态 | 运营成熟，现金流充沛，年租金数十亿                     |
| 套现规模     | IPO一次性套现53.8亿 + 后续资产注入再套现9.8亿 = 63.6亿 |
| 保留权益     | 仍持有51.3%（33.4%+17.9%），继续享受增值收益           |
| 本质操作     | "部分退出+保留控制权"——典型的李嘉诚式套现哲学          |

> 类比理解：这就像你有一栋每年收租500万的楼，你把它打包成REIT卖给公众，自己拿回了3000万现金，同时还保留51%的控制权继续收租分红。

动机二：资产周转加速——"低买高卖循环"

李嘉诚的商业哲学核心之一是"资产周转"：

```
传统地产开发模式：
买地 → 建设 → 出售/出租 → 回笼资金 → 再投资
（周期长、资金沉淀重）

李嘉诚的REIT化创新模式：
持有优质物业 → 打包成REIT上市 → 大额套现 → 投资更高回报领域
                ↓
         仍保留控制权和后续增值收益
```

具体到东方广场案例：

1. 1993-1999年：投入15亿美元建设（"低买"阶段）
2. 2000-2010年：享受10年租金红利（"培育"阶段）
3. 2011年REIT化：高点套现53.8亿（"高卖"阶段）
4. 套现后的资金投向：欧洲电信基建、港口、能源等更高回报资产

动机三： 风险分散——"鸡蛋不放一个篮子"

| 风险维度   | REIT化的作用                                             |
| ---------- | -------------------------------------------------------- |
| 政策风险   | 将内地物业权益部分转让给公众投资者，降低单一项目集中风险 |
| 汇率风险   | REIT以人民币计价但港股交易，自然形成对冲                 |
| 流动性风险 | 非流动的房地产变为可交易的证券                           |
| 周期风险   | 如果内地商业地产见顶回落，已提前锁定部分收益             |

动机四：📐 结构设计精妙——"控制权最大化"

李嘉诚团队在汇贤REIT的结构设计中体现了极高的财技水平：

```
控制链路：
李嘉诚（个人）
  → 长江实业（33.4%股东）
  → 和记黄埔（17.9%股东）
  → 合计控制汇贤REIT 51.3%
    → 控制北京东方广场（核心资产）

同时：
  • 管理人是长江实业附属公司（每年收取~1.2亿管理费）
  • 物业管理人也是关联方（收取物业管理费）
  • 后续资产注入（重庆大都会39.1亿）也是向自己买
```

> 一句话总结：李嘉诚既是大股东（收分红）、又是管理人（收管理费）、还是卖家（资产注入时收对价）。"一鱼三吃"的设计堪称经典。

## 第二部分：信托契约分派义务分析

### 一、分派义务是否"强制"？

核心结论：汇贤的信托契约有分派义务，但有条件门槛。

| 条款           | 内容                                                         | 影响                            |
| -------------- | ------------------------------------------------------------ | ------------------------------- |
| 分派比例       | ≥90%但不高于100%的可分派收入                                 | 有义务分派90%以上               |
| 分派触发条件   | 仅在"可分派收入"为正数时触发                                 | 若可分派收入为0或负，无强制分派 |
| 可分派收入公式 | NPI - 利息支出 - 管理人费用 - 法定公积金 - 汇兑亏损 + 资本性质溢利元素 | 多重扣减后，正数才能分派        |
| 管理人酌情权   | 管理人可额外分派资本性质金额                                 | 可提高分派但不强制              |

### 二、债务还清后分派能否恢复？

## 问题四：税费和法定公积金为什么能逐年下降？

### 法定公积金的运作机制

```
中国《公司法》第166条规定：
├── 公司分配当年税后利润时，应当提取10%列入法定公积金
├── 法定公积金累计额达注册资本50%以上时，可以不再提取
└── 如果以前年度有亏损，先用利润弥补亏损，再提取
```

### 汇贤REIT子公司的情况

| 项目           | 数据                                                    |
| -------------- | ------------------------------------------------------- |
| 子公司名称     | 北京东方广场有限公司（中外合作经营企业→已转为外商独资） |
| 注册资本       | 6亿美元（约42亿元人民币）                               |
| 法定公积金上限 | 注册资本的50% = 3亿美元（~21亿元人民币）                |
| 2025年提取金额 | ~7100万元人民币                                         |
| 开始提取年份   | 2025年（财资[2025]101号新规后）                         |

### 为什么法定公积金金额可以逐年下降？

| 原因                             | 说明                                                |
| -------------------------------- | --------------------------------------------------- |
| ① 提取基数是"税后利润"，不是收入 | 当子公司利润下降时，10%提取额自然下降               |
| ② 子公司可能存在累计亏损         | 如以前年度亏损未弥补完，先补亏再提取，基数更小      |
| ③ 达到注册资本50%后停止提取      | 累计达到21亿元后不再需要提取 → 约需20-30年          |
| ④ 多个子公司的利润不均           | 北京东方广场（高利润）vs 重庆/沈阳/成都（可能亏损） |
| ⑤ 酒店板块可能拉低整体利润       | 酒店运营成本，某些年份酒店子公司可能亏损→无需提取   |

### 法定公积金逐年下降的路径预测

| 年份  | 子公司税后利润（估） | 提取10% | 累计提取 | 距上限余额 | 说明                 |

| 2026  | ~6.5亿               | 6500万  | 1.36亿   | 19.6亿     | NPI下降              |
| 2027  | ~5.8亿               | 5800万  | 1.94亿   | 19.1亿     | 衰退期               |
| 2028  | ~5.2亿               | 5200万  | 2.46亿   | 18.5亿     | 最低点               |
| 2029  | ~5.5亿               | 5500万  | 3.01亿   | 18.0亿     | 复苏                 |
| 2030  | ~6.0亿               | 6000万  | 3.61亿   | 17.4亿     | 继续复苏             |

> ★ 关键结论：法定公积金约在2045-2050年达到上限后永久停止提取。但从信托契约扣减角度看，这笔钱并非消失——它留在子公司账上，只是不能分红。如果未来清算或股权转让，法定公积金对应的净资产仍属于信托。

### 税费为什么也能波动？

| 税种           | 计算方式                      | 为什么波动                   |
| -------------- | ----------------------------- | ---------------------------- |
| 房产税（从租） | 租金收入 × 12%                | 租金下降→房产税自然减少      |
| 房产税（从价） | 房产原值 × 70% × 1.2%         | 与租金无关，固定             |
| 增值税         | 租金收入 × 5%（简易征收）或9% | 租金下降→增值税减少          |
| 企业所得税     | 利润 × 25%                    | 利润下降→所得税减少          |
| 土地使用税     | 土地面积 × 单位税额           | 固定，不随收入波动           |
| 印花税         | 合同金额 × 0.1%               | 新签/续签合同减少→印花税减少 |

> ★ 税费下降的核心原因：房产税（从租部分）、增值税、所得税都与收入/利润挂钩。当租金和利润下滑时，这些税费自然同步下降——这是"收入下降的银边"。

## 六、核心投资风险深度分析

### 6.1 租金持续下滑风险（⭐⭐⭐⭐⭐ 最高优先级）

现状：

- 东方新天地零售租金从峰值1000元/㎡跌至559元/㎡（跌幅44%）
- 写字楼租金同步下滑
- 2025年租金收入仍在下滑

尚未见底的信号：

1. 北京写字楼空置率持续走高
2. 消费复苏缓慢，零售租金承压
3. 以价换量策略效果有限

对估值的影响：

- 若租金继续下滑10-20%，物业估值将进一步下调
- 公允价值变动损失可能继续产生（纸面亏损，但影响分派能力）

### 6.2 私有化风险（⭐⭐⭐⭐）

支持私有化的理由：

1. 市值极低：27.72亿港元 vs 单北京东方广场物业估值曾达314亿
2. 大股东有动机：长江实业持股35%，私有化成本相对较低
3. REITs架构限制：作为REIT，投资范围、借贷比率受监管限制，私有化后更灵活

反对私有化的理由：

1. 需解决小股东问题：需收购其余65%单位，按溢价20-30%计算需~36亿港元
2. 债务问题：私有化后需处理50亿债务
3. 政治敏感性：东方广场位于长安街1号，涉及外资控制敏感地段
4. 李嘉诚近年收缩内地投资：不太可能加大投入

结论：私有化有可能但未确认，需持续关注大股东动向。

### 6.3 管理层利益冲突风险（⭐⭐⭐）

管理费结构：

```
基本费用：物业价值0.3%/年
浮动费用：物业收入净额3%（东方广场为2%）

合计：年收管理费约1亿港元
```

利益冲突点：

1. 管理人（长江实业系）无论业绩好坏都收取固定费用
2. 2014年重庆大都会收购被质疑为高估资产向大股东输送利益
3. 小股东对管理层信任度低，多次分派政策修订被质疑为有利于管理人

### 6.4 港元汇兑持续出血风险（⭐⭐⭐）

如前所述，每年汇兑亏损约1.5-2.0亿港元。虽然人民币贷款占比提升将缓解此风险，但仍是长期隐忧。

### 6.5 2049年合作期限届满风险（⭐⭐）

北京东方广场的合作经营期限为50年（至2049年届满）。

潜在影响：

- 距离期限届满还有23年，短期无忧
- 但若租金长期低迷，剩余年限内能否收回投资存在疑问
- 期限届满后能否续期存在不确定性（政治因素）







## 八、核心结论与风险提示

### 8.1 核心结论

1. 严重低估但有明显缺陷：PB仅0.13，FCF/EV达17.2%，但分派能力崩溃，不符合传统REIT投资者的收益预期。

2. Waiting Game（等待游戏）：当前投资汇贤产业信托的核心是等待租金企稳。在租金明确见底前，任何买入都是"接飞刀"。

3. 债务改善是亮点：从108亿降至50亿，人民币贷款占比提升，汇兑风险缓解，管理层的这一操作值得肯定。

4. 私有化是期权：当前市值27.72亿，若长实发起私有化，可能存在30-50%的事件驱动收益，但不能以此为主要买入理由。

### 8.2 风险提示

1. 租金持续下滑：最核心风险，若租金未见底，估值将继续承压。
2. 港元汇兑亏损：仍有约50%债务为港元计价，人民币贬值将持续产生亏损。
3. 管理人利益冲突：小股东对管理层信任度低，治理风险长期存在。
4. 政策风险：跨境资金流动政策可能进一步收紧。
5. 2049年期限届满：长期不确定性。

### 8.3 适合什么类型的投资者？

- ✅ 烟蒂股猎手：能忍受短期无分红，等待价值回归
- ✅ 事件驱动投资者：博弈私有化或REITs政策变化
- ✅ 长期价值投资者：能持有3-5年，等待租金周期反转
- ❌ 收益型投资者：当前分派几乎为零，不适合需求稳定现金流的投资者
- ❌ 短期交易者：租金未见底前，股价可能继续承压
