汇贤产业信托（87001.HK，首只人民币计价REIT，长和系/李嘉诚旗下）的情况，本质上是**"资产很硬、报表很稳，但股价几乎与基本面脱钩"**。以下基于其2025年年度业绩及最新公告整理。

## 资产负债表：其实相当健康

| 项目                              | 数据（2025年末，人民币）   |
| --------------------------------- | -------------------------- |
| 基金单位持有人应占资产净值（NAV） | 207.03亿元                 |
| 每单位NAV                         | 3.1737元                   |
| 总债务                            | 50.38亿元                  |
| 杠杆率                            | 15.4%                      |
| 2025年利息支出                    | 2.4亿元（较2024年减少1亿） |
| 币种结构                          | 人民币借款52% / 港元48%    |

资产端是北京东方广场（商场、写字楼、服务式公寓、北京东方君悦酒店）、重庆大都会、沈阳索菲特、成都酒店等四城核心地段物业，总面积超110万平方米。

负债表本身没什么毛病：五年间总债务从108.71亿压降到50.38亿（降53.7%），杠杆率仅15.4%，在REIT里属于极低水平，安全垫很厚。问题**不在资产负债表的健康度，而在它产生现金分派的能力，以及现金被什么吃掉了**。

## 为什么这么低估

现价约0.50港元，对应每单位NAV约3.17元人民币（≈3.4港元），**折让约85%**——市场只给资产净值打了一折多。原因可以拆成四层：

**1. 致命的币种错配 + 完全不做对冲。** 这是核心。收入100%是内地物业的人民币现金流，但历史上银行借款几乎100%是港元。过去两年人民币兑港元持续贬值，每偿还一笔港元旧贷，就一次性确认一笔已实现汇兑亏损：2024年5月亏1.59亿、2024年11月亏2.09亿、2025年1月亏0.77亿、2025年6月亏0.79亿、2026年4月又亏0.44亿。年报白纸黑字写着"并无进行任何货币对冲"。对一个数十亿港元负债、收入全为人民币的跨境REIT来说，这是机制性、可预见却未规避的风险。

**2. 分派被打穿，"稳定现金流信仰"崩塌。** REIT的估值锚是分派。2025年全年可供分派仅2800万元，每单位分派0.0043元（中期更只有0.0016元，同比近乎腰斩）。按现价算分派收益率不足1%。更刺眼的是，2026年4月那笔4400万汇兑亏损，相当于2025年全年可分派额的157%——一次还债亏掉的钱比基金一整年能分的还多57%，等于直接吞掉2026年上半年的分派。当非经营性亏损能反复击穿半年分派，市场就不再把它当"收息工具"定价。

**3. 主业处于下行周期，太薄扛不住冲击。** 2025年总收益22.09亿元，同比降1.28亿；零售物业收入净额降1.1亿、写字楼降0.59亿，内地商办+零售租金仍在调整。唯一增长的是酒店（收入净额1.04亿，+19.6%，受入境游复苏带动），但体量不足以覆盖整体下滑。经营现金流本就偏紧，再叠加汇兑冲击，捉襟见肘。

**4. 结构性折价因素。** 跨境内地商业地产敞口、人民币资产在港股估值长期受压、成交量低流动性差、市场对内地写字楼/零售前景悲观，以及对管理人风控的信任折价，叠加在一起放大了折让。

## 怎么看

折价巨大但**不是没有理由**——它精确反映了"分派极低 + 风险反复爆发"。真正决定价值能否修复的，是三件管理人完全可控的事：剩余港元贷款分批择期偿还避免集中兑损、尽快建立汇率对冲、继续用人民币贷款置换港元。积极信号是旧港元贷款在陆续出清、人民币负债已过半，最痛的阶段或在过去；但在结构调整完成前，持有人仍要承担分派承压的阵痛。

简言之：**资产打一折多，是真便宜；但便宜的对价是看不到稳定分派、且要继续承受汇兑出清的不确定性。** 这是典型的"深度价值 vs 价值陷阱"之争，取决于你是否相信管理人能补上风控这一课。

它不是永久产权——这是理解它估值的一个关键点。

汇贤的物业都在内地,中国没有永久地权,持有的是**有期限的土地使用权**,到期后资产归还。最核心的一点:

**旗舰资产北京东方广场,土地使用权/合作经营期到2049年结束**,届时整个东方广场要归还内地合作方。东方广场是汇贤的绝对主力(占总估值约七成以上),所以以2026年算,它最值钱的资产只剩**约23年**寿命。

其余物业按内地通行年限:商业/写字楼用地一般40–50年、酒店用地50年。重庆大都会广场、沈阳丽都索菲特、成都酒店各有自己的出让年期(普遍是40–50年的商业综合用地),年报里逐项列示,但具体到期年份没有东方广场这么广为披露。

这对估值的含义很重要,也补上了之前"为什么折让这么大"的一块拼图:

汇贤的207亿NAV是建立在**会随时间归零的土地使用权**上,本质是一项"递减/有寿命的资产"——不像永久产权的房子可以世代持有。2049年东方广场一到期,这部分账面价值理论上清零。所以市场不愿意按NAV给它定价,而是更看重它**在剩余年限里每年能分多少现金**。偏偏它现在每年能分的现金又被汇兑亏损吃得所剩无几(2025年仅2800万)——一个会到期的资产、又分不出钱,两头叠加,这就是它股价只有NAV一折多的深层逻辑。

换句话说:对这类有期限地权的REIT,真正该算的不是"打几折买资产",而是"在到期前能收回多少分派",这也是它和永久产权REIT估值逻辑根本不同的地方。

## 为什么物业收入净额和可供分派额不一样

因为NPI只是"楼这一层赚的钱",而可供分派额是把楼以上所有开支和损益都扣干净之后、真正能拿去分的钱。中间隔着好几道。

物业收入净额(NPI)=租金等物业收入 − 物业层面的营运开支(物管、维修、物业税等)。它衡量的是"物业本身的盈利能力",还没碰到基金层面的成本。

从NPI往下到可供分派额,要再依次处理这些项目:

- **减 利息支出**(基金层面的债务成本)
- **减 管理人费用、信托及其他行政开支**
- **减 税**(中国预提税/企业所得税等)
- **加/减 已实现汇兑损益**(偿还港元贷款时确认的汇兑盈亏)
- **加/减 资本性质项目调整**,其中关键是"可供分派之折旧"

用2025年的实际数字串一遍就很直观:

| 步骤                   | 金额(人民币) |
| ---------------------- | ------------ |
| 物业收入净额 NPI       | 11.46亿      |
| 减：利息、管理费、税等 | 约 −9亿      |
| 减：已实现汇兑亏损     | −1.56亿      |
| **= 可供分派额**       | **0.28亿**   |

所以11.46亿到0.28亿之间蒸发的约11亿,大头是利息和各项费用,再被汇兑亏损补了一刀。

还有一个汇贤**特有**的结构性原因,解释了为什么这个差距在2020年后突然拉大:过去年报里,"可供分派之折旧"(一笔非现金的折旧金额,可以汇出中国、提前归还外方股东投资成本)是计入可供分派额并分给持有人的——这等于让分派额一度高于纯租金现金。但2020年1月生效的《外商投资法》取消了用折旧方式汇出的条文,这笔钱汇不到香港、只能留在内地项目公司,可供分派额因此被结构性砍掉一大块。叠加2023年起的汇兑亏损,可分派额才会从十几亿崩到几千万,而NPI还有十几亿。

一句话:**NPI看的是"资产会不会赚钱"(答案是会),可供分派额看的是"扣完利息、税、汇兑和监管限制后还剩多少能分"(答案是几乎不剩)。** 二者背离,正是这只REIT的核心症结。

## 外商投资法和发布《关于公司法、外商投资法施行后有关财务处理问题的通知》（财资〔2025〕101号）法案，对汇贤影响多大

这是个很具体的新规,我需要先查证财资〔2025〕101号的内容和发布情况,再判断对汇贤的影响。我查到了这份通知(财政部财资〔2025〕101号,2025年6月25日发布)。先确认一下汇贤是否专门提及它,再给你影响判断。查证清楚了。先说结论:**这份通知对汇贤是边际、偏中性略正面的影响,但它并不能解决汇贤分派崩塌的核心病根,谈不上"利好"量级。** 下面拆开讲。

**财资〔2025〕101号到底管什么**

它是2025年6月财政部为"外商投资法五年过渡期(2020.1.1–2024.12.31)结束、外资企业全面转为《公司法》体制"而出的财务处理细则,核心三件事:

第一,**取消"三项基金"**(储备基金、企业发展基金、职工奖励及福利基金)。外资企业从2025年1月1日起不再计提,存量余额转为《公司法》下的法定公积金/任意公积金。

第二,**允许用资本公积弥补亏损**(在盈余公积仍不足弥补时,可动用资本公积)。

第三,接受非货币资产出资需评估等程序性规定。

**和汇贤什么关系**

汇贤的内地项目公司——北京东方广场公司、沈阳丽都、成都长天等——大多是**中外合作经营企业(CJV)**,正好是这次过渡和101号的适用对象。两个潜在传导点:

1. **取消三项基金 → 强制留存减少**。过去CJV分配利润前要先提储备基金、企业发展基金;现在改按《公司法》只提10%法定公积金(累计达注册资本50%即可停提),任意公积金可不提。理论上**释放出更多可上分的利润**,对可供分派额是个小的正面。
2. **资本公积弥补亏损 → 可能加快恢复分配**。这是相对更实在的一点。汇贤部分项目公司这几年因汇兑、资产重估下调、2020年酒店亏损等累积了亏损;按常规要等未来利润把亏损补平才能分红。若能动用资本公积一次性冲销累计亏损,项目公司就能**更早恢复向上分配利润**,从而让更多现金回到香港、抬高基金层面的可供分派额。

**但它修不了真正的病根**

汇贤可供分派额从2019年约13亿塌到现在不足1亿,主因有三,**101号一个都没解决**:

- **折旧分派被取消**:这才是2020年那一刀。旧CJV模式允许外方"以折旧方式提前回收投资"并汇出、计入可分派;外商投资法取消了这一条文。101号讲的是"三项基金"和资本公积,**完全没有重新恢复折旧式投资回收分派**——这笔最大的结构性损失依旧。
- **汇兑亏损**:港元负债、无对冲,与本通知无关。
- **租金下行 + 2049年地权到期**:更与之无关。

**影响量级判断**

偏小、最多算"边际改善":它优化的是利润上分的**机制性障碍**(少留存、能冲亏损),对应的可能是每年几千万级别的潜在改善空间,且高度取决于各项目公司具体的资本公积和累计亏损余额——这些数据未公开,所以连这点正面也无法量化坐实。相比之下,真正压制汇贤的折旧规则、汇兑和租金问题,体量是以亿计的,且不在这份通知的射程内。

所以,**别把101号当成汇贤的反转催化剂**。它顶多是过渡期收尾时一个轻微利好的技术性安排,改变不了"资产硬、却分不出钱"的基本格局。汇贤能否真正受益、受益多少,要看它后续年报/中报里是否专门披露——目前公司尚无相关具体说明,值得后续跟踪。
