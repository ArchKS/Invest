## 第二部分：管理层费用深度分析

### 一、费用结构（信托契约约定）

| 费用类型 | 计算公式 | 2025年估算金额 | 占比 |
|---------|---------|---------------|------|
| **基本费用** | 物业总价值(GAV) × **0.3%** | ~5100万元/半年 ≈ **1亿/年** | ~63% |
| **浮动费用** | 物业收入净额(NPI) × **3%** | ~700万元/半年 ≈ **1400万/年** | ~17% |
| **物业管理人费用** | 东方广场NPI × **2%** | — | ~20% |
| **年度管理费合计** | — | **约1.1-1.2亿元** | 100% |

### 二、历年管理人费用变化趋势

通过整理港交所历次付息公告，可还原以下费用轨迹：

| 财政期间 | 基本费用（万元） | 浮动费用（万元） | 合计（万元） | 支付方式 |
|---------|----------------|----------------|------------|---------|

| **2021H1** | 5503.69 | — | — | 同上 |
| **2021H2** | 5594.92 | 847.30 | **6442** | 同上 |
| **2022H2** | 5594.92 | — | — | 同上 |
| **2023H1** | 5382.33 | — | — | 同上 |
| **2023H2** | 5159.23 | 700.58 | **5860** | 同上（退回339万调整）|
| **2024H2** | ~5100 | ~700 | **5800** | 同上 |

### 三、费用变化的关键发现

#### 📉 **基本费用呈下降趋势**

| 对比期 | 基本费用变化 | 原因 |
|-------|------------|------|
| 2021H2 → 2023H2 | 5595万 → 5159万 | **-7.8%** |
| **原因** | 物业估值下调导致GAV降低 → 按0.3%计算的基本费相应减少 | 公允价值减值传导 |

#### 📉 **浮动费用大幅下降**

| 对比期 | 浮动费用变化 | 原因 |
|-------|------------|------|
| 2021H2(847万) → 2023H2(701万) | **-17.3%** | NPI下降导致按3%计算的浮动费减少 |

#### 💡 **核心结论**

1. **费用总额在下降**：从2021年的~1.3亿/年降至2023年的~1.16亿/年（两年降约10%）
2. **下降原因是被动而非主动**：费用减少完全是因为物业估值下降和收入下滑，**不是管理人主动降费**
3. **"资产值税"本质**：基本费用与物业估值挂钩（0.3% of GAV），无论盈亏都照收不误，被投资者批评为"资产值税"
4. **支付方式稀释股权**：70%的费用以发行基金单位形式支付，意味着**管理人持股比例逐年上升**（从最初的~0.7%升至当前的~1.8%）
5. **与其他REITs对比**：领展等优质REIT的管理费通常在0.1-0.2%且与业绩挂钩更紧密；汇贤的0.3%+3%双重收费模式偏贵

## 第三部分：信托契约经典版本整理

### A组：初始信托契约基础条款（2011年4月1日生效）

> 这是汇贤产业信托上市时的"宪法性文件"，规定了REIT运作的根本规则。

#### A1. 分派政策（最核心条款）

**原始公式（第11.4.2条）**：

```
实际分派金额 = (分派比例 × 可供分派收入) + 管理人厘定的额外金额 - 当期已分派金额
```

其中各项原始定义：

| 项目 | 2011年原始定义 |
|------|--------------|
| **分派比例** | **固定不低于90%** |
| **可供分派收入** = | 除税后纯利 + 调整因素 |
| **调整因素（加回项）** | 全部折旧及摊销（无条件全额加回） |
| **额外金额** | 管理人酌情决定是否分派的资本性质金额 |

#### A2. 投资范围限制

| 限制类别 | 2011年原始规定 |
|---------|---------------|
| **地域限制** | 仅限中国境内商用物业 |
| **借贷上限** | 总资产值的45% |
| **物业发展投资** | 不允许 |
| **金融工具投资** | 不允许 |
| **单一地区集中度** | 无明确限制 |

#### A3. 管理人费用结构

| 费用类型 | 2011年原始规定 |
|---------|---------------|
| **基本费用** | 物业总价值的0.3%/年 |
| **浮动费用** | 物业收入净额的3%/年 |
| **物业管理人费用** | 包含在上述费用中或另行约定 |
| **支付频率** | 每季度支付一次 |

#### A4. 其他重要基础条款

| 条款类别 | 内容摘要 |
|---------|---------|
| **功能货币** | 人民币（全球首只人民币计价港股REIT） |
| **报告货币** | 人民币 |
| **基金单位类别** | 单一类（人民币计价） |
| **上市地点** | 香港联交所主板 |
| **持有人大会** | 至少每年一次，审批重大事项需特别决议案（75%以上赞成） |
| **回购机制** | 管理人可在市场上回购基金单位（需授权） |
| **关联交易限制** | 与关联方的交易需独立董事批准 |

### B组：历次修订变更情况一览

> 2011年至今共经历**7次修订**，以下按影响程度排序。

#### B1. 第一次重大修订（2013年5月24日生效）— ⚠️⚠️⚠️ 最关键

| 项目 | 修订内容 |
|------|---------|
| **触发背景** | 中国法律环境变化，外资企业折旧资金汇出路径受限 |
| **核心修订** | 引入**"可分配折旧及摊销"**概念，替代原有的"全部折旧及摊销" |
| **新旧差异** | |
| ~~旧~~ | 全部折旧及摊销无条件加回到可分派收入 |
| **新** | 仅当中国法律允许调回香港的部分才能加回（需扣除用于还贷和资本开支后） |
| **对分派的直接影响** | **年度可分派收入显著减少**，估计每年减少约2-3亿元 |
| **投票结果** | 通过（但小股东有争议）|

#### B2. 第二次重大修订（2025年12月18日生效）— ⚠️⚠️ 最新冲击

| 项目 | 修订内容 |
|------|---------|
| **触发背景** | 《外商投资法》实施后，内地子公司统一适用《公司法》，需提取法定公积金 |
| **核心修订** | 在"调整"定义中新增：将按《公司法》提取的**法定公积金（税后利润10%）**予以撇除 |
| **对分派的直接影响** | **2025年起每年减少可分派约7100万元人民币** |
| **投票结果** | 2025年12月11日通过 |

#### B3. 其他5次次要修订汇总表

| 时间 | 主要内容 | 对分派影响 | 性质 |
|------|---------|-----------|------|
| **2014年5月16日** | ①取消地域限制（扩展至全球）；②分派比例从"≥90%"改为"90%-100%"区间 | 中性（增加灵活性） | 配合业务拓展 |

### 二、站在李嘉诚角度：为什么要设立这个REIT？

#### 动机一：⏰ 时机精准——"高点套现"

| 分析维度 | 详情 |
|---------|------|
| **时间窗口** | 2011年正值人民币升值预期强烈 + 内地房地产泡沫初现 |
| **东方广场状态** | 运营成熟，现金流充沛，年租金数十亿 |
| **套现规模** | IPO一次性套现53.8亿 + 后续资产注入再套现9.8亿 = **63.6亿** |
| **保留权益** | 仍持有51.3%（33.4%+17.9%），继续享受增值收益 |
| **本质操作** | **"部分退出+保留控制权"**——典型的李嘉诚式套现哲学 |

> **类比理解**：这就像你有一栋每年收租500万的楼，你把它打包成REIT卖给公众，自己拿回了3000万现金，同时还保留51%的控制权继续收租分红。

#### 动机二：🔄 资产周转加速——"低买高卖循环"

李嘉诚的商业哲学核心之一是**"资产周转"**：

```
传统地产开发模式：
买地 → 建设 → 出售/出租 → 回笼资金 → 再投资
（周期长、资金沉淀重）

李嘉诚的REIT化创新模式：
持有优质物业 → 打包成REIT上市 → 大额套现 → 投资更高回报领域
                ↓
         仍保留控制权和后续增值收益
```

具体到东方广场案例：
1. **1993-1999年**：投入15亿美元建设（"低买"阶段）
2. **2000-2010年**：享受10年租金红利（"培育"阶段）
3. **2011年REIT化**：高点套现53.8亿（"高卖"阶段）
4. **套现后的资金投向**：欧洲电信基建、港口、能源等更高回报资产

#### 动机三：🛡️ 风险分散——"鸡蛋不放一个篮子"

| 风险维度 | REIT化的作用 |
|---------|------------|
| **政策风险** | 将内地物业权益部分转让给公众投资者，降低单一项目集中风险 |
| **汇率风险** | REIT以人民币计价但港股交易，自然形成对冲 |
| **流动性风险** | 非流动的房地产变为可交易的证券 |
| **周期风险** | 如果内地商业地产见顶回落，已提前锁定部分收益 |

#### 动机四：📐 结构设计精妙——"控制权最大化"

李嘉诚团队在汇贤REIT的结构设计中体现了极高的财技水平：

```
控制链路：
李嘉诚（个人）
  → 长江实业（33.4%股东）
  → 和记黄埔（17.9%股东）
  → 合计控制汇贤REIT 51.3%
    → 控制北京东方广场（核心资产）

同时：
  • 管理人是长江实业附属公司（每年收取~1.2亿管理费）
  • 物业管理人也是关联方（收取物业管理费）
  • 后续资产注入（重庆大都会39.1亿）也是向自己买
```

> **一句话总结**：李嘉诚既是**大股东**（收分红）、又是**管理人**（收管理费）、还是**卖家**（资产注入时收对价）。**"一鱼三吃"**的设计堪称经典。

#### 动机五：🎯 人民币国际化布局——抢占先机

| 战略意义 | 详情 |
|---------|------|
| **历史地位** | 香港首只人民币计价证券，开创先河 |
| **时机把握** | 2011年恰逢人民币国际化启动元年 |
| **政治信号** | 向中国政府展示对人民币的信心 |
| **实际利益** | 人民币升值预期下，以人民币计价的REIT对外资有吸引力 |

### 三、事后诸葛亮：REIT化成功了吗？

| 维度 | 评价 |
|------|------|
| **对李嘉诚而言** | ✅ **非常成功**——提前套现63.6亿，保留了51%控制权，成功转移了大部分下行风险 |
| **对小股东而言** | ❌ **相当惨痛**——IPO认购者若持有至今，亏损约90%；即使2019年买入也亏了87% |
| **对REIT本身而言** | ⚠️ **结构性困境**——受政策打击（外商投资法）+ 行业周期（租金下行）双重夹击 |
| **对中国资本市场而言** | ✅ **有探索价值**——为内地公募REITs（2021年启动）提供了宝贵经验 |
