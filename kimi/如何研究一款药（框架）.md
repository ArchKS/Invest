# 如何研究一款药：完整框架

## 〇、总原则

你缺的不是信息量，而是一个**独立于任何单一标的的维度生成器**。

博主从 100 个候选论点里挑 3 个，偏见藏在"挑选"这一步。
你顺着他的 3 个论点走，永远只能验证他的结论，无法生成自己的。
解法：用一张固定的清单**自己生成**候选论点，再去看别人挑了哪几个、漏了哪几个、漏掉的是不是致命的。

---

## 一、五层维度清单（候选论点生成器）

每一格都是一组问题。100 个论点 = 5 层 × 每层 20 个问题，不是从信息流里捞出来的。

### L1 需求层（这个病值不值得治、值不值得花钱治）
1. 流行病学：发病率/患病率、中美差异、患者漏斗（确诊→可治疗→可支付）
2. 未满足需求：现有 SoC 的效应量是多少？痛点在疗效、安全性还是便利性？
3. 终点与真实获益的相关性：PFS 改善在这个适应症里能否转化为 OS/生活质量？
4. 对照组质量：对照是不是当前最强 SoC？（弱对照 = 虚高的 HR）
5. 未来 SoC：数据读出时，标准疗法会不会已经换代？（"打败昨天的 K药"陷阱）

### L2 药物层（这个分子本身）
1. 靶点验证度：这个靶点的生物学是被人体数据验证过的，还是只有临床前证据？
2. 类效应史：同靶点/同机制的所有资产，历史上成了几个、败了几个、败因是什么？（基率）
3. 分子设计：结构、选择性、半衰期、off-target——与同类分子的差异是**分子级的**还是**给药方案级的**？（方案优势可被模仿，分子优势不可）
4. 治疗窗：疗效剂量与毒性剂量之间的距离。治疗窗决定**联用天花板**，联用天花板决定适应症扩张能力。
5. 剂量合理性：III 期剂量是否经过 II 期随机剂量探索优化？（大量 III 期失败本质是剂量失败）
6. 耐药谱：耐药的分子机制是什么？耐药模式暴露机制的边界。

### L3 证据层（临床数据怎么读）
1. 效应量：HR/ORR/CR 的绝对水平，以及与历史基线比是否异常（"好得不真实"是危险信号）
2. **跨场景一致性**（核心，见第二节矩阵）：同一药物在不同适应症/线数/人群/地区，效应量是否稳定？
3. 数据成熟度：事件数、中位随访、曲线是否还在分离/收敛
4. 亚组裂缝：哪个亚组**不**获益？裂缝处就是机制的边界
5. 安全性：≥3 级 AE、停药率、剂量中断率、特殊毒性（TLS、irAE、出血）——安全不是附属项，是联用和扩适应症的前置条件
6. 评估独立性：BICR 还是研究者评估？开放标签还是双盲？
7. 统计结构：α 分配、多重性校正、中期分析消耗了多少 α、样本量是否事件驱动
8. 人群外推：中国数据→全球、亚裔→白人，有没有已知的 PK/疗效人种差异

### L4 外部层（药好不等于卖得好）
1. 竞争时间窗：数据读出时、获批时、放量时，三个时点的竞争格局分别是什么？
2. 专利：化合物专利到期、制剂/晶型专利、专利悬崖与管线衔接
3. 监管路径：各国审评口径差异（FDA 对单国数据的接受度、人种外推要求）、突破性疗法/优先审评资格
4. 支付方：医保/商保谈判降价幅度、放量弹性、适应症拓展对续约价的影响
5. 商业化执行：销售团队、准入能力、与 MNC 合作的条款质量（里程碑结构暴露对方信心）

### L5 公司层（药好不等于股票好）
1. 管理层：过往指引兑现率（你已对标再鼎做过）、管线取舍记录、融资纪律
2. 治理：股权结构、关联交易、激励与股东利益一致性
3. 财务：现金跑道 = 现金 / 年净消耗，覆盖到下一个里程碑吗？稀释节奏？
4. 组合逻辑：管线之间是协同（共享机制/共享渠道）还是拼盘？
5. 估值：当前市值隐含了几条管线的成功？每条管线的成功概率 × 峰值销售 × 倍数，倒推市场定价的预期

## 二、效应量一致性矩阵（"More is Different"的实操形态）

**不要评判单个 III 期。评判一个药物跨试验涌现出的模式。**

一款药的真实特性，体现在效应量矩阵的"形状"上：

| | 适应症A 一线 | 适应症A 后线 | 适应症B | 适应症C | … |
|---|---|---|---|---|---|
| ORR/CR vs SoC | | | | | |
| PFS HR | | | | | |
| OS HR | | | | | |
| ≥3级AE增量 | | | | | |
| 特征毒性 | | | | | |

判读规则：
- **伟大的药**：整列稳定。K药在十几个瘤种里 HR 稳定落在 0.6–0.8，这才是平台。
- **幸运的药**：只有一个热点格子。单个适应症亮眼、其余平庸 → 第一个胜利大概率吃了"富集人群"或"低门槛对照"的红利。
- **一致性的方向比数值更重要**：如果二线有效、一线反而无效，或者中国有效、全球无效，必须给出机制层面的解释，给不出就降权。
- 矩阵里**空的格子**就是你的研究缺口清单——这比刷帖子更能告诉你"还欠什么"。

立即行动：用 Z) 数据库里已有的数据，为利沙托克拉和依沃西各填一张矩阵。2575 目前已有 CLL/AML/MDS/MM 四个适应症的散点数据，依沃西有 2 个 III 期 + 多个 II 期，都够填出雏形。

## 三、药物特性不可直接观察，只能从五种"差异化数据"反推

1. **头对头试验**——最硬的证据。HARMONi-2 头对头 K药就是这个级别，全中国没几个资产有。
2. **同对照跨药比较**——不同药物打同一个 SoC，对照组数据互相校准后间接比较。
3. **亚组裂缝**——哪里无效，机制的边界就在哪里。例如 venetoclax 在 del(17p)/IGHV 未突变亚组的效应量变化。
4. **耐药谱**——耐药的分子形式告诉你药物压住了哪条通路、放过了哪条。
5. **同类差异归因**——2575 对 venetoclax 的安全性优势（TLS≈0、60天死亡率0），要追问：这是分子级差异（半衰期短、无需剂量爬坡）还是方案级差异？方案级优势竞品可以抄，分子级抄不走——这直接决定优势的持久性。

## 四、论点台账（替代"顺博主结论"的工具）

每一条你持有的信念，登记为一行：

| 字段 | 内容 |
|---|---|
| 主张 | 例：GLORA-4 大概率成功 |
| 证据 | 机制链条 + 早期数据 + 竞品对照 |
| 基率 | 同类/同阶段试验的历史成功率 |
| 最强反方论证 | 自己写，必须比任何博主写得都狠 |
| 证伪条件 | 出现什么数据/事件，我就认错 |
| 复核日期 | 下次数据读出日 |

规则：
- **先写自己的判断，再看别人的**。顺序反了，你的"独立判断"就不存在。
- 维护一份**分歧清单**：我在哪几点上和市场共识不一致、为什么。没有分歧清单，你的收益来源就是模糊的。
- 预测要打分（你已经在做 HARMONi-3 预测，很好）：每次预测记录概率，事后算校准度。判断力的唯一训练方式是可追溯的预测记录。

## 五、文件夹结构建议

现有结构按"标的"分，导致跨标的的共性知识（类效应、失败案例、统计方法）散落。建议按**变化速度**分层：

```
L0 通识（不变）      生物/  知识/
L1 行业与类效应（慢变） 以史为鉴/  疾病/  ← 每个重点靶点建一份"类效应史"档案
L2 公司（中变）      亚盛/  康方/
    ├─ 1) 概览
    ├─ 2) 3) 分资产档案（用第一节清单做固定模板）
    ├─ 4) 事件与催化剂
    └─ 论点台账.md   ← 新增，每公司一份
L3 决策与复盘（快变）  预测记录、事后复盘、校准评分
```

O) 开头的摘录文件：建议每份摘录末尾加三行——"我同意什么 / 我反对什么 / 他没有回答什么"。摘录不经过这三问，就只是收藏。
