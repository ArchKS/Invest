# JNJ 双抗

| 药物                    | 双抗靶点       | 主要区别                            |
| ----------------------- | -------------- | ----------------------------------- |
| Tecvayli（teclistamab） | **BCMA×CD3**   | 引导T细胞攻击表达BCMA的骨髓瘤细胞   |
| Talvey（talquetamab）   | **GPRC5D×CD3** | 引导T细胞攻击表达GPRC5D的骨髓瘤细胞 |

Talvey目前用于什么患者

美国FDA批准的适应证是：

- 复发/难治性多发性骨髓瘤
- 已经接受至少四线治疗
- 既往治疗包括蛋白酶体抑制剂、免疫调节剂和抗CD38单抗

它是皮下注射治疗，需要先进行阶梯加量：

- 0.4 mg/kg：每周一次
- 或0.8 mg/kg：每两周一次

目前仍属于加速批准，确认性Ⅲ期研究正在推进。

支持批准的MonumenTAL-1研究属于单臂Ⅰ/Ⅱ期研究：

| 给药方案            | ORR   | 中位缓解持续时间 |
| ------------------- | ----- | ---------------- |
| 0.4 mg/kg每周一次   | 73.0% | 9.5个月          |
| 0.8 mg/kg每两周一次 | 73.6% | 当时尚未达到     |

这些患者多数经过至少四线治疗，因此约73%的ORR具有临床意义；但这不是随机Ⅲ期结果，证据成熟度暂时低于teclistamab最新的Ⅲ期数据。

Talvey也会发生双抗常见风险：

- 细胞因子释放综合征（CRS）
- 血细胞减少
- 感染
- 少见ICANS神经毒性

但它还有一组非常有辨识度的 **GPRC5D靶点相关毒性**：

- 味觉减退或味觉改变
- 口干、吞咽不适
- 食欲下降和体重下降
- 皮疹、皮肤干燥
- 指甲改变、脱落或变脆

原因是GPRC5D不仅存在于骨髓瘤细胞，也在皮肤、毛囊、指甲和舌部角化组织表达。部分患者的味觉和体重问题会明显影响生活质量

与Tecvayli相比

- **疗效证据**：目前Tecvayli更强，已有两个随机Ⅲ期研究显示PFS和OS获益；Talvey的成熟Ⅲ期结果尚未完全建立。
- **感染风险**：Talvey通常不像BCMA双抗那样明显压低正常浆细胞和免疫球蛋白，严重感染负担可能相对低一些。
- **生活质量毒性**：Talvey的味觉、口腔、皮肤、指甲和体重问题更突出。
- **序贯价值**：由于靶点不同，Talvey在BCMA CAR-T或BCMA双抗治疗后仍可能有效，是它的重要优势。
- **生物标志物**：不像Sonrotoclax主要针对t(11;14)，Talvey通常不要求特定染色体易位。

一句话概括：**Tecvayli目前证据更成熟、疗效更确定；Talvey最大的价值是避开BCMA，适合BCMA治疗后或需要不同靶点的患者，但要重点防范味觉、口腔和体重下降。**



## 对照组DPd或DVd是什么

| 方案    | 组成                                     | 药物类型                         |
| ------- | ---------------------------------------- | -------------------------------- |
| **DPd** | Daratumumab＋Pomalidomide＋dexamethasone | 达雷妥尤单抗＋泊马度胺＋地塞米松 |
| **DVd** | Daratumumab＋Bortezomib＋dexamethasone   | 达雷妥尤单抗＋硼替佐米＋地塞米松 |
| **PVd** | Pomalidomide＋Bortezomib＋dexamethasone  | 泊马度胺＋硼替佐米＋地塞米松     |
| **Kd**  | Carfilzomib＋dexamethasone               | 卡非佐米＋地塞米松               |

具体来说：

- **Daratumumab（D）**：抗CD38单克隆抗体，直接和通过免疫系统清除骨髓瘤细胞。
- **Pomalidomide（P）**：泊马度胺，免疫调节剂，常用于来那度胺治疗后复发。
- **Bortezomib（V）**：硼替佐米，蛋白酶体抑制剂；“V”来自其早期名称Velcade。
- **dexamethasone（d）**：地塞米松，糖皮质激素，具有抗骨髓瘤作用，也能降低部分输注或免疫反应。
- **Kyprolis（K）**：卡非佐米，第二代蛋白酶体抑制剂

需要注意：MajesTEC-3只有约5%的患者既往接受过抗CD38治疗。因此DPd/DVd在该研究中是合理且有效的对照，但对于目前一线已经普遍使用daratumumab、尤其已经对daratumumab耐药的患者，其代表性有限。

**PVd更适合：**

- 来那度胺治疗后复发，但泊马度胺仍可能有效
- 可以接受硼替佐米皮下注射
- 没有明显周围神经病变

主要风险是血细胞减少、感染，以及硼替佐米相关的周围神经病变和带状疱疹再激活。

**Kd更适合：**

- 对免疫调节剂耐药或不耐受
- 希望避免泊马度胺
- 既往硼替佐米效果不佳或有明显神经毒性

卡非佐米的神经毒性通常比硼替佐米少，但需要注意高血压、心功能不全、缺血事件、呼吸困难和肾功能影响。





## Teclistamab

**MajesTEC-3**：teclistamab＋daratumumab，主要支持二线及以后联合治疗

**MajesTEC-9**：teclistamab单药，主要验证既往接受过抗CD38和来那度胺患者的二线及以后治疗







MajesTEC-3：Tec＋Dara联合治疗



### 研究设计与入组患者

- 研究编号：[NCT05083169](https://clinicaltrials.gov/study/NCT05083169)
- 全球、开放标签、随机Ⅲ期研究
- 共随机入组 **587人**
  - teclistamab＋daratumumab：291人
  - 对照组DPd或DVd：296人
- 既往接受 **1–3线治疗**
- 必须既往接受过：
  - 来那度胺
  - 蛋白酶体抑制剂
- 接受过一线治疗者必须对来那度胺耐药
- ECOG一般为0–2
- 未接受过BCMA靶向治疗

主要患者特征：

| 特征               | 总体              |
| ------------------ | ----------------- |
| 中位年龄           | 64岁，范围25–88岁 |
| ≥75岁              | 10%               |
| 男性               | 55%               |
| 亚洲患者           | 22%               |
| 中位既往治疗线数   | 2线               |
| 仅接受过1线        | 38%               |
| 来那度胺暴露       | 100%              |
| 来那度胺耐药       | 84%               |
| 蛋白酶体抑制剂暴露 | 99.8%             |
| 既往自体移植       | 74%               |
| 高危细胞遗传学     | 35%               |
| 髓外病变           | 约5%              |
| 既往抗CD38治疗     | 仅约5%            |

最后一项非常重要：**MajesTEC-3中绝大多数患者并未接受过daratumumab。** 因此它不能完全代表目前临床上已经使用Dara一线治疗后复发的患者。

### 疗效结果

中位随访 **34.5个月**：

| 终点          | Tec＋Dara   | DPd/DVd对照 |
| ------------- | ----------- | ----------- |
| 中位PFS       | 尚未达到    | 18.1个月    |
| 36个月PFS率   | **83.4%**   | 29.7%       |
| PFS风险比     | **HR 0.17** | —           |
| ORR           | **89.0%**   | 75.3%       |
| ≥完全缓解     | **81.8%**   | 32.1%       |
| MRD阴性，10⁻⁵ | **58.4%**   | 17.1%       |
| 36个月OS率    | **83.3%**   | 65.0%       |
| OS风险比      | **约0.46**  | —           |

也就是说：

- 疾病进展或死亡风险下降约 **83%**
- 死亡风险下降约 **54%**
- 不仅ORR高，最突出的是完全缓解和MRD阴性率明显提高

这是目前teclistamab最强的Ⅲ期结果，也是2026年美国批准 **Tecvayli＋Darzalex Faspro用于至少一线治疗后的RRMM** 的主要依据



主要问题是免疫抑制和感染：

- 3/4级感染：约 **54.1%**，对照约43.3%
- 严重感染：约 **54%**
- Tec＋Dara组报告了 **13例感染相关死亡**
- 其他常见严重不良事件包括：
  - 中性粒细胞减少
  - 淋巴细胞减少
  - 低丙种球蛋白血症
  - 肺炎和机会性感染
- CRS主要出现在阶梯加量初期，多数为1/2级
- 强化抗感染预防、监测IgG并及时补充免疫球蛋白后，严重感染明显减少

因此其疗效非常突出，但感染管理是核心代价。





## MajesTEC-9：teclistamab单药

- 研究编号：[NCT05572515](https://clinicaltrials.gov/study/NCT05572515)
- 全球、开放标签、随机Ⅲ期

  - teclistamab单药：296人
  - PVd或Kd：297人，其中约69%选择Kd
- 既往接受 **1–3线治疗**
- 所有患者均接受过：
  - 来那度胺
  - 抗CD38单抗
- 排除既往接受过BCMA靶向治疗者
- ECOG 0–2

主要患者特征：

| 特征                     | Teclistamab组     |
| ------------------------ | ----------------- |
| 中位年龄                 | 70岁              |
| ≥75岁                    | 28.4%             |
| 中位既往治疗线数         | 2线               |
| 1线/2线/3线              | 21.6%/44.3%/34.1% |
| 既往自体移植             | 49.0%             |
| 对最近一线耐药           | 92.6%             |
| 来那度胺耐药             | 79.1%             |
| 抗CD38耐药               | 85.5%             |
| IMiD＋抗CD38双重耐药     | 73.6%             |
| PI＋IMiD＋抗CD38三重耐药 | 34.5%             |
| 高危细胞遗传学           | 35.7%             |

这一研究的人群比MajesTEC-3更难治，也更贴近当前接受过Dara一线治疗后复发的患者。

### 疗效结果

中位随访 **17.3个月**：

| 终点                | Teclistamab | PVd/Kd对照 |
| ------------------- | ----------- | ---------- |
| 中位PFS             | 尚未达到    | 8.2个月    |
| 18个月PFS率         | **69.8%**   | 26.9%      |
| PFS风险比           | **HR 0.29** | —          |
| ORR                 | **84.5%**   | 54.2%      |
| ≥VGPR               | **80.1%**   | 36.4%      |
| ≥完全缓解           | **65.9%**   | 16.8%      |
| 中位缓解持续时间    | 尚未达到    | 13.4个月   |
| 18个月缓解持续率    | **80.6%**   | 40.1%      |
| ITT人群MRD阴性＋≥CR | **38.5%**   | 6.7%       |
| 18个月OS率          | **79.2%**   | 68.6%      |
| OS风险比            | **HR 0.60** | —          |

即：

- 进展或死亡风险下降约 **71%**
- 死亡风险下降约 **40%**
- 在抗CD38和来那度胺高度耐药的人群中，仍达到约85%的ORR和66%的完全缓解率

[NEJM论文](https://www.nejm.org/doi/full/10.1056/NEJMoa2603870)、[ASCO 2026完整研究资料](https://www.jnjmedicalconnect.com/media/attestation/congresses/oncology/2026/asco/majestec-9-a-phase-3-randomized-study-of-teclistamab-monotherapy-presentation.pdf)

### 安全性

| 安全性指标    | Teclistamab | PVd/Kd |
| ------------- | ----------- | ------ |
| 3/4级不良事件 | 84.9%       | 76.3%  |
| 5级不良事件   | 6.5%        | 3.5%   |
| 任意级别感染  | 82.8%       | 68.2%  |
| 3/4级感染     | 41.6%       | 29.0%  |
| 致死性感染    | 5.5%        | 2.8%   |
| 3/4级肺炎     | 14.4%       | 10.6%  |

CRS和ICANS多数较轻，但感染、低IgG和肺炎依然是主要风险，需要抗病毒、PJP预防、疫苗、IgG监测和必要时免疫球蛋白替代治疗。

核心解读

- **疗效最强的是MajesTEC-3的Tec＋Dara**：36个月PFS率83.4%，但患者基本没有既往Dara暴露，存在人群选择上的优势。
- **更适合与现实二线患者对应的是MajesTEC-9**：85.5%已经抗CD38耐药，仍显示显著PFS和OS获益。
- 两项研究共同证明teclistamab已经不仅是末线治疗，而有能力进入 **二线及以后**。
- 主要短板不是抗肿瘤活性，而是持续性免疫抑制和感染风险。对感染史、低IgG、肺部基础疾病或体弱患者，获益—风险需要特别评估。



## CARTITUDE-4

随机Ⅲ期 **CARTITUDE-4**：1–3线治疗后、来那度胺耐药的复发/难治MM

入组患者

- 419人随机入组：
  - Carvykti组：208人
  - 标准治疗DPd或PVd：211人
- 既往接受1–3线治疗
- 来那度胺耐药
- 既往接受过蛋白酶体抑制剂和免疫调节剂
