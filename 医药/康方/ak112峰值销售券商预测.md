**二、能核实到金额的适应症贡献**

**杰富瑞：最接近你要求的“欧美市场”口径。**

其原报告列出的2035年预测如下，单位为亿美元：

| 原报告适应症标签            | 美国      | 欧洲      | 合计       | 成功概率 |
| --------------------------- | --------- | --------- | ---------- | -------- |
| 一线PD-L1阳性NSCLC          | 44.00     | 20.00     | **64.00**  | 55%      |
| 一线PD-L1高表达NSCLC        | 26.00     | 11.00     | **37.00**  | 55%      |
| 二线及以后EGFR突变非鳞NSCLC | 2.97      | 1.31      | **4.28**   | 65%      |
| **按原报告分项加总**        | **72.97** | **32.31** | **105.28** | —        |

按这些分项，**一线治疗贡献约96%，EGFR突变后线贡献约4%**。但原报告摘要把“PD-L1阳性”和“高表达”分别列项，没有展示两者在底层模型中如何避免重叠；上表忠实转录其销售预测，不能据此把两个患者池直接相加。[杰富瑞原报告，第67页](https://cn.immuneonco.com/upload/file/20250317/37fd6f687658103d18606320ff26d98e.pdf)

**兴业证券：233亿美元可以拆成153＋80。**

| 贡献来源                                                   | 海外峰值销售  | 占扩展后总额 |
| ---------------------------------------------------------- | ------------- | ------------ |
| NSCLC                                                      | **153亿美元** | **65.7%**    |
| 三阴性乳腺癌、胆道癌、结直肠癌、头颈鳞癌、胰腺癌，五项合计 | **80亿美元**  | **34.3%**    |
| **扩展情景合计**                                           | **233亿美元** | **100%**     |

这里的80亿美元，是参考其中国模型中五项适应症相对肺癌的销售比例52.4%外推得到；并非公开了五份独立海外患者模型。153亿美元则由美国76.5亿美元，再假设欧洲及其他发达国献同等规模得到。因此，233亿美元不能当成严格欧美预测。[兴业证券原报告，第27—28页](https://pdf.dfcfw.com/pdf/H3_AP202508061722603667_1.pdf)

**高盛：530亿美元依赖明显的非肺癌贡献。**

康方引用的高盛图表展示了2035年的分癌种销售，按图形粗读：

| 癌种大类         | 2035年全球销售，约亿美元 |
| ---------------- | ------------------------ |
| 肺癌             | **130**                  |
| 乳腺癌           | **20**                   |
| 消化系统肿瘤     | **170**                  |
| 泌尿生殖系统肿瘤 | **30**                   |
| 其他             | **60**                   |
| **合计**         | **约410**                |

**这些是图形估读值，不是高盛公布的精确分项表；2035年的约410亿美元也不等于最终530亿美元峰值。**图表明确覆盖结直肠癌、胆道癌、三阴性乳腺癌、肝癌等扩展方向，消化系统肿瘤是重要贡献来源。[康方业绩材料引用高盛研究，第15页](https://www.akesobio.com/media/2535/2024-earnings.pdf)

另外，东吴常被引用的**“171亿元峰值收入”是人民币、康方收入口径**：约101亿元中国销售，加至少70亿元海外销售分成。它与“海外药品销售超过100亿美元”是两个不同数字，不能混用。[东吴研究所原文](https://finance.sina.com.cn/stock/stockzmt/2025-07-09/doc-infevnxx2995347.shtml)
