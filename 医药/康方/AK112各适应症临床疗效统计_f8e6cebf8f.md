## 统计 ak112 药在各适应症上的临床效果，列出临床成功显著疗效、一般疗效和临床失败的适应症。早期临床和三期临床都要，那些早期临床失败了没有开三期的也要列入

### AK112（依沃西单抗 / ivonescimab，SMT112）各适应症临床效果盘点

数据截至 **2026-09-05**。评级依据：是否有随机对照的统计学显著获益 > 单臂数据相对历史对照的幅度 > 是否被推进到 III 期 / 是否被悄悄放弃。

#### 一、临床成功、疗效显著（有随机对照 + 统计学显著）

| 适应症 | 研究 | 关键结果 | 状态 |
|---|---|---|---|
| EGFR-TKI 进展后 EGFR 突变 nsq-NSCLC（+培美+卡铂） | **HARMONi-A / AK112-301**（中国 III，n=322） | PFS 7.06 vs 4.80 m，**HR 0.46**，p<0.0001；ORR 50.6% vs 35.4%；最终 OS 16.8 vs 14.1 m，**HR 0.74，p=0.019**（SITC 2025 / JAMA 2026） | 2024/5 中国获批，2024/11 入医保。该领域历史上 PD-1 III 期全部失败 |
| 同上（全球人群） | **HARMONi**（全球 III，114 中心） | PFS 6.8 vs 4.4 m，**HR 0.52**，p<0.0001（Lancet Oncol 2026/8）；G3-5 出血 <1% | PFS 成功。**但 OS 未达标（见第三节）**；FDA PDUFA 2026/11/14 |
| 一线 PD-L1 阳性（TPS≥1%）晚期 NSCLC，**单药头对头 K 药** | **HARMONi-2 / AK112-303**（中国 III，n=398） | PFS 11.14 vs 5.82 m，**HR 0.51**，p<0.0001（Lancet 2025）；亚组一致（鳞/非鳞、TPS 1-49%/≥50%、肝转、脑转）；**2026/9/2 宣布 OS 期中分析达统计学显著**（HR 未披露） | 2025/4 中国获批。全球首个单药优效 K 药的 III 期 |
| 一线晚期**鳞状** NSCLC（+紫杉+卡铂），头对头替雷利珠+化疗 | **HARMONi-6 / AK112-306**（中国 III，n=532） | PFS 11.1 vs 6.9 m（HR 0.60）；**OS 27.9 vs 23.7 m，HR 0.66，p=0.0017**（ASCO 2026 全会 LBA4 / Lancet） | **全球首个 OS 优效于「PD-1+化疗」的方案（任何瘤种）**。2026 中国获批 |
| 一线晚期**胆道癌**（+吉西他滨/顺铂），头对头度伐利尤+化疗 | **HARMONi-GI1 / AK112-309**（III，n=682） | 2026/8/25 IDMC 期中分析 **OS 主终点达统计学显著**，PFS、ORR 同时达标（HR 未披露）；前置 II 期 mOS 16.8 m（对照 TOPAZ-1 durva 组 12.9 m） | **肺癌外首个 III 期成功** |

#### 三、临床失败 / 未达终点 / 事实上被放弃

##### 3.1 明确未达统计学终点
| 适应症 | 研究 | 失败细节 |
|---|---|---|
| EGFR-TKI 后 nsq-NSCLC（全球） | **HARMONi 的 OS 主终点** | 双主终点中 OS **失败**：主分析 OS HR 0.79（0.62–1.01），**p=0.057**；2025/9 更新 HR 0.78、nominal p=0.0332（非正式统计学成功，界值已用尽）。**西方亚组 OS HR：主分析 0.98 → 2025/9 0.84 → 2026/6 0.76，始终无统计学显著**。FDA 曾明确要求 OS 显著；BLA 仍在审（PDUFA 2026/11/14，更新数据可能触发 3 个月延期） |
| 一线转移性 NSCLC（+化疗）vs K药+化疗，**鳞癌队列** | **HARMONi-3**（全球 III，n≈1600） | 2026/4/30 公布**期中 PFS 分析未达统计学界值**，SMMT 单日跌约 25%；IDMC 建议继续。最终 PFS + OS 早期期中在 **2026 H2**；非鳞队列 PFS 在 **2027 H1**。目前状态＝期中失败、未定论 |

##### 3.2 早期临床后被停掉 / 从未推进 III 期（"隐性失败"）
| 适应症 / 组合 | 研究 | 结局 |
|---|---|---|
| 晚期妇科肿瘤（卵巢 / 宫颈 / 内膜）单药 | **AK112-203**（II，NCT04870177，n=53，2024/5 完成） | **至今未公开任何疗效数据，也未启动任何妇科 III 期** → 未过内部门槛。妇科方向改走 AK104+AK112 或 +化疗/奥拉帕利 II 期重探 |
| 复发卵巢癌 + PARP 抑制剂 | **AK112-204**（NCT04999605） | **TERMINATED**，理由"入组率过低"，仅入组 8 例 |
| 不可切除 HCC（单药/队列） | **AK112-207**（II，n=40，2025/6 完成） | **无公开疗效数据、无 HCC III 期**；肝癌改为 AK112-209（Ib/II，随机对照信迪利+贝伐类似物）重启 → 单药路线未成立 |
| AK119（CD73）+ AK112 治 NSCLC | **AK119-201**（Ib/II，n=59） | **TERMINATED**，"申办方战略优先级调整" |
| Tiragolumab + ivonescimab 肺鳞癌 | STRIVE（NCT07038915） | **WITHDRAWN**，0 例入组 |
| Ia 期有零星 PR 但从未建立注册路径的瘤种 | AK112-101/102（Ia） | 内膜癌（pMMR/dMMR）、**MSS/pMMR CRC 单药**、胸膜间皮瘤、肛管癌、小细胞卵巢癌——均只是个别 PR。其中 CRC 后来改走"+化疗"路线才成立，单药路线废弃 |

##### 3.3 需要标注的"疗效退坡"隐忧（不算失败，但影响判读）
- **HARMONi-6**：PFS 优势由 2025/2 切点的 40% 降至 2025/9 切点的 **28%**（已写进中国说明书）；分析师（Leerink，2026/8/14）预计 OS 的 34% 也会随随访衰减，并预测 HARMONi-3 的 OS 改善将 **低于 20%**。
- **HARMONi-A** OS HR 轨迹：0.72（30% 成熟度）→ 0.80（52%）→ 0.74（最终，勉强达标）。
- **III 期不及 II 期**：HARMONi-A III 期 PFS 7.06 m / ORR 50.6%，明显低于同适应症 II 期的 8.5 m / 68.4%（2024/5 曾引发暴跌）。

#### 四、尚无任何疗效数据（不评级，仅登记）

绝大多数为研究者发起（IIT）或刚启动：食管鳞癌（新辅助/二线放疗联合）、鼻咽癌（PD-1 耐药）、间皮瘤（初治/经治）、复发 GBM、经治 ccRCC（IVORY，NCT06940518）、胸腺瘤/胸腺癌、唾液腺癌、皮肤鳞癌、平滑肌肉瘤/软组织肉瘤、膀胱癌（+维迪西他单抗）、宫颈/内膜癌（MSK）、直肠癌短程放疗新辅助、结直肠肝转移转化、神经内分泌癌、阑尾腺癌、肾上腺皮质癌/PPGL、乳腺癌各类新辅助与 ADC 联合，以及大量 ADC/KRAS 抑制剂/mRNA 疫苗联合的 I/Ib 期。

---

#### 一句话总结

**成立且已被随机对照证实的只有 4 个适应症**：EGFR-TKI 后 nsq-NSCLC、一线 PD-L1+ NSCLC 单药、一线鳞状 NSCLC + 化疗、一线胆道癌 + 化疗（后三个均为头对头优效）。**核心争议全部集中在"全球人群 + OS"**：HARMONi 的 OS 失败、HARMONi-3 鳞癌队列期中 PFS 失败、以及多项研究观察到的获益随随访衰减。**单药路线的边界很清楚**——PD-L1 阴性（ORR 14.7%）、HNSCC CPS≥20（ORR 0%）、妇科肿瘤和 HCC 单药都没走通，几乎所有拓展瘤种最终都必须叠化疗或叠第二个抗体（AK117/AK104）。

#### 计数

- **显著成功 6 条**（4 个真实适应症）：EGFR-TKI 后 nsq-NSCLC（HARMONi-A，PFS+OS）、全球 HARMONi（仅 PFS）、一线 PD-L1+ NSCLC 单药 vs K 药、一线鳞状 NSCLC + 化疗 vs 替雷利珠+化疗、一线胆道癌 + 化疗 vs 度伐利尤+化疗
