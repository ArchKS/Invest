# 全球三期临床复盘（2020–2025）：框架与方法

## 0. 这份东西是什么 / 不是什么

**是**：60 个真实三期临床试验的逐个复盘，目的是**广泛理解全球三期临床的运行逻辑与历年代表作**——设计怎么做、统计怎么设、成功和失败分别死在哪一层、哪些教训可以迁移。

**不是**：
- 不是临床试验史（不做编年通史）
- 不是任何个股的投资论证（不绑定特定持仓，只抽通用规律）
- 不是药理教科书（机制只讲到"足以理解这个试验为什么这么设计"）

---

## 1. 归年规则（必须统一，否则跨年可比性崩掉）

**按 topline / 首次关键数据公开披露的日期归年**，而不是：
- 开题年（NCT 注册年）
- 正式论文发表年
- 获批年

三种例外的处理：
| 情形 | 处理 |
|---|---|
| topline 新闻稿在 A 年、完整数据在 B 年会议公布 | 归 A 年，但在卡片里注明"完整数据 B 年" |
| 平台试验分批出结果（如 RECOVERY） | 按该**具体干预臂**的结果日期归年 |
| topline 在 A 年，但真正引发认知转折的事件在 B 年（如监管否决、再分析） | 归 B 年，并在开头显式标注归年理由 |

## 2. 选样标准

### 2.1 「重要」的打分（每年取 Top10）

| # | 维度 | 说明 |
|---|---|---|
| 1 | **SOC 影响** | 是否改写标准治疗或指南 |
| 2 | **机制级结论** | 是否验证/推翻一个靶点或通路假设（不只是单个分子的成败） |
| 3 | **方法论教训** | 是否有可迁移的设计/统计/人群教训 |
| 4 | **资本冲击** | 读数当日/周股价与市值变化量级 |
| 5 | **锚定效应** | 是否成为后续同类试验的参照或警示 |

### 2.2 配额（软约束，遇到特殊年份可调，但要写明为什么调）

| 维度 | 目标配比 |
|---|---|
| 失败 : 成功 | 约 6 : 4 |
| 领域 | 肿瘤约 6、自免约 1、CNS/代谢/心血管约 2、其他（感染/疫苗/血液/罕见病）约 1 |
| 地域 | 每年至少 1–2 个非欧美主导资产（中国/日本/新兴市场） |

> 2020 年因 COVID 大流行，感染/疫苗配额上调、肿瘤下调，属于经用户确认的合理偏离。

### 2.3 「失败」采用宽定义（用户确认）

一个试验被归为**失败**，只要满足以下任一条：
1. **统计失败**：主终点未达到其预设 α 阈值
2. **临床无意义**：统计显著但绝对获益微小、或替代终点未转化为硬终点，临床价值被广泛质疑
3. **监管失败**：未获批、收到完全回应函（CRL）、加速批准未能转正、或获批后撤市
4. **商业性失败**：科学上成立但被同期更优方案挤出市场（"赢了试验、输了赛道"）

标注方式：`失败(统计)` / `失败(临床意义)` / `失败(监管)` / `失败(商业)` / `成功` / `混合`

## 3. 三档深度（用户确认）

| 档位 | 每年数量 | 写哪些模块 | 目标篇幅 |
|---|---|---|---|
| **A 档 · 深挖** | 3 | 全部 0–9 | 3000–4500 字 |
| **B 档 · 标准** | 4 | 0 / 2 / 3 / 4 / 5 / 7 | 1500–2200 字 |
| **C 档 · 卡片** | 3 | 0 / 4 / 7 | 500–800 字 |

A 档挑选原则：教训最可迁移、且争议最大的三个。不必是当年最出名的。

## 4. 单个试验的复盘模板（十模块）

### 模块 0 · 速览卡（结构化，字段固定，可直接抽进主表）

```
试验名        │ NCT 号
药物          │ 靶点 / 分子类型 / 代号
公司          │
适应症        │ 瘤种或疾病 · 线数 · 人群限定
期别 · 设计   │ 优效/非劣 · 盲法 · 随机比 · 对照臂具体方案
样本量        │ 计划 N / 实际 N
主终点        │
α 与中期分析  │ 总 α · 分配方式（层级/O'Brien-Fleming/Hochberg…）· 中期分析次数与实际用掉的 α
统计假设      │ 假定 HR · power · 目标事件数 · 预计随访
topline 日期  │ YYYY-MM-DD（披露渠道）
结论          │ 成功 / 失败(统计|临床意义|监管|商业) / 混合
市场反应      │ 读数当日或次日股价、市值变化
一句话        │ 这个试验在历史上留下了什么
```

### 模块 1 · 决策背景（立项时的世界）
- 当时 SOC 是什么、未满足需求的规模
- 竞争格局：同靶点/同机制谁在跑、领先或落后多久
- 公司为什么敢押三期：现金状况、BD/License 压力、专利或指南窗口、内部政治

### 模块 2 · 早期数据 → 三期的推断链（★ 含盲推）
- 二期实际数字：ORR / DCR / mPFS / 关键生物标志物，**连同 N、是否随机、是否富集人群、随访时长一起写**
- 从二期到三期，公司做了哪些**外推假设**（人群放宽？线数前移？终点换了？对照臂换了？）
- **盲推（Blind Call）**：只用 topline 之前的公开信息，写下
  - 我给主终点达成的概率：__%
  - 我预期的 HR 点估计区间：__
  - 我最担心的失败路径（排序）：
  - 事后对照：实际结果 / 我错在哪 / 这个错误是系统性的还是偶然的

> 盲推纪律：先写完盲推段落再去看结果段落的数字。凡是查证过程中已被结果污染的案例，必须在盲推段落标注 `[污染]`，不计入最终校准统计。

### 模块 3 · 设计解剖（一半的失败死在这里）
- **对照臂是否公允**：立项到读数之间 SOC 有没有升级？对照臂是否已经落后于同期真实世界？
- **人群定义**：biomarker cutoff、突变亚型、线数、既往治疗限制、ECOG
- **终点选择**：PFS / OS / DFS / EFS / 复合终点；BICR 还是研究者评估；替代终点与硬终点的历史相关性
- **统计计划**：假定效应量是否激进、power、目标事件数、中期分析节点、多重性控制
- **分层因素**与是否允许**交叉（crossover）**及后续治疗规则
- **地域构成**：各国/各区域入组占比，是否存在区域异质性风险

### 模块 4 · 结果（数字层）
- 主终点：**HR + 95% CI + p，并明确该终点分到的 α 阈值**（不与 0.05 直接比）
- 绝对获益：中位数差值 + 里程碑率（12/24/36 月等）
- **KM 曲线形态**：分离时点、是否早期交叉、尾部是否平台、比例风险假设是否成立（必要时看 RMST）
- 关键次要终点与亚组森林图：哪个亚组反常、是否存在质性交互
- 安全性：G3+ 发生率、因不良事件停药率、治疗相关死亡、剂量强度

### 模块 5 · 成/败归因（五层，逐层排除）

| 层 | 内容 |
|---|---|
| 1 机制层 | 靶点本身错了 / 生物学假设不成立 / 通路冗余 |
| 2 人群层 | 选错受益人群、富集不足、biomarker 无效 |
| 3 设计与统计层 | 终点、对照、α 分配、样本量、随访不足、效应量假设过激 |
| 4 执行层 | 入组慢、地域异质、脱落、数据质量、给药错误、疫情干扰 |
| 5 环境层 | SOC 升级、后线交叉稀释、监管口径变化、竞品抢位 |

每层标注 **`[事前可预见]`** 或 **`[事后才可知]`**——只有前者能变成投资/研发规律。

### 模块 6 · 事后验证（这条结论站住了吗）
- 后续同靶点/同类试验是否复现该结论
- 监管结局：获批 / CRL / 加速批准转正或撤回 / 撤市
- 指南采纳情况与真实世界使用

### 模块 7 · 可迁移规律（→ 进 99_规律库）
抽 1–3 条**可被证伪**的启发式，格式：
```
R-0XX  条件 → 后果（附量化阈值）
       支持案例：
       反例：
       当前置信度：高/中/低
```

### 模块 8 · 对同类在研管线的通用启示
不点名个股，只描述"具备什么特征的在研三期，应该被这条规律降权或升权"。

### 模块 9 · 争议与反方
- 当时与现在专家的分歧点
- 我自己不确定的地方
- 什么样的相反证据会推翻本篇的归因

## 6. 记录纪律

1. 所有 HR / CI / p / N 必须能追到一次公开来源（新闻稿、会议摘要、论文、FDA 审评文件），来源写在案例末尾
2. 数字有版本差异（如 topline vs 最终发表）时，两个都记，标明数据截止日
3. 区分**"我查到的事实"**与**"我的推断"**，后者用 `〔判断〕` 标记
4. 不确定就写不确定，不用模糊措辞掩盖
