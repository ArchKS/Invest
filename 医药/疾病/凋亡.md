**Caspase‑8 是细胞膜“死亡受体通路”的启动酶**。在前面讨论的杀伤性 T 细胞中，当 T 细胞表面的 FasL 与肿瘤细胞的 Fas 结合时，肿瘤细胞会组装 DISC 复合体并激活 caspase‑8，随后启动凋亡。

“Caspase”可理解为一类**使用半胱氨酸作为催化中心、主要在天冬氨酸之后切割蛋白质的蛋白酶**。它们通常先以无活性的 procaspase 形式存在，收到相应信号后才被激活。

### Caspase‑8 的作用

主要有三项：

1. **直接启动外源性凋亡**

   Fas、TRAIL 受体等死亡受体被激活后：

   `FasL → Fas → FADD → DISC → caspase‑8 → caspase‑3/7 → 凋亡`

2. **连接死亡受体与线粒体通路**

   Caspase‑8 切割 BID，生成 tBID：

   `caspase‑8 → BID/tBID → BAX/BAK → 线粒体释放细胞色素c → caspase‑9 → caspase‑3/7`

   许多癌细胞需要这种线粒体放大，才能充分执行死亡指令。[细胞死亡命名委员会综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC5864239/)

3. **抑制坏死性凋亡**

   Caspase‑8 还能限制 RIPK1–RIPK3–MLKL 通路，防止细胞转向坏死性凋亡。因此它并非单纯的“死亡开关”，也是不同死亡方式之间的转换器。

需要注意：杀伤性 T 细胞通过 **FasL–Fas** 杀伤时依赖 caspase‑8；但通过**穿孔素–颗粒酶 B** 杀伤时，颗粒酶 B 可以直接激活执行者 caspase 或线粒体通路，不一定先经过 caspase‑8。

## 人体有多少种 Caspase？

按传统人体 caspase 家族计算，共有 **12个编号成员**：

**caspase‑1～10、caspase‑12、caspase‑14。**

其中人体没有 caspase‑11 和 caspase‑13：

- Caspase‑11主要是小鼠中的成员，大致对应人体 caspase‑4/5。
- Caspase‑13后来被确认不是人体成员，与牛的相关基因及早期样本污染有关。
- 人体 CASP12 多数情况下带有提前终止突变，产生无功能蛋白，所以也可以说人体有**11个明确具有功能的主要 caspase**。[NCBI CASP12记录](https://www.ncbi.nlm.nih.gov/gene/100506742)

### 各成员的主要作用

| Caspase | 类别            | 主要作用                                                     |
| ------- | --------------- | ------------------------------------------------------------ |
| **1**   | 炎症型          | 炎症小体核心酶；成熟 IL‑1β、IL‑18，并切割 gasdermin D，引起焦亡 |
| **2**   | 启动型          | 感应 DNA损伤、染色体异常和代谢压力；可通过 BID 接入线粒体凋亡，但功能较依赖具体细胞环境 |
| **3**   | 执行型          | 最主要的凋亡执行者；切割 PARP、ICAD和细胞骨架等，引起 DNA断裂、细胞皱缩和凋亡小体形成 |
| **4**   | 炎症型          | 人体细胞质内直接感应脂多糖等信号，切割 gasdermin D，启动非经典焦亡 |
| **5**   | 炎症型          | 与 caspase‑4相似，参与人体非经典炎症小体和焦亡               |
| **6**   | 执行型          | 切割核纤层及细胞骨架蛋白，参与核结构拆解；也与神经轴突退化等过程有关 |
| **7**   | 执行型          | 与 caspase‑3高度重叠，负责拆解细胞蛋白和细胞器               |
| **8**   | 启动型          | Fas、TRAIL等死亡受体通路的主要启动酶；切割 BID，并抑制坏死性凋亡 |
| **9**   | 启动型          | 线粒体凋亡启动酶；在线粒体释放细胞色素c后，由 Apaf‑1凋亡小体激活 |
| **10**  | 启动/调节型     | 人体死亡受体通路成员，与 caspase‑8部分重叠；具体作用仍有争议，小鼠缺少功能性 caspase‑10 |
| **12**  | 特殊/通常无功能 | 人体多数人的 CASP12 是截短、无活性的；其他哺乳动物中可能参与炎症或内质网应激 |
| **14**  | 分化型          | 主要存在于皮肤角质形成细胞，处理丝聚蛋白、促进角化和皮肤屏障形成，不是经典凋亡酶 |

最容易记忆的分类是：

- **启动凋亡**：2、8、9、10  
- **执行凋亡**：3、6、7  
- **炎症与焦亡**：1、4、5  
- **特殊成员**：12、14

所以，caspase 并不都负责凋亡：**3/6/7负责“拆细胞”，8/9等负责“下达启动命令”，1/4/5主要负责炎症性焦亡，14则主要负责皮肤分化。**
