## 吉西他滨：给DNA复制掺入“假原料”

吉西他滨 gemcitabine 是脱氧胞苷类似物，即结构很像DNA原料 dCTP。

进入细胞后，它需要被磷酸化成两种主要活性代谢物：

吉西他滨
  ↓
dFdCDP：抑制核糖核苷酸还原酶
  ↓               ↓
减少正常dCTP     dFdCTP掺入DNA
        ↓
DNA延伸停止、复制叉受损
        ↓
DNA损伤反应和细胞凋亡



具体有两重攻击：

1. **二磷酸形式 dFdCDP**
   抑制核糖核苷酸还原酶，减少细胞制造DNA原料的能力。
2. **三磷酸形式 dFdCTP**
   冒充正常 dCTP掺进DNA。掺入后DNA聚合酶还能再接一个核苷酸，然后复制停止，称为“隐蔽性链终止”。

由于它一方面减少真原料，另一方面提供假原料，形成“自我增强”。最终引发复制压力、DNA损伤和凋亡。[FDA/DailyMed说明书](https://dailymed.nlm.nih.gov/dailymed/fda/fdaDrugXsl.cfm?setid=4031017d-d768-46de-8081-476bcb883f5e)



吉西他滨1996年即获批，价格相对成熟，可与多种机制的药物联合，常见于：

- 胰腺癌：吉西他滨＋白蛋白紫杉醇等
- 胆道癌：吉西他滨＋顺铂，后续可再加入免疫治疗
- 膀胱癌：吉西他滨＋顺铂或卡铂
- 非小细胞肺癌
- 卵巢癌
- 乳腺癌
- 某些肉瘤和淋巴瘤方案

攻击正在进行DNA复制的细胞。因此既能覆盖多种癌症，也会损伤骨髓等正常快速增殖组织，常见毒性是白细胞、血小板下降和贫血







## 来那度胺：把肿瘤依赖的蛋白送去“垃圾处理”

来那度胺 lenalidomide 是沙利度胺的衍生物，过去常被笼统称为“免疫调节剂”。现在更准确的理解是：它是一种早期成功的 **分子胶降解剂**。

它与 **CRBN/cereblon** 结合。CRBN是 CRL4-CRBN E3泛素连接酶复合物的底物受体。来那度胺结合后改变这个复合物识别蛋白的方式，使原本不容易被处理的蛋白被贴上泛素标签，送入蛋白酶体降解。

```
来那度胺＋CRBN
       ↓
改变E3泛素连接酶的底物选择
       ↓
IKZF1、IKZF3等被泛素化
       ↓
蛋白酶体降解
       ↓
IRF4、MYC生存网络下降
       ↓
骨髓瘤细胞停止生长或凋亡
```



在多发性骨髓瘤中的作用

它主要降解：

- IKZF1／Ikaros
- IKZF3／Aiolos

这两个转录因子帮助维持 **IRF4–MYC** 生存网络，而多发性骨髓瘤细胞常高度依赖这个网络。降解 IKZF1/3后，IRF4和MYC下降，骨髓瘤细胞失去生存支持。[Science机制研究](https://pubmed.ncbi.nlm.nih.gov/24292623/)

### 在 5q缺失型MDS中的作用

来那度胺还会促进 **CK1α** 降解。CK1α基因恰好位于5号染色体长臂缺失区域，del(5q)细胞本来就只剩较低水平，再降一点便可能越过生存阈值，因此产生特殊的治疗窗口。[Nature 2015](https://www.nature.com/articles/nature14610)

### 免疫调节作用

来那度胺还可以：

- 增加IL-2和干扰素γ；
- 激活T细胞和NK细胞；
- 增强抗体依赖性细胞毒作用，因而常与抗体药联合；
- 改变骨髓微环境和炎症因子；
- 产生一定抗血管生成作用。

所以它同时具有“直接打击肿瘤细胞”和“调动免疫系统”的双重效果。[DailyMed说明书](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=ca8cc2cc-c856-e676-4f60-1e46d7b53d73)

### 为什么特别常见

来那度胺是多发性骨髓瘤治疗的重要基础药物，经常与以下药物组合：

- 地塞米松
- 硼替佐米
- 达雷妥尤单抗
- 卡非佐米等

它还用于特定 MDS、滤泡性淋巴瘤和边缘区淋巴瘤。因为是口服药，又可长期用于骨髓瘤维持治疗，所以在血液肿瘤论文、临床试验和治疗方案中出现频率非常高。









# 卡铂



卡铂（Carboplatin）是一种经典的**铂类化疗药**，与顺铂（Cisplatin）、奥沙利铂（Oxaliplatin）属于同一家族。

实体：Carboplatin

作用机制：

- 进入肿瘤细胞后释放铂离子
- 与DNA结合形成交联
- 阻止DNA复制和转录
- 最终导致肿瘤细胞死亡

简单理解：

```text
DNA = 肿瘤细胞的说明书

卡铂 = 用订书机把说明书钉死

细胞无法复制
↓
细胞死亡
```

肺癌中为什么常用卡铂？

因为它比顺铂毒性更低：

| 项目       | 卡铂 | 顺铂 |
| ---------- | ---- | ---- |
| 肾毒性     | 较低 | 较高 |
| 恶心呕吐   | 较轻 | 较重 |
| 神经毒性   | 较低 | 较高 |
| 骨髓抑制   | 较高 | 中等 |
| 使用便利性 | 较好 | 较差 |

因此全球肺癌一线治疗大量采用：

- 卡铂 + 培美曲塞（非鳞癌）
- 卡铂 + 紫杉醇（鳞癌）

再联合：

- K药（Pembrolizumab）
- AK112（Ivonescimab）

形成目前主流方案。

在HARMONi-3中：

非鳞癌：

```text
AK112 + 卡铂 + 培美曲塞
VS
K药 + 卡铂 + 培美曲塞
```

鳞癌：

```text
AK112 + 卡铂 + 紫杉醇
VS
K药 + 卡铂 + 紫杉醇
```

卡铂在这里主要负责：

- 快速缩瘤
- 杀死大量肿瘤细胞
- 释放肿瘤抗原

而AK112或K药负责：

- 激活免疫系统
- 维持长期控制

从商业角度看，卡铂已经是几十年的老药，价格很低，真正决定疗效差异的是：

- K药（PD-1）
- AK112（PD-1/VEGF双抗）

所以HARMONi-3本质上是在比较：

```text
AK112 + 标准化疗
VS
K药 + 标准化疗
```

而不是比较卡铂本身。
