## 核苷酸

是一类由三个零件组成的小分子：含氮碱基＋五碳糖＋磷酸

腺嘌呤＋核糖＋3个磷酸＝ATP

鸟嘌呤＋核糖＋3个磷酸＝GTP



少了磷酸，就叫“核苷”：

- 腺嘌呤＋核糖＝腺苷
- 腺苷＋磷酸＝腺苷酸，也就是核苷酸

因此“核苷”和“核苷酸”不是同一个概念。

核苷酸首先是DNA和RNA的原料，DNA可以理解为一条由核苷酸连接而成的长链。主要使用四种脱氧核苷酸：

- dATP：携带碱基A
- dTTP：携带碱基T
- dGTP：携带碱基G
- dCTP：携带碱基C

RNA主要使用：

- ATP
- UTP
- GTP
- CTP

每个核苷酸都像一个带有字母的积木：

```
核苷酸—核苷酸—核苷酸—核苷酸
   A       T       G       C
```



其中：

- 碱基负责储存遗传信息；
- 糖和磷酸构成DNA或RNA链的骨架；
- 碱基配对保证信息可以复制。

## 但核苷酸远不只是遗传物质

它之所以在生物学中无处不在，是因为细胞把这套分子同时用于信息、能量、信号和代谢。

### 1. ATP：通用能量货币

ATP是腺嘌呤核苷三磷酸。它末端磷酸键水解时，可以推动原本不容易发生的反应：ATP → ADP＋磷酸＋可利用能量



ATP参与：

- 蛋白质合成
- 肌肉收缩
- 离子泵运转
- DNA复制
- 蛋白质磷酸化
- 细胞运动

严格说，ATP不是一个简单的“能量容器”，而是一种把放能反应与耗能反应连接起来的化学工具。

### 2. GTP：分子开关和机械动力

GTP与ATP结构相似，但细胞经常把它用于开关和定向过程。

RAS就是典型例子：

```
RAS结合GTP＝开启
RAS把GTP水解为GDP＝关闭
```

KRAS致癌突变会妨碍这一关闭过程，使生长信号持续传递。

GTP还参与：

- 蛋白质翻译
- 微管装配
- 囊泡运输
- G蛋白偶联受体信号
- 核内外物质运输

### 3. cAMP和cGMP：第二信使

ATP或GTP还可以被改造成环状核苷酸：

```
ATP → cAMP
GTP → cGMP
```

它们负责把细胞膜表面收到的激素或神经递质信号传到细胞内部。

例如肾上腺素与细胞表面受体结合后，常通过cAMP放大信号。一个受体可以产生大量cAMP，因此弱小的外界刺激可以形成强烈的细胞反应。

### 4. 构成重要辅酶

很多名字看起来不像核苷酸的分子，实际上也包含核苷酸结构，例如：

- NAD⁺：参与氧化还原和能量代谢
- FAD：参与电子转移
- 辅酶A：运输乙酰基等化学基团
- NADPH：提供还原力
- SAM：参与甲基化

这里的核苷酸部分常像一个“标准接口”，帮助酶识别和结合这些辅酶。

### 5. 给代谢物加上“可反应标签”

细胞有时把糖、脂质等物质与核苷酸连接，使它们进入容易发生反应的“活化状态”。

例如：

```
葡萄糖＋UDP → UDP-葡萄糖
```

UDP-葡萄糖可用于合成糖原和复杂糖链。核苷酸在这里很像一个临时把手，让酶更容易抓住、转移和加工代谢物。

## 为什么生物反复使用同一种结构

核苷酸之所以被生命系统大量采用，大致有五个原因：

1. **容易连接成稳定长链**
   糖—磷酸骨架适合储存遗传信息。
2. **碱基能够精确配对**
   A–T/U和G–C配对使复制和读取成为可能。
3. **磷酸可以携带和转移化学能**
   因此ATP、GTP适合推动反应。
4. **容易被酶识别**
   细胞在进化早期已经形成大量识别核苷酸的蛋白，后来不断重复利用这套接口。
5. **既稳定又可调控**
   核苷酸足够稳定，可以在细胞中存在；同时又能通过水解、磷酸化或环化迅速改变状态。

一种重要推测是，早期生命可能经历过“RNA世界”：RNA既能储存信息，也能催化反应。现代生命因此保留了大量以核苷酸为中心的化学体系。

## 与吉西他滨的关系

吉西他滨本身是“核苷类似物”；进入细胞并被加上磷酸后，才变成活性核苷酸形式：

```
吉西他滨
  ↓ 加磷酸
二磷酸形式：减少正常DNA原料
三磷酸形式：冒充dCTP掺入DNA
  ↓
DNA复制停止
  ↓
细胞可能启动凋亡
```

这也是为什么很多抗病毒药和抗癌药都是核苷或核苷酸类似物：只要制造一个“长得很像真原料”的假分子，就可能让病毒或快速增殖的癌细胞在复制遗传物质时把它误用。

最简洁地说：

> 核苷酸既是DNA和RNA的字母，也是细胞的电池、开关、信使和代谢接口，所以几乎在每个生命过程中都能看到它。
