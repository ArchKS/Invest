| 现象          | 细胞层面的含义                                               | 常见对应暴露 |
| ------------- | ------------------------------------------------------------ | ------------ |
| 高峰/阈值杀伤 | 必须在短时间内把某个关键过程压到“崩溃点”以下，才触发不可逆死亡 | Cmax         |
| 持续暴露杀伤  | 药物一撤，靶点和细胞功能能较快恢复；要持续压制才逐渐走向死亡 | T>阈值、Cmin |
| 累计暴露杀伤  | 每次药物作用都留下部分不可逆或难修复的损伤，损伤随时间/总剂量累积 | AUC          |

**Cmax**：一次给药后，血液（或靶组织）中达到的**最高药物浓度**。
它回答的是：“峰值有多高？”

**AUC**（Area Under the Curve，浓度–时间曲线下面积）：一段时间内药物浓度的**总暴露量**。
它同时综合了浓度高低和维持多久。
它回答的是：“身体总共接触了多少药？”



这些“杀伤方式”本质上来自：**药物和靶点怎么结合、细胞受损后能否修复、以及致死过程是否需要持续累积**。它不是药物永恒不变的标签，而是“药物–靶点–细胞类型–暴露时间”共同决定的。



1. 为什么会出现“阈值/高峰”杀伤？

通常因为细胞存在一个非线性的“**失稳点**”。

例如药物需要在短时间内：

- 占据足够高比例的关键靶点；
- 造成足够多 DNA 双链断裂；
- 使膜完整性、线粒体功能或蛋白稳态突然失效；
- 快速达到触发凋亡、焦亡或坏死的阈值。

阈值以下，细胞的修复与代偿系统还能扛住；超过阈值，损伤产生速度超过修复能力，细胞就跨过不可逆的死亡边界。此时“峰值够不够高”很关键，因此表现得像 Cmax 驱动。

在细胞数据中常见特征是：

- 浓度–效应曲线非常陡（高 Hill slope）；
- 短脉冲给药后，即使洗脱药物，仍继续发生凋亡；
- 达到某一浓度后，caspase 激活、膜破裂或 DNA 损伤急剧上升；
- washout 后靶点/下游信号仍不能恢复。

2. 为什么有些药必须持续暴露？

因为药物造成的是**可逆功能抑制**，而不是立刻留下不可逆损伤。

例如：

- 可逆抑制激酶、转录、蛋白合成或代谢；
- 药物离开后，靶点重新有活性；
- 细胞可重新合成蛋白、修复 DNA、恢复能量代谢；
- 只有持续阻断多个小时到数天，细胞才因为饥饿、复制失败、错误累积或持续应激而死亡。

这类情况下，一次很高但很短的 Cmax 可能只是“暂停细胞”，并不能真正杀死；关键是药物浓度在有效阈值以上维持多久，因此看 `T>ECx`、`Cmin` 或持续的靶点抑制更有意义。

典型的验证现象是：

- 相同 AUC 下，持续输注/高频给药比一次冲高更有效；
- 短脉冲后细胞可恢复增殖；
- 靶标磷酸化或下游 biomarker 在 washout 后迅速反弹；
- 必须持续维持一定的 target engagement，才出现不可逆凋亡。

3. 为什么 AUC 也会成为主要指标？

因为许多损伤并不是瞬间致死，而是“**生成 – 修复 – 累积**”的竞争。

若药物每单位时间造成一部分损伤，细胞同时也在修复：

- 药效弱或暴露短：修复赶得上，细胞存活；
- 总暴露增加：残留损伤越来越多；
- 损伤累积到阈值：细胞停止分裂或死亡。

所以 AUC 常代表“总体药理压力”或“累计有效作用量”。但 AUC 驱动不等于高峰不重要；它意味着，在所测试的范围内，总暴露最能解释疗效差异。





细胞本身哪些性质决定它偏哪一种？

- **靶点周转速度**：靶蛋白/通路恢复越快，越需要持续暴露。
- **药物–靶点结合动力学**：解离慢、共价结合或造成不可逆后果时，短时高暴露也可能有效。
- **损伤可修复性**：DNA 修复强、抗氧化强、蛋白稳态能力强的细胞，更不容易被短脉冲杀死。
- **细胞周期依赖性**：只在 S 期或 M 期有效的药，往往需要覆盖更长时间，才能“等到”更多细胞进入敏感期。
- **凋亡阈值**：BCL-2 家族、p53 状态、线粒体 priming 等决定细胞是否容易跨过死亡阈值。
- **细胞异质性和药物穿透**：组织/肿瘤内细胞所见浓度不同，体外看似 Cmax 驱动的药，在体内可能更依赖持续覆盖。

**Cmax、AUC、持续暴露不是药物的“机制名称”，而是不同细胞死亡动力学在 PK 曲线上的投影。**真正要同时测的是：药物浓度、靶点占有/通路抑制的持续时间，以及细胞损伤和死亡发生的时间过程。





## Lisaftoclax对单个细胞和对整体

> 我个人感觉，既然Lisaftoclax实现了和Venetoclax差不多的疗效，那基本可以说明它是Cmax驱动的了

对单个依赖BCL-2的细胞是超过凋亡阈值后可触发不可逆死亡，对整体则需要每天重复暴露，属于“阈值触发 + 反复覆盖”的模式。

| 要验证的问题             | 最关键实验                                                   |
| ------------------------ | ------------------------------------------------------------ |
| 是否“短脉冲过阈值即可杀” | CLL 原代细胞或 BCL-2 依赖细胞：2/4/8 小时药物 pulse 后 washout，追踪 24–72 小时凋亡 |
| Cmax 还是 AUC            | 设计相同 AUC、不同峰值和给药时长的方案；再设计相同 Cmax、不同 AUC 的方案 |
| 是否需持续靶点抑制       | washout 后连续测 BCL-2 target engagement、BAX/BAK 激活、MOMP、cleaved caspase-3/7 和 Annexin V/PI |
| 能否外推到患者           | 将个体 `Cmax`、`AUC`、`Ctrough`、`T>有效浓度` 分别与外周 CLL 细胞下降速度、MRD、骨髓反应、ORR/PFS 做模型比较 |

如果短 pulse 后仍有相近的 MOMP、caspase 激活和细胞死亡，且在相同 AUC 下“高峰短暴露”优于低峰长暴露，就可称它偏**阈值/Cmax 驱动**。反过来，若 washout 后细胞恢复、而持续低浓度暴露更有效，则它是**持续暴露或 AUC/T>阈值驱动**。
