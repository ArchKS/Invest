# IWG

IWG 2023 剔除了既往“虚高”的单纯骨髓完全缓解（mCR，不要求外周血象恢复），新增要求血象恢复的 **CR_L（有限计数恢复CR）** 与 **CR_h（部分血液学恢复CR）**，与传统CR合称 **复合完全缓解（cCR）**



| **评估维度**           | **IWG 2006 标准**                            | **IWG 2023 标准（HR-MDS 专用）**                             | **核心影响**                                    |
| ---------------------- | -------------------------------------------- | ------------------------------------------------------------ | ----------------------------------------------- |
| **适用人群**           | 涵盖所有 MDS（低危 + 高危）                  | 专用于**高危 MDS（HR-MDS）**                                 | 剥离低危干扰，聚焦生存与桥接移植终点            |
| **CR 血红蛋白门槛**    | **Hb ≥ 11.0 g/dL**                           | **Hb ≥ 10.0 g/dL**（下调 1 g/dL）                            | 释放大批骨髓清零但轻度贫血的“准 CR”患者         |
| **CR 骨髓与其余血象**  | 原始细胞 ≤ 5%；ANC ≥ 1.0、PLT ≥ 100          | 原始细胞 **＜ 5%**；ANC ≥ 1.0、PLT ≥ 100                     | 骨髓清零标准微调为严格小于 5%                   |
| **骨髓完全缓解 (mCR)** | **保留**（仅骨髓原始细胞降 ≥ 50%，不看血象） | **彻底废除**                                                 | 挤掉无血象改善、不延长 OS 的“虚假有效”水分      |
| **新增过渡缓解层级**   | 无                                           | 新增 **CRL**（单系 `CRuni` / 双系 `CRbi`）、**CRh**、**CRequ** | 汇总为 **cCR（复合 CR）**，与 OS 相关性显著增强 |
| **部分缓解 (PR)**      | 原始细胞降幅 ≥ 50%（仍 ＞ 5%），Hb ≥ 11.0    | 原始细胞降幅 ≥ 50%（仍 ≥ 5%），**Hb ≥ 10.0**                 | 同步下调 PR 的血红蛋白门槛                      |
| **缓解持续时间**       | 需连续维持 **≥ 4 周**方可确认                | **取消 4 周强制要求**，单次达标即确认                        | 适配患者达到缓解后快速桥接造血干细胞移植的节奏  |
| **血液学改善 (HI)**    | 并入总有效率（ORR）计算                      | 降级为次要终点，**不纳入 cCR**                               | 防止单系短暂血象波动拉高核心疗效读数            |

核心逻辑总结

- **一升一降**：IWG 2023 通过下调 Hb 门槛（11→10 g/dL）并增设 CRL，抬高了真正具备血象恢复的 **CR/cCR 读数**；同时废除纯 mCR，砍掉了过去 HMA 单药靠无血象改善撑起来的“虚高 ORR”。
- **监管认可度**：FDA 放行 GLORA-4 采用 IWG 2023 CR 作为共同主要终点，核心原因在于剔除纯 mCR 后，该指标与**桥接移植率**及最终 **OS 获益**的一致性大幅提高。

2023年IWG标准更新：引入多个“近CR”终点作为暂定缓解类别，即CR伴有限血液学恢复（CR-L）和CR伴部分血液学恢复（CRh）；移除骨髓CR（mCR）和疾病稳定（SD）作为缓解类别。





# IPSS-R



**骨髓原始细胞 <5% 的 MDS 患者，IPSS‑R 仍可 >3 分。** 骨髓原始细胞 **≤2% 计 0 分**，**>2% 且 <5% 计 1 分**。是否超过 3 分，取决于核型和三项血细胞计数的得分。

1. IPSS‑R 评分标准

五项得分相加，得到 IPSS‑R 总分。

| 项目                             | 计分标准                                               |
| -------------------------------- | ------------------------------------------------------ |
| 细胞遗传学（核型）               | 极好 **0**，好 **1**，中等 **2**，差 **3**，极差 **4** |
| 骨髓原始细胞比例                 | ≤2% **0**，>2% 且 <5% **1**，5%–10% **2**，>10% **3**  |
| 血红蛋白 Hb（g/L）               | ≥100 **0**，80 至 <100 **1**，<80 **1.5**              |
| 血小板 PLT（×10⁹/L）             | ≥100 **0**，50 至 <100 **0.5**，<50 **1**              |
| 中性粒细胞绝对计数 ANC（×10⁹/L） | ≥0.8 **0**，<0.8 **0.5**                               |

| 核型分组     | 染色体异常                                                   |
| ------------ | ------------------------------------------------------------ |
| 极好（0 分） | −Y、del(11q)                                                 |
| 好（1 分）   | 正常核型、del(5q)、del(12p)、del(20q)，或含 del(5q) 的双异常 |
| 中等（2 分） | del(7q)、+8、+19、i(17q)，其他单一异常，或其他两个独立克隆   |
| 差（3 分）   | −7、inv(3)/t(3q)/del(3q)，含 −7 或 del(7q) 的双异常，或恰有 3 项异常的复杂核型 |
| 极差（4 分） | 有 4 项或以上异常的复杂核型                                  |

总分对应风险组为 **极低 ≤1.5，低 >1.5 至 3，中等 >3 至 4.5，高 >4.5 至 6，极高 >6**。因此，**恰好 3 分仍属低危，3.5 分是进入中危的最低分**。[Greenberg 等，*Blood*，IPSS‑R 原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4425443/)







2. 骨髓原始细胞 <5% 时，哪些情况总分 >3？

先把 **Hb、PLT、ANC 的得分相加**，再按核型和骨髓原始细胞比例查下表。

| 核型                     | 原始细胞 ≤2% 时，三项血细胞计数合计需达到 | 原始细胞 >2% 且 <5% 时，三项血细胞计数合计需达到 |
| ------------------------ | ----------------------------------------- | ------------------------------------------------ |
| 极好（0 分）             | 无法超过 3 分，三项最多 3 分              | ≥2.5 分                                          |
| 好（1 分，包括正常核型） | ≥2.5 分                                   | ≥1.5 分                                          |
| 中等（2 分）             | ≥1.5 分                                   | ≥0.5 分                                          |
| 差（3 分）               | ≥0.5 分                                   | 0 分即可                                         |
| 极差（4 分）             | 0 分即可                                  | 0 分即可                                         |

**例子。** 正常核型（1 分）、骨髓原始细胞 3%（1 分）、Hb 90 g/L（1 分）、PLT 80×10⁹/L（0.5 分）、ANC 1.0×10⁹/L（0 分），总分为 **3.5 分，属中危**。
