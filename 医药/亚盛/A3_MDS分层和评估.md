IPSS-M评分

| **评分体系**       | **核心评估维度**                                             | **风险分层**                                                 | **高危（HR-MDS）判定标准**                                   |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **IPSS（1997）**   | 骨髓原始细胞、核型、血细胞减少系别数（3项）                  | 低危、中危-1、中危-2、高危（4层）                            | **中危-2（Int-2）与 高危（High）**（[Haematologica 2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC11788630/)） |
| **IPSS-R（2012）** | 原始细胞比例（≤2% / >2–<5% / 5–10% / >10%）、5级染色体核型、血红蛋白、血小板、中性粒细胞绝对值（5项） | 极低危（≤1.5）、低危（>1.5–3）、中危（>3–4.5）、高危（>4.5–6）、极高危（>6） | **总分 > 3.5分**（含中危中 >3.5分部分、高危及极高危）（[IWG 2023 Blood](https://ashpublications.org/blood/article/141/17/2047/494297/Consensus-proposal-for-revised-International)；[HealthTree](https://healthtree.org/news/ipss-r-risk-categories-mds)） |
| **IPSS-M（2022）** | IPSS-R全部参数 + **31个高频驱动基因突变**（重点加权多打击 *TP53*、*FLT3*、*MLL-PTD* 等高危变异及孤立 *SF3B1* 保护因素） | 极低、低、中低、中高、高、极高（6层）                        | **中高危（Moderate-High）、高危（High）与 极高危（Very High）**（[IWG 2023 Blood](https://ashpublications.org/blood/article/141/17/2047/494297/Consensus-proposal-for-revised-International)；[Current Oncology 2026](https://www.mdpi.com/1718-7729/33/7/404)） |

IWG 2023 剔除了既往“虚高”的单纯骨髓完全缓解（mCR，不要求外周血象恢复），新增要求血象恢复的 **CR_L（有限计数恢复CR）** 与 **CR_h（部分血液学恢复CR）**，与传统CR合称 **复合完全缓解（cCR）**



| **评估维度**           | **IWG 2006 标准**                            | **IWG 2023 标准（HR-MDS 专用）**                             | **核心影响**                                    |
| ---------------------- | -------------------------------------------- | ------------------------------------------------------------ | ----------------------------------------------- |
| **适用人群**           | 涵盖所有 MDS（低危 + 高危）                  | 专用于**高危 MDS（HR-MDS）**                                 | 剥离低危干扰，聚焦生存与桥接移植终点            |
| **CR 血红蛋白门槛**    | **Hb ≥ 11.0 g/dL**                           | **Hb ≥ 10.0 g/dL**（下调 1 g/dL）                            | 释放大批骨髓清零但轻度贫血的“准 CR”患者         |
| **CR 骨髓与其余血象**  | 原始细胞 ≤ 5%；ANC ≥ 1.0、PLT ≥ 100          | 原始细胞 **＜ 5%**；ANC ≥ 1.0、PLT ≥ 100                     | 骨髓清零标准微调为严格小于 5%                   |
| **骨髓完全缓解 (mCR)** | **保留**（仅骨髓原始细胞降 ≥ 50%，不看血象） | **彻底废除**                                                 | 挤掉无血象改善、不延长 OS 的“虚假有效”水分      |
| **新增过渡缓解层级**   | 无                                           | 新增 **CRL**（单系 `CRuni` / 双系 `CRbi`）、**CRh**、**CRequ** | 汇总为 **cCR（复合 CR）**，与 OS 相关性显著增强 |
| **部分缓解 (PR)**      | 原始细胞降幅 ≥ 50%（仍 ＞ 5%），Hb ≥ 11.0    | 原始细胞降幅 ≥ 50%（仍 ≥ 5%），**Hb ≥ 10.0**                 | 同步下调 PR 的血红蛋白门槛                      |
| **缓解持续时间**       | 需连续维持 **≥ 4 周**方可确认                | **取消 4 周强制要求**，单次达标即确认                        | 适配患者达到缓解后快速桥接造血干细胞移植的节奏  |
| **血液学改善 (HI)**    | 并入总有效率（ORR）计算                      | 降级为次要终点，**不纳入 cCR**                               | 防止单系短暂血象波动拉高核心疗效读数            |

### 核心逻辑总结

- **一升一降**：IWG 2023 通过下调 Hb 门槛（11→10 g/dL）并增设 CRL，抬高了真正具备血象恢复的 **CR/cCR 读数**；同时废除纯 mCR，砍掉了过去 HMA 单药靠无血象改善撑起来的“虚高 ORR”。
- **监管认可度**：FDA 放行 GLORA-4 采用 IWG 2023 CR 作为共同主要终点，核心原因在于剔除纯 mCR 后，该指标与**桥接移植率**及最终 **OS 获益**的一致性大幅提高。

2023年IWG标准更新：引入多个“近CR”终点作为暂定缓解类别，即CR伴有限血液学恢复（CR-L）和CR伴部分血液学恢复（CRh）；移除骨髓CR（mCR）和疾病稳定（SD）作为缓解类别。
