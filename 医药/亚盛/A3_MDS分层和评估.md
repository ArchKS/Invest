# 缓解评估指标

IWG 2006中，患者骨髓原始细胞降至≤5%，但血象没有完全恢复时，通常归入**骨髓完全缓解mCR**。mCR不要求外周血恢复。

IWG 2023取消了mCR，改为以下更具体的类别：

1. CRL：有限血象恢复的CR

共同要求：

- 骨髓原始细胞<5%；
- 外周血原始细胞为0；
- 尚未满足严格CR的三系血象标准。

按照达到多少项严格CR血象门槛细分：

- **CRuni**：Hb≥10、血小板≥100、ANC≥1.0三项中，只达到1项；
- **CRbi**：三项中达到2项。

CRL是CRuni和CRbi的合称。

2. CRh：部分血液学恢复的CR

要求：

- 骨髓原始细胞<5%；
- 外周血原始细胞为0；
- 不满足严格CR或CRL；
- 血小板≥50×10⁹/L；
- ANC≥0.5×10⁹/L；
- **不设Hb最低门槛**。

CRL和CRh目前属于**暂定/探索性终点**，不应与严格CR完全等同。

3. CR equivalent：CR等效反应

对于治疗前骨髓原始细胞已经<5%的患者，不能仅凭治疗后仍<5%就认定普通CR。IWG 2023要求：

- Hb≥10 g/dL；
- 血小板≥100×10⁹/L；
- ANC≥1.0×10⁹/L；
- 外周血原始细胞为0；
- 治疗前细胞遗传学异常完全清除。

满足这些条件才可报告为 **CR equivalent**，并且需要与普通CR分开报告。

**IWG 2023降低了严格CR的血红蛋白门槛，同时取消mCR，并新增“血象未完全恢复的CR亚型”**，以更细致地描述骨髓缓解但血象恢复不足的患者。取消mCR的原因是：单纯骨髓原始细胞下降、但没有血象改善的mCR，其生存获益并不稳定。



- CR：骨髓✓ + 血液完全改善（HI）✓ （ANC≥1.0, PLT≥100）
- CRh：骨髓✓ + 血液部分改善（ANC≥0.5, PLT≥50）
- CRi：骨髓✓ + 血液状态未恢复（ANC < 1.0 或 PLT < 100）
- mCR：骨髓✓ + 不评估血液是否改善
