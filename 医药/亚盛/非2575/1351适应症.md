# CML、PH+ALL



**CML 是“慢性髓性白血病”，俗称慢粒；Ph+ ALL 是“费城染色体阳性的急性淋巴细胞白血病”，属于急淋的一种。** 两者有相同的关键基因异常，但病变细胞、进展速度和治疗方式不同。

| 对比     | CML（慢粒）                                            | Ph+ ALL（费城阳性急淋）               |
| -------- | ------------------------------------------------------ | ------------------------------------- |
| 病变细胞 | 髓系细胞，慢性期以较成熟的粒细胞增多为主               | 未成熟的淋巴细胞，通常属于 B 细胞类型 |
| 进展速度 | 慢性期通常较慢                                         | 进展快，需要尽快治疗                  |
| 常见表现 | 体检发现白细胞升高，也可出现乏力、盗汗、脾大、左上腹胀 | 乏力、贫血、发热、感染、瘀斑或出血    |
| 治疗核心 | 长期口服靶向药，定期监测                               | 靶向药联合化疗或免疫治疗，分阶段治疗  |
| 总体前景 | 控制良好的慢性期患者可长期生存                         | 治疗更复杂，但现代治疗已明显改善预后  |

1. **为什么这两种疾病经常一起出现？**

   它们都有一个关键驱动因素：**BCR::ABL1 融合基因**。通常是第 9 号和第 22 号染色体交换了一段片段，形成异常的第 22 号染色体——“费城染色体”，简称 **Ph**；“Ph+”就是检测阳性。

   这个融合基因制造持续活跃的酪氨酸激酶，相当于细胞增殖的“油门卡住了”。因此，两种病都能使用抑制它的靶向药，称为 **TKI（酪氨酸激酶抑制剂）**。这种异常通常是后天在造血细胞中发生的，不属于通常意义上的遗传病，也不会传染。

2. **CML：治疗重点是长期控制，防止进入急变期。**

   多数患者在慢性期确诊，初期可能没有明显症状。如果疾病控制不好，可能进入急变期，出现大量幼稚白血病细胞，治疗难度明显增加。

   常用药物包括伊马替尼、达沙替尼、尼洛替尼等。医生会结合疾病风险、其他疾病、药物副作用和耐药情况选择药物，并定期检测血液中的 **BCR::ABL1 水平**，判断治疗效果。

   **许多接受有效治疗的慢性期患者，预期寿命可以接近普通人群。** 少数达到并长期维持深度分子缓解的患者，可以在医生安排的严格监测下尝试停药；停药需要满足条件，不能因为血常规正常就自行停药。[来源：美国国家癌症研究所](https://www.cancer.gov/types/leukemia/hp/cml-treatment-pdq)

3. **Ph+ ALL：治疗重点是迅速清除白血病，并降低复发风险。**

   这类疾病中的幼稚淋巴细胞快速增殖，会挤占正常造血空间，导致贫血、感染和出血。它可以直接发生，**并不意味着患者之前一定患有 CML**。

   治疗通常以 TKI 为基础，联合化疗或免疫治疗，例如贝林妥欧单抗。部分患者可以采用减少传统化疗的方案。治疗还需要监测 **MRD（微小／可测量残留病）**，寻找普通显微镜下看不到的残余白血病细胞，并进行中枢神经系统预防治疗，降低脑和脊髓相关部位复发的风险。

   是否需要异基因造血干细胞移植，要根据风险、MRD、治疗反应和身体状况决定。过去 Ph+ ALL 被认为预后较差，现在靶向药与免疫治疗已显著改善结果，部分患者能够获得长期缓解。[来源：D-ALBA 长期随访研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10927329/)

4. **诊断时，不能只看“BCR::ABL1 阳性”。**

   医生还需要结合血常规、骨髓检查、流式细胞检测和染色体／基因检测，判断病变细胞属于髓系还是淋巴系，并区分 **Ph+ ALL 与 CML 的淋巴系急变**。两者可能使用部分相同的药物，但整体治疗方案不同。

下一步（1 分钟）：若你正在看检查报告，先找到“诊断名称”“骨髓细胞类型”和“BCR::ABL1”这三处，便于理解报告对应哪一种疾病。
