## 第一层：分子层面药理机制

### 1.1 核心分子靶点

Lisaftoclax (APG-2575) 是一种**口服小分子 BH3 模拟物**，高度选择性抑制 **BCL-2** 蛋白。

| 参数 | Lisaftoclax (APG-2575) | Venetoclax (ABT-199) |
|------|------------------------|---------------------|
| BCL-2 亲和力 (Ki) | **< 0.1 nM** | < 0.1 nM |
| BCL-xL 选择性比 | **>500 倍** | >100 倍 |
| MCL-1 活性 | 极弱 | 极弱 |
| 血浆半衰期 (t½) | **4–6 小时** | ~26 小时 |
| Tmax | 4–6 小时 | 5–8 小时 |

### 1.2 结构差异决定功能差异

Lisaftoclax 与 Venetoclax 存在两个关键结构修饰：

- **位点 1**：二甲基基团 → **环丁基环** 取代
- **位点 2**：四氢-2H-吡喃基团 → **1,4-二恶烷** 取代

这两个修饰保持了与 BCL-2 疏水槽的高亲和力，同时进一步降低了对 BCL-xL 的脱靶结合。

### 1.3 凋亡信号传导机制

```
Lisaftoclax
    ↓
竞争性结合 BCL-2 蛋白 BH3 疏水槽
    ↓
置换 BCL-2:BIM 复合物 → 释放 BIM 蛋白
    ↓
释放 BAX/BAK 促凋亡蛋白
    ↓
线粒体外膜通透化 (MOMP)
    ↓
细胞色素 c 释放 → Caspase-9 → Caspase-3/7 级联激活
    ↓
PARP 切割 → 凋亡执行


化学式：
1、lisaftoclax + BCL-2:BIM  →  lisaftoclax:BCL-2 + 游离 BIM 
2、游离 BIM → 激活 BAX/BAK → 线粒体外膜通透化（MOMP） → 细胞色素 c / caspase → 凋亡

```

**关键机制预测 1**：由于 BCL-2 高度依赖的肿瘤细胞（如 CLL）对 BCL-2 抑制特别敏感，Lisaftoclax 应在 CLL/SLL 中表现出最强的单药活性。

**关键机制预测 2**：短半衰期（4-6小时）意味着每日一次给药后药物快速清除，可能降低靶点持续抑制带来的 TLS 风险，但需要每日给药维持有效暴露。

**关键机制预测 3**：高 BCL-2/BCL-xL 选择性比（>500倍）应带来较低的血小板减少发生率（血小板依赖 BCL-xL 生存）。

## <a id="2"></a>第二层：临床前验证

### 2.1 体外实验验证

**来源**: Clin Cancer Res. 2022; PMID: 36048524

| 细胞系 | 依赖性 | Lisaftoclax IC50 | Venetoclax IC50 | 结论 |
|--------|--------|-----------------|-----------------|------|
| RS4;11 (ALL) | BCL-2 | **3.6 nM** | 相当或更高 | ✓ 强效 |
| HL-60 (AML) | BCL-2 | **2.4 nM** | 相当或更高 | ✓ 强效 |
| MV-4-11 (AML) | BCL-2 | **1.9 nM** | 相当或更高 | ✓ 强效 |
| SKLU-1 (NSCLC) | BCL-xL | **无显著影响** | — | ✓ 选择性验证 |
| NCI-H23 (NSCLC) | MCL-1 | **无显著影响** | — | ✓ 选择性验证 |

**机制对齐检查** ✅ — BCL-2 依赖性细胞系高度敏感，BCL-xL/MCL-1 依赖性细胞系不受影响，验证了高选择性机制。

### 2.2 CLL 患者原代样本

- Lisaftoclax 对 CLL 原代样本的 IC50 比 Venetoclax **低 2 倍**（P=0.05）
- 多组 CLL 样本均显示 Lisaftoclax 对细胞活力的抑制**更强**（P=0.0022）

**发现**：Lisaftoclax 对 CLL 原代细胞的效力优于 Venetoclax，提示可能存在超越单纯 BCL-2 亲和力的额外机制优势。

### 2.3 机制深化验证

**BIM/Noxa 上调效应**：
- Lisaftoclax 处理后，促凋亡蛋白 **BIM 和 Noxa 表达上调**
- BIM 从细胞质**转位至线粒体**
- 形成正反馈：BCL-2 被抑制 → BIM 释放 → 更多 BIM 转位至线粒体 → 持续竞争 BCL-2 → 凋亡信号放大

**线粒体功能抑制**：
- Lisaftoclax 显著下调**线粒体呼吸功能**和 ATP 产生
- 药物进入肿瘤细胞**快速（2小时达平台期）**

**机制预测 4（新增）**：快速细胞进入 + 短半衰期 → "脉冲式"靶点抑制 → 可能解释为何 TLS 风险更低（肿瘤细胞逐步凋亡 vs 大规模同步裂解）。

### 2.4 体内异种移植模型

- 多种血液肿瘤异种移植模型中确认抗肿瘤活性
- Lisaftoclax + 利妥昔单抗 / 苯达莫司汀+利妥昔单抗 → 增强抗肿瘤活性
- Caspase 激活和 PARP 切割与 PK 特征相关

### 3.3 Phase 1 → 机制修正

**原始机制假设**：BCL-2 选择性抑制剂，主要对 BCL-2 高度依赖的 CLL 有效。

**Phase 1 数据反馈**：
- CLL ≥200mg ORR 87.5% → **假设成立**
- MCL ORR 50%, MZL ORR 50% → **BCL-2 依赖谱比预期更广**
- 0% TLS（全球+中国共约 86 例）→ **短半衰期 TLS 保护假说得到强有力验证**

**机制修正 1**：将"脉冲式靶点抑制模型"正式纳入核心机制——

> **脉冲式抑制假说**：Lisaftoclax 的 4-6 小时短半衰期使每日给药后 BCL-2 靶点抑制呈"峰谷交替"模式。峰浓度时有效抑制 BCL-2、启动凋亡程序；谷浓度时允许部分肿瘤细胞恢复、避免大规模同步裂解 → TLS 风险极低。这种模式允许每日 ramp-up（4-6天达目标剂量），而 Venetoclax 的 26小时半衰期只能采用每周 ramp-up（5周达目标剂量）。

### 4.4 Phase 1b/2 → 第二轮机制深化与修正

#### 核心发现 1：VEN 经治患者仍有效 — 需解释机制

**问题**：如果 Lisaftoclax 和 Venetoclax 都是 BCL-2 抑制剂，为何 VEN 耐药后 Lisaftoclax 仍有效？

**机制修正 2 — VEN 耐药克服假说**：

> 维奈克拉耐药的主要机制包括：
> 1. **BCL-2 突变**（如 G101V, F104L）降低 Venetoclax 结合亲和力
> 2. **MCL-1 上调**代偿 BCL-2 抑制
> 3. **BCL-xL 上调**
>
> Lisaftoclax 克服耐药的潜在机制：
> 1. **结构差异**（环丁基环 + 1,4-二恶烷修饰）→ 与 BCL-2 结合模式略有不同 → 可能对某些 VEN 耐药突变（如 G101V）**仍保持结合力**
> 2. **BIM/Noxa 正反馈放大** → 即使在部分 BCL-2 被突变体占据的情况下，BIM 释放 + Noxa 上调可中和 MCL-1 → 恢复凋亡信号
> 3. **线粒体呼吸直接抑制** → 独立于 BCL-2 结合的额外凋亡机制
> 4. **短半衰期峰谷交替** → 可能减少 BCL-2 耐药突变的代偿性选择压力

#### 核心发现 2：14天间歇给药优于 28天持续给药

**数据**：R/R AML 中，14天给药 ORR 50% vs 28天给药 ORR 39%

**机制修正 3 — 间歇给药优化假说**：

> 持续 BCL-2 抑制可能：
> 1. 增加对正常造血干细胞的毒性（中性粒细胞减少）
> 2. 驱动 MCL-1/BCL-xL 代偿性上调
> 
> 间歇给药（14天开/14天关）允许：
> 1. 正常造血恢复窗口
> 2. 减少代偿机制激活
> 3. 维持肿瘤细胞对 BCL-2 抑制的"成瘾性"

#### 核心发现 3：BTKi + BCL-2i 协同效应

**数据**：联合阿可替尼 ORR 96.6%，远超单药 73.3%

**机制整合**：

```
BTK 信号通路                         BCL-2 凋亡通路
     ↓                                      ↓
BTKi (阿可替尼)                      Lisaftoclax
     ↓                                      ↓
抑制 BCR 信号 → 减少增殖信号         抑制 BCL-2 → 恢复凋亡
     ↓                                      ↓
        ╰────────── 协同 ──────────╯
                     ↓
              CLL 细胞双重打击
          （无法增殖 + 被迫凋亡）
```

## 第六层：Phase 3 预测与进行中数据对齐

### 6.1 GLORA 研究 — BTKi 经治 CLL/SLL (NCT06104566)

**设计**：全球多中心、随机、开放 III 期
- **入组**：~440 例，BTKi 单药 ≥12个月后未达 CR 且未进展的 CLL/SLL
- **随机**：1:1 → Lisaftoclax + BTKi vs BTKi 单药
- **主要终点**：PFS（独立评审委员会，iwCLL 2018）
- **关键次要终点**：OS
- **启动**：2023年12月，126个中心，18个国家
- **预计完成**：2026年12月

#### 基于药理机制的 Phase 3 预测

| 预测指标 | 预测值 | 机制依据 |
|---------|--------|---------|
| **PFS HR** | **0.50–0.65** | 双通路协同 → 加深缓解 → 延长PFS |
| **ORR (联合组)** | **>90%** | Phase 1b/2 ORR 96.6% |
| **ORR (对照组)** | **~70%** | BTKi 单药历史数据 |
| **MRD 阴性率 (联合组)** | **>40%** | 双通路深度清除 |
| **TLS 率** | **<3%** | 2.8% in Phase 1b/2 |
| **≥3级中性粒细胞减少** | **25-30%** | Phase 1b/2 数据 |
| **因AE停药 (Lisaftoclax相关)** | **<5%** | 历史数据 0% |

### 6.2 GLORA 设计中的机制验证锚点

GLORA 研究的**独特设计特征**提供了直接的机制验证机会：

1. **入组患者为 BTKi ≥12个月后 PR/SD 状态**：这些患者处于"BTKi 平台期"，BCR 信号已被抑制但残留疾病存活依赖 BCL-2 → **直接检验 BCL-2 作为 BTKi 耐药/残留节点的核心地位**

2. **分层因素为 del(17p)/TP53**：TP53 失活 → 凋亡通路缺陷 → BCL-2 可能成为更关键的生存依赖 → **预测 del(17p)/TP53 突变亚组从 Lisaftoclax 联合治疗中获益更大**

3. **5天 ramp-up 至 400mg**：在 III 期大规模人群中验证每日 ramp-up 的 TLS 安全性 → **如果 TLS <3%，则短半衰期脉冲式机制在 III 期确定性验证**

## 结论与未解决问题

### 已确认的核心药理机制

1. **BCL-2 选择性 BH3 模拟**：与 Venetoclax 机制同源但结构差异带来关键临床优势
2. **短半衰期脉冲式抑制**：Lisaftoclax 最核心的差异化特征，直接导致 TLS 低风险、每日 ramp-up 可行、间歇给药可能更优
3. **BIM/Noxa 正反馈**：强化凋亡信号，可能部分解释 VEN 耐药克服
4. **BTK + BCL-2 双通路协同**：全口服无化疗方案的基础

### 待 III 期确定性验证的假说

| 假说 | 验证锚点 | 关键度 |
|------|---------|--------|
| 脉冲式抑制 → 更低 TLS (III期规模验证) | GLORA TLS <3% | ★★★★★ |
| BTK+BCL-2 → PFS 显著延长 | GLORA 主要终点 | ★★★★★ |
| del(17p)/TP53 → 更大获益 | GLORA 分层分析 | ★★★★ |
| 结构差异 → 对 G101V 等突变保持结合 | 需要体外结合实验 | ★★★★★ |
| 间歇给药 AML 更优 → III期方案优化 | GLORA-AML | ★★★★ |
