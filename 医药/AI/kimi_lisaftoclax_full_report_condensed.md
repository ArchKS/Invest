# Lisaftoclax（APG-2575）药理机制与临床前景：精简版

## 摘要

Lisaftoclax 是亚盛医药开发的口服 BCL-2 偏向性抑制剂，已获中国 NMPA 批准用于复发/难治性 CLL/SLL。其核心定位不是“克服 venetoclax 耐药的第二代药物”，而是以**高 Cmax、短血浆半衰期和短 ramp-up**换取更便捷、潜在更可控的 BCL-2 抑制方案。

本报告以“机制假设—临床验证—模型修正—Phase 3 推导”为框架。核心模型为：药物快速达到足以跨越线粒体凋亡阈值的峰浓度，释放 BIM 并激活 BAX/BAK，触发不可逆的 MOMP；随后短血浆暴露限制正常组织持续受药，肿瘤组织滞留则可能维持疗效。该模型可解释早期 ALC 下降、0% TLS、4–6 天 ramp-up 及相对可控的血液学毒性。

现有数据支持其在 CLL/SLL 中的活性和联合治疗潜力，但 TP53 缺失/突变、复杂核型及 MCL-1 上调仍是关键疗效边界。四项 GLORA Phase 3 中，CLL/SLL 项目成功把握最高；AML 居中；HR-MDS 受 VERONA 阴性结果和 OS 竞争风险影响，确定性最低。

## 1. 药理机制与差异化定位

### 1.1 靶点与凋亡通路

Lisaftoclax 是 BH3 模拟物，通过占据 BCL-2 的 BH3 结合槽，置换被隔离的促凋亡蛋白（主要为 BIM），继而激活 BAX/BAK、诱发线粒体外膜通透化（MOMP），启动 caspase 级联反应并执行凋亡。

其生化特征为 BCL-2 偏向、但仍保留 BCL-xL 抑制活性：BCL-2 IC50 约 2 nM，BCL-xL IC50 约 5.9 nM，MCL-1 IC50 >5,000 nM。因此，它更接近“BCL-2 偏向性双重抑制剂”，而非 venetoclax 式的高度 BCL-2 选择性抑制剂。细胞实验中，其对 BCL-2 与 BCL-xL 依赖细胞均有功能性活性。

### 1.2 Cmax 驱动的脉冲式凋亡模型

本报告的统一假设是：BCL-2 抑制的关键不是持续累积暴露，而是短时间内跨越凋亡阈值的峰浓度。MOMP 属于阈值型、不可逆事件；一旦足量 BIM 被释放并形成 BAX/BAK 孔道，后续维持高浓度的边际收益可能有限。

Lisaftoclax 的血浆半衰期约 3–5 小时，显著短于 venetoclax 的约 26 小时。由此形成“高 Cmax、短全身暴露”的 PK 特征：

- 快速达到有效细胞内浓度，触发肿瘤细胞凋亡；
- 减少持续性骨髓和血小板暴露，降低累积毒性；
- 预临床肿瘤组织滞留（约 13–48 小时）若能在人体验证，可解释短血浆暴露下的持续药效。

该肿瘤滞留数据目前主要来自临床前模型，不能等同于人体组织 PK 结论。

### 1.3 安全性与耐药边界

BCL-xL 在巨核细胞和血小板生存中重要。Lisaftoclax 约 3 倍的 BCL-2/BCL-xL 选择性提示存在血小板减少风险；但其短半衰期可能降低持续 BCL-xL 抑制，从而部分抵消这一风险。现有早期综合数据中，≥3 级血小板减少约 13.5%，仍需长期暴露数据确认。

对于 venetoclax 常见的 BCL-2 G101V 耐药突变，Lisaftoclax 的生化 IC50 约 57 nM、细胞 IC50 约 61 nM，活性并不显示其具有明确的耐药覆盖优势。因此，其主要竞争价值在安全性、给药便利性和联合方案，而非 G101V 克服能力。MCL-1 上调仍是最重要的旁路耐药机制。

## 2. 临床验证：从早期信号到机制修正

### 2.1 Phase 1/1b：核心模型的初步支持

首次人体研究在 20–1,200 mg 范围内递增，主要纳入复发/难治血液肿瘤患者。关键观察与“脉冲式凋亡”模型一致：

| 预测 | 临床观察 | 机制含义 |
|---|---|---|
| 低 TLS 风险 | TLS 发生率 0% | 短暴露降低持续、大规模细胞杀伤风险 |
| 快速起效 | 最低 20 mg 首日即可见 ALC 下降 | 峰浓度可快速跨越凋亡阈值 |
| 短 ramp-up | 4–6 天可完成递增，无 DLT，未达 MTD | 不需 venetoclax 式长递增期的初步支持 |
| 可控骨髓抑制 | ≥3/4 级中性粒细胞减少 26.1%，恢复较快 | 较低累积暴露可能减少持续骨髓毒性 |

单药 CLL/SLL 初步 ORR 为 63.6%；BTKi 不耐受患者 ORR 80%；del(17p)/TP53 突变患者 ORR 66.7%。这些为 BCL-2 依赖肿瘤中的药效提供了信号，但高危亚组的长期获益仍不能由早期 ORR 推断。

联合治疗进一步提供协同线索：与 acalabrutinib 联用 ORR 约 96–98%，与 rituximab 联用 ORR 87%。BTKi 可能通过下调 MCL-1、增强 BCL-2 依赖；抗 CD20 抗体则提供 ADCC 与凋亡的互补作用。未见显著药物相互作用，支持联合可行性。

### 2.2 Phase 2：疗效确认与模型边界

CLL/SLL 注册性研究 APG2575CC201（n=77）报告 ORR 62.5%、中位 PFS 23.89 个月、12 个月 OS 率 78%。这些结果支持持续的 BCL-2 通路抑制活性，但亦明确了模型边界：TP53 缺失/突变合并复杂核型患者的中位 PFS 约 11.2 个月（HR 约 5.0），提示 p53 轴和基因组不稳定性会显著削弱长期获益。

AML/MDS 中，Lisaftoclax 与 HMA 的活性支持“BCL-2 抑制 + MCL-1 下调”这一联合逻辑；不过 venetoclax 暴露患者中的反应有限，不能将其视为普遍的 venetoclax 耐药解法。MRD 阴性与更深缓解相关，但其作为注册替代终点的监管确定性仍不足。

### 2.3 修正后的机制模型

| 层级 | 结论 | 临床含义 |
|---|---|---|
| 分子 | BCL-2 抑制释放 BIM，触发 BAX/BAK-MOMP | 解释 BCL-2 依赖肿瘤的快速响应 |
| PK/PD | 高 Cmax 触发、短血浆暴露限制毒性 | 支持短 ramp-up 与低 TLS 的设计逻辑 |
| 肿瘤依赖性 | BCL-2 priming 决定敏感性；CLL 通常高于 MDS 和实体瘤 | 适应症与患者筛选应以生物学依赖性为中心 |
| 负向因素 | TP53 异常、复杂核型、MCL-1 上调 | 高危分层和联合策略的重点 |
| 安全性 | BCL-xL 活性带来血小板风险，但短暴露可能缓冲 | 需以长期随访验证风险/获益 |

## 3. 与 Venetoclax 的临床定位

两药不可由跨试验数据直接判定优劣。Lisaftoclax 的潜在差异化在于短半衰期、较快剂量递增和较低 TLS 负担；venetoclax 则具有更高 BCL-2/BCL-xL 选择性、成熟的全球证据基础及已验证的多适应症组合。

因此，Lisaftoclax 可被定位为“更便捷、全身累积暴露可能更低的 BCL-2 抑制剂”，而不是已证实优于 venetoclax 的替代品。两者尚无随机、对照、头对头试验；跨试验比较受到人群、联合方案和剂量策略差异的限制。

## 4. Phase 3 推导

| 试验 | 人群/策略 | 机制依据 | 主要风险 | 预测判断 |
|---|---|---|---|---|
| GLORA（NCT06104566） | BTKi 经治 CLL/SLL | BTKi 下调 MCL-1，增强 BCL-2 依赖 | TP53/del(17p)比例、BTKi 异质性 | PFS HR 0.40–0.60；成功概率约 78% |
| GLORA-2（NCT06319456） | 初治 CLL/SLL，固定疗程 | BTKi+BCL-2i 可促进深度缓解/MRD 阴性 | 对照方案的外部可比性、长期固定疗程最优周期未知 | PFS HR 0.45–0.65；成功概率约 72% |
| GLORA-3（NCT06389292） | AML | HMA 与 BCL-2 抑制协同，可能清除白血病干细胞 | TP53 突变、早期死亡、AML 异质性 | OS HR 0.60–0.75；成功概率约 55% |
| GLORA-4（NCT06641414） | 新诊断 HR-MDS | 高 BCL-2 priming 与 HMA 协同或提高缓解率 | VERONA 阴性、OS 竞争风险、双终点多重性 | CR >30%、OS HR 0.70–0.90；成功概率约 35% |

上述概率为基于既有机制和早期数据的推演，不是统计预测或投资建议。CLL/SLL 证据链最完整；AML 的不确定性主要来自高危分子亚组；MDS 即使改善缓解率，也未必能转化为 OS 获益。

## 5. 关键未解问题与研究优先级

1. **人体肿瘤组织 PK**：需验证“短血浆半衰期、长肿瘤滞留”是否真实存在于患者体内。
2. **长期安全性**：特别是 BCL-xL 相关血小板毒性在数月到数年暴露下的表现。
3. **疗程与终点**：MRD 的监管地位、固定疗程的最优周期、MRD 指导停药均未定论。
4. **直接比较**：需要与 venetoclax 的随机头对头研究，明确真实的疗效、安全性和便利性差异。
5. **耐药与联合**：MCL-1 是共同汇聚节点；直接 MCL-1 抑制受心脏毒性限制，间接下调（如 CDK9 或 MDM2 路径）值得优先探索。
6. **适应症拓展**：SLE 等自身免疫病的研究可检验短暴露模式在长期用药场景中的安全性，但目前仍属探索阶段。

## 结论

Lisaftoclax 的核心价值在于以高 Cmax 触发凋亡、以短半衰期限制系统性暴露的药理设计。早期及 Phase 2 数据总体支持这一机制，并显示其在 CLL/SLL 联合治疗中的竞争潜力。决定其最终差异化地位的，不是单纯的早期 ORR，而是全球 Phase 3 对 PFS/OS 的验证、长期血液学安全性、对高危分子亚组的真实获益，以及与 venetoclax 的直接比较。
