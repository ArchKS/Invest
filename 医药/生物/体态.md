# 体态

## 圆肩驼背

圆肩驼背的本质是**前面的肌肉太紧、后面的肌肉太弱**:长期低头、含胸、久坐让胸肌、肩前侧变紧,而背部上中段(中下斜方肌、菱形肌)和颈深层肌肉变弱无力。所以矫正不能只靠"挺直",而要从三方面下手:**拉伸前侧 + 强化后侧 + 改善胸椎活动度**,再加上日常姿势习惯。

**一、拉伸放松前侧(紧的部分)**

- **门框扩胸拉伸**:手臂屈肘搭在门框上,身体前倾,感受胸部被拉开,每侧30秒,重复2~3次。这是最重要的一个,直接松开把肩膀往前拽的胸肌。
- **胸小肌/肩前侧拉伸**:也可以用前面提到的筋膜球压在胸口靠近肩窝的位置滚一滚。

**二、强化后侧(弱的部分)——这是矫正的核心**

- **弹力带面拉(Face Pull)**:把弹力带固定在面前高度,双手拉向脸两侧,肘部打开、肩胛向后夹。专练中下斜方肌,对圆肩特别有效。3组×15次。
- **弹力带扩胸(Band Pull-Apart)**:双手平举握住弹力带,直臂向两侧拉开夹背。简单、随时能做。3组×15~20次。
- **俯卧 YTW**:趴在地上或斜板上,手臂分别摆成 Y、T、W 三种形状抬起,挤压肩胛。激活整个上背。每个姿势×10次。
- **划船(坐姿/弹力带/哑铃)**:拉的时候想着"用背把肩胛往后挤",而不是只用手臂。3组×12次。

**三、改善胸椎活动度(让背能挺起来)**

- **靠墙天使(Wall Angels)**:背贴墙,后脑、上背、臀贴墙,手臂贴墙做上下滑动。能立刻让你感受到挺胸的发力。
- **泡沫轴胸椎伸展**:把泡沫轴横垫在上背处,身体后仰打开胸椎,反复几次。
- **猫牛式 / 四足位胸椎旋转**:活动僵硬的胸椎。

**四、顺带处理"探颈"**(圆肩驼背常伴随头前伸)

- **收下巴练习(Chin Tuck)**:像挤出双下巴一样把下巴水平后收,保持几秒。强化颈深层肌肉。

**怎么安排**:每周做3~4次,每次从拉伸开始,再做2~3个强化动作,配合靠墙天使。**最关键的其实是日常意识**——久坐时每30~40分钟起来动一下,有意识地沉肩、挺胸、收下巴,因为再好的训练也抵不过一天十几个小时的含胸。
