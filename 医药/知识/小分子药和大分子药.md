这种说法**在“代谢途径、药物相互作用和脱靶作用”方面有一定道理，但不能概括为小分子药在人体内一定更复杂。**这里的大分子药，主要以单克隆抗体这类蛋白质药物为例。

关键不在分子结构本身有多复杂，而在于药物进入人体后，**能去哪里、会变成什么、会影响哪些东西**。

**1. 小分子药通常能接触更多细胞内部的靶点。**

许多小分子可以穿过细胞膜，进入细胞内部；除了预期靶点，也可能结合结构相似的其他蛋白，产生“脱靶作用”。抗体通常难以自由进入细胞，主要作用于细胞表面或细胞外的靶点，而且结合往往更具特异性。因此，小分子的潜在作用范围常常更广，但这不是每种药都成立。[药理学综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC6923804/)

**2. 小分子被代谢后，可能产生仍有作用的新物质。**

很多小分子药会经过肝脏等组织的酶处理，形成一种或多种代谢物。这些代谢物可能失活，也可能继续发挥药效，甚至产生毒性。所以研究时，不能只看原来的药，还要看它的“后续产物”。

抗体则主要被分解成小肽和氨基酸，通常不会像小分子那样形成一串具有独立药理作用的代谢物。这是两者很重要的区别。[药物代谢与抗体分解途径](https://pmc.ncbi.nlm.nih.gov/articles/PMC6226118/)

**3. 小分子更容易与其他药物“共用通道、互相影响”。**

很多小分子依赖相同的代谢酶和转运蛋白。一种药如果抑制了另一种药的代谢，后者就可能在体内积累；如果加快其代谢，后者的药效就可能下降。人的酶活性差异，也会影响药物暴露水平。抗体通常不直接依赖这些代谢酶，因此这类相互作用相对少。[FDA 药物相互作用资料](https://www.fda.gov/drugs/drug-interactions-labeling/healthcare-professionals-fdas-examples-drugs-interact-cyp-enzymes-and-transporter-systems)

不过，**大分子药的复杂性集中在另一些地方**：人体可能产生抗药抗体，改变药效和清除速度；靶点多少会影响药物被消耗的速度；抗体还有回收机制，使剂量与体内浓度的关系不一定简单。这些都可能让它的体内行为很难预测。[抗体药代动力学综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC5613179/)

所以，更准确的表述是：**小分子药往往在“化学代谢和多种分子之间的相互作用”上更复杂；大分子药往往在“免疫反应、组织分布和靶点相关清除”上更复杂。不能由此推断大分子药一定更安全。**



| 比较     | 小分子药                               | 大分子药（以抗体为例） |
| -------- | -------------------------------------- | ---------------------- |
| 分子大小 | 通常分子量较小                         | 分子量很大             |
| 结构     | 通常是相对较小的化学化合物             | 有复杂空间结构的蛋白质 |
| 进入细胞 | 许多可以，但不是全部                   | 通常不能自由穿过细胞膜 |
| 作用位置 | 可以在细胞内，也可以在细胞外或细胞表面 | 主要在细胞外或细胞表面 |



靶点区别

|              | 细胞外/细胞表面靶点                  | 细胞内靶点                               |
| ------------ | ------------------------------------ | ---------------------------------------- |
| 所在位置     | 血液、组织液、细胞膜表面             | 细胞质、细胞核、细胞器                   |
| 例子         | 细胞因子、生长因子、膜受体、凝血因子 | 激酶、代谢酶、转录因子、细胞内信号蛋白   |
| 药物到达难度 | 较低，血液中的药物容易接触           | 较高，需要穿过细胞膜，有时还要进入细胞核 |
| 常见药物     | 抗体、融合蛋白、部分多肽药           | 小分子抑制剂、部分核酸药物               |

细胞外靶点负责“接收和传递信息”，细胞内靶点负责“处理信息并执行反应”。

| 类型         | 常见功能                                           | 例子                                    |
| ------------ | -------------------------------------------------- | --------------------------------------- |
| 细胞外靶点   | 在细胞之间传递信号，或直接影响血液、组织液中的过程 | 炎症因子、凝血因子、生长因子            |
| 细胞表面靶点 | 接收外部信号，并把信号传入细胞                     | EGFR、胰岛素受体、T细胞受体             |
| 细胞内靶点   | 参与信号传递、代谢、基因表达和细胞生存             | 激酶、代谢酶、转录因子、DNA/RNA相关蛋白 |
