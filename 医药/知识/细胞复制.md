# 表观遗传



表观遗传决定“哪些DNA可以被读取”，但标记本身不改变DNA字母顺序。

主要机制包括：

- DNA甲基化
- 组蛋白修饰
- 染色质开放或压缩
- 染色质重塑

例如，正常TET2参与调节DNA甲基化状态。TET2发生突变后，甲基化分布可能紊乱，使造血细胞的分化程序不能按时开启。


# 转录

转录因子决定“打开后抄哪一段、抄多少”。

例如 **RUNX1、GATA2** 都是重要的造血转录因子。RUNX1异常后，某些造血分化基因不能正常启动，同时干/祖细胞的自我更新可能增强。





# RNA剪接异常



一个基因刚转录出来的是**前体mRNA**，其中包含：

- 外显子：通常需要保留的部分；
- 内含子：通常需要删除的部分。

剪接体会去掉内含子，把外显子重新连接。不同拼接方法还可以让同一个基因产生不同蛋白质，称为“可变剪接”。

剪接因子突变后可能出现：

- 内含子没有被正确删除；
- 外显子被错误跳过；
- 选择了错误的剪接位点；
- 形成提前终止密码子；
- mRNA被细胞降解；
- 产生结构异常的蛋白质。

例如 **SF3B1突变**会改变剪接位点选择，影响线粒体、铁代谢和红细胞成熟，因而与环形铁粒幼红细胞密切相关。剪接体基因突变在MDS中经常彼此互斥，提示它们作用于相同的关键过程

它与转录异常的区别是：

- 转录异常：RNA“制造多少、何时制造”不正常。
- 剪接异常：RNA已经制造出来，但“后期剪辑拼装”出了问题。





## 七、为什么DNA选择甲基作为重要标记

甲基并不是像胶水一样直接挡住RNA聚合酶。它更像DNA表面一个小而稳定的识别标签。读取蛋白识别这个标签后，会招募抑制复合物并改变染色质状态。

需要注意：

- 启动子或增强子区域的CpG甲基化通常抑制转录；
- 基因内部的甲基化不一定抑制，有时反而与活跃转录相关。

### 1. 甲基如何加到DNA上

哺乳动物最常见的是胞嘧啶甲基化：

> 胞嘧啶C + 甲基（—CH₃） 
> → 5-甲基胞嘧啶（5mC）

甲基被加在胞嘧啶的第5号碳原子上，通常发生于CpG位点。甲基供体主要是S-腺苷甲硫氨酸（SAM）。

### 2. 为什么甲基化会影响读取

#### 甲基出现在DNA大沟表面

胞嘧啶第5位甲基：

- 不参与C和G之间的氢键；
- 基本不破坏正常C–G配对；
- 会突出在DNA大沟表面。

DNA仍可正常复制，但多出了能被蛋白质识别的化学标志。

#### 部分转录因子不能正常结合

一些转录因子对DNA表面的形状、电荷和疏水性很敏感。增加甲基后，蛋白质与DNA的接触面发生改变，结合能力可能下降。

并非所有转录因子都会受到抑制：有些不受影响，少数甚至偏好甲基化序列。

#### 甲基招来读取蛋白

MeCP2、MBD1、MBD2等蛋白可识别甲基化CpG，并进一步招募：

- 组蛋白去乙酰化酶；
- 组蛋白甲基转移酶；
- 转录共抑制复合物；
- 染色质重塑蛋白。

结果是DNA与组蛋白结合更紧，RNA聚合酶和转录因子更难进入。

因此过程更接近：

> DNA甲基化 
> → 读取蛋白识别 
> → 招募调控复合物 
> → 组蛋白改变、染色质压紧 
> → 转录下降。

### 3. 为什么是甲基，而不是其他基团

甲基并非唯一可能的标签，但它具有几项适合长期信息存储的性质。

#### 足够小

- 不带电；
- 体积小；
- 不明显干扰C–G碱基配对；
- 通常不会阻止DNA复制。

如果添加很大或强带电的基团，可能明显扭曲双螺旋、妨碍复制，并被当作DNA损伤。

#### 足够容易识别

甲基具有疏水性并突出到DNA大沟中。它对DNA结构影响较小，却能明显改变蛋白质识别表面。

#### 化学性质稳定

甲基与胞嘧啶形成稳定共价键，适合保存较长时间，因此能够形成细胞记忆。

#### 容易由细胞添加

SAM是细胞中普遍存在的甲基供体，DNA甲基转移酶可以高效地把甲基转移到胞嘧啶。

#### 容易在细胞分裂时复制

DNA复制后：

- 旧链保留甲基；
- 新链暂时没有甲基。

这种状态称为半甲基化DNA。UHRF1和DNMT1能识别它，并在新链对应位置补上甲基，使表观遗传信息传给子细胞。

#### 稳定但仍可清除

TET1、TET2和TET3可逐步氧化5mC：

> 5mC → 5hmC → 5fC → 5caC

随后通过DNA修复机制恢复成普通胞嘧啶。因此甲基化既稳定，又可以被专门系统调整或清除。

### 4. 其他化学标记也存在

细胞并不只使用甲基：

- DNA上还有5-羟甲基胞嘧啶、5-甲酰胞嘧啶等；
- 组蛋白上有乙酰化、甲基化、磷酸化和泛素化；
- 某些生物大量使用腺嘌呤甲基化；
- 细菌还利用DNA甲基化区分自身与外来DNA。

更准确地说：

> 甲基不是唯一标签，而是哺乳动物进化中形成的一种小、稳定、可读取、可复制、又可清除的DNA信息标签。

## 八、谁在控制表观遗传

控制哪些基因开启或关闭的主要因素包括：

- **转录因子**：识别特定DNA序列，直接启动或抑制基因。少数“主调控因子”可以决定细胞身份。
- **细胞外信号**：激素、生长因子、神经信号以及邻近细胞发出的信号，会改变转录因子的活动。
- **染色质调控蛋白**：通过DNA甲基化、组蛋白修饰和核小体重塑，让某段DNA更容易或更难被读取。
- **非编码RNA**：帮助关闭、激活或精细调节特定基因。
- **细胞代谢与环境**：营养、压力、炎症、毒物和衰老等会影响表观遗传酶的活动。
- **细胞自身的反馈回路**：某些基因一旦开启，会促进自己继续开启，同时压制其他细胞类型的程序，因此细胞身份能够在分裂后长期保持。

那么“谁控制这些控制者”？答案仍然不是另一个单独的控制者，而是：

**DNA中编码的调控规则 + 发育过程中的位置信号 + 细胞间通信 + 环境影响 + 自我维持的反馈网络。**

例如，一个胚胎细胞接收到“成为神经细胞”的信号后，会激活神经相关的主转录因子；这些因子招募染色质调控蛋白，打开神经基因、关闭皮肤或肌肉基因，最终形成稳定的神经细胞状态。

所以更准确地说，**表观遗传不是DNA之外的一位“指挥官”，而是细胞利用DNA所编码的调控系统，根据发育历史和环境信息形成并保存的一种状态记忆。**



### 从受精卵到人

人体分化可以理解为：**同一本DNA说明书，在不同时间、位置接收不同信号，于是逐步锁定不同的章节。**它不是一次决定完成，而是不断“分叉选择”的过程。

```
受精卵
  ↓
全能性细胞
  ↓
囊胚
  ├─ 滋养层 → 胎盘等支持组织
  └─ 内细胞团 → 胚胎本身
         ↓
      三个胚层
      ├─ 外胚层 → 神经、皮肤
      ├─ 中胚层 → 肌肉、骨骼、血液、心脏
      └─ 内胚层 → 消化道、肝、胰、肺等
             ↓
        各组织的祖细胞
             ↓
        成熟的专门细胞
```

### 1. 受精：恢复完整的发育程序

精子和卵子结合形成受精卵。卵子中预先储存的RNA、蛋白质和细胞器首先控制早期发育，随后胚胎自己的基因组逐渐启动。

受精卵具有“全能性”：理论上既能形成胚胎身体，也能形成胎盘等胚外组织。

### 2. 卵裂：细胞增多，但总体积基本不变

受精卵连续分裂成2、4、8、16个细胞，形成桑椹胚。这时主要是在把一个大细胞分割成许多小细胞。

早期细胞看起来相似，但已经开始出现细微差别，例如：

- 位于胚胎内部还是外部；
- 接触多少邻近细胞；
- 承受怎样的压力；
- 获得多少特定信号分子。

这些微小差异会被基因调控网络放大。

### 3. 囊胚：第一次明显分工

大约受精后数日，胚胎形成中空的囊胚，并出现两类细胞：

- **外层滋养层细胞**：主要形成胎盘等支持结构；
- **内细胞团**：形成胚胎本身，其细胞具有多能性。

这次选择与细胞的位置、极性、相互接触和 Hippo 等信号通路有关。也就是说，细胞会根据“我在里面还是外面”开启不同基因。

### 4. 原肠胚形成：建立身体的基本坐标

胚胎植入子宫后，一部分细胞迁移、折叠并重新排列，形成三个胚层：

- **外胚层**：形成神经系统、表皮等；
- **中胚层**：形成肌肉、骨骼、血液、心脏、肾脏等；
- **内胚层**：形成消化道和呼吸道内壁，以及肝、胰等器官。

与此同时，胚胎建立前后、背腹和左右轴。细胞因此知道自己处在身体的什么位置。

### 5. 位置信号告诉细胞“你在哪里”

胚胎中的一些组织会释放信号分子，例如 Wnt、BMP、FGF、Nodal 和 Hedgehog。它们在空间中形成浓度梯度，称为**形态发生素梯度**。

同一种细胞接收到不同浓度或持续时间的信号，可能产生不同命运。例如：

```
信号高浓度 → 开启A组基因
信号中浓度 → 开启B组基因
信号低浓度 → 开启C组基因
```

细胞不仅读取一种信号，而是综合判断多种信号的组合、顺序和持续时间。

### 6. 转录因子执行身份选择

信号进入细胞后，会启动特定的转录因子。它们像“章节选择器”，决定哪些基因可以被读取。

例如，某组转录因子可能推动细胞成为神经前体；另一组则推动它成为肌肉或血液前体。这些转录因子还会形成反馈回路：

- 激活自己的身份程序；
- 抑制其他细胞身份；
- 招募染色质调控蛋白。

因此，最初很小的差异会逐渐变成稳定的细胞命运差异。

### 7. 表观遗传把选择逐渐“锁定”

分化过程中，DNA甲基化、组蛋白修饰和染色质重塑会改变DNA的可读取性。

例如，神经细胞会：

- 打开神经功能相关基因；
- 关闭肌肉、肝脏等基因；
- 在细胞分裂时尽量复制这种开关状态。

不过这种锁定通常不是绝对不可逆。实验中加入特定转录因子，可以把成熟细胞重新变成诱导多能干细胞，说明细胞身份主要是稳定的调控状态，而不是DNA序列发生了根本改变。

### 8. 器官形成与终末分化

三个胚层继续分成越来越专门的祖细胞：

```
中胚层
  → 造血干细胞
     → 红细胞祖细胞
        → 成熟红细胞
外胚层
  → 神经干细胞
     → 神经祖细胞
        → 不同类型的神经元或胶质细胞
```

每次分化都缩小了未来选择范围。与此同时，细胞迁移、增殖、改变形状或程序性死亡，最终共同塑造器官。

所以，人体不是由某个“总设计者细胞”逐一安排出来的，而是通过一个自组织过程形成：

**初始的不对称 → 位置信号 → 转录因子网络 → 表观遗传记忆 → 细胞相互作用与组织塑形。**

DNA提供规则，细胞的位置和历史决定采用哪套规则，而细胞之间不断互相发送信号，使整个胚胎协调发育。





### 1. 写入器

#### DNA甲基化写入器

- **DNMT3A、DNMT3B**：建立新的甲基化标记；
- **DNMT1**：在DNA复制后维持和复制既有甲基化图谱。

可理解为：

- DNMT3A/3B负责首次做标记；
- DNMT1负责复印原有标记。

#### 组蛋白标记写入器

- HAT：添加组蛋白乙酰基，通常使染色质更开放；
- EZH2/PRC2：添加H3K27me3等抑制性组蛋白甲基化标记；
- SETD2等：在其他组蛋白位置添加甲基。

### 2. 擦除器

#### DNA去甲基化系统

- TET1、TET2、TET3：逐步氧化5mC；
- TDG和碱基切除修复系统：最终恢复普通胞嘧啶。

TET蛋白不是简单把甲基直接摘掉，而是先将其逐步氧化，再由DNA修复系统完成清除。

#### 组蛋白标记擦除器

- HDAC：去除组蛋白乙酰基，通常使染色质更紧；
- KDM/LSD1：去除特定组蛋白甲基化标记。

### 3. 读取器

标记需要被蛋白理解：

- MeCP2、MBD1、MBD2读取甲基化CpG；
- BRD4等溴结构域蛋白读取组蛋白乙酰化；
- 含特定染色质结构域的蛋白读取组蛋白甲基化标记。

读取器结合后会招募转录激活或抑制复合物。标记本身更像信号，真正执行开放或关闭的是读取器及其伙伴。

### 4. 染色质重塑器

染色质重塑复合物使用ATP提供的能量：

- 移动核小体；
- 移除或更换核小体；
- 暴露启动子和增强子；
- 或把DNA区域重新遮挡。

主要复合物包括：

- SWI/SNF；
- CHD；
- ISWI；
- INO80。

它们像整理书架的人，决定某本书摆在外面还是锁进柜子。

### 5. 谁告诉这些酶去哪里工作

#### 转录因子

造血系统中的RUNX1、GATA1、GATA2、PU.1、CEBPA等转录因子，可识别特定DNA序列，再招募甲基化酶、组蛋白修饰酶或染色质重塑复合物。

#### 非编码RNA

部分长链非编码RNA可像导航RNA一样，把表观遗传复合物带到特定染色体区域。

#### DNA序列和染色体三维结构

- CpG岛本身提供定位信息；
- CTCF和黏连蛋白复合物控制DNA三维折叠；
- 增强子与启动子的空间接触决定调控蛋白能否相遇。

### 6. 细胞外环境与代谢也在控制表观遗传

炎症因子、激素和生长因子通过NF-κB、JAK–STAT、MAPK和TGF-β–SMAD等通路改变转录因子活性，继而影响表观遗传复合物。

表观遗传酶还依赖代谢原料：

- SAM：DNA和组蛋白甲基化的甲基供体；
- 乙酰辅酶A：组蛋白乙酰化原料；
- α-酮戊二酸：TET和部分组蛋白去甲基化酶的辅助因子；
- NAD⁺：影响Sirtuin类去乙酰化酶；
- 氧、铁离子和ROS也会影响相关酶。

### 7. MDS中哪些控制环节失常

- **DNMT3A突变**：甲基化标记写入异常；
- **TET2突变**：5mC氧化和去甲基化过程异常；
- **IDH1/IDH2突变**：产生2-HG，抑制TET2等α-酮戊二酸依赖酶；
- **EZH2突变**：抑制性组蛋白标记异常；
- **ASXL1突变**：扰乱多种染色质和组蛋白调控复合物；
- **STAG2异常**：改变DNA三维折叠，间接改变表观遗传和转录；
- **RUNX1异常**：不能把相应调控复合物正确带到造血基因附近。

因此，MDS中的表观遗传异常可能来自三层问题：

1. 写入器或擦除器本身发生突变；
2. 转录因子把它们带到错误位置；
3. 炎症和代谢环境改变它们的活性。

最简洁的总结是：

> DNA序列提供地址，转录因子负责导航，写入器和擦除器改变标记，读取器解释标记，染色质重塑器执行开放或关闭；代谢和细胞信号控制整套系统的工作状态。
