不是临床试验史，而是一个个真实试验复盘“背景—设计—结果—成败原因—启示”，最好覆盖多个年份。

》你要的这种内容确实存在，但主要以系列课程和年度报告发布，并没有全部结集成纸质书。

最匹配的是“肿瘤十大‘未’成功临床试验多领域研讨”系列。《2023年度经典临床试验多学科案例解析》本身就是从这个系列整理出版的。

目前有完整的[历年专题总入口](https://www-search.liangyihui.net/feature/4709/0)：

- 2022年度：10个案例，包括LEAP-002、CheckMate 914、PALOMA-2、PARP抑制剂后线撤退、TIGIT失败、奥拉单抗撤市等。
- 2023年度：10个案例，即已经出版成书的内容，包括KEYNOTE-789、CD47治疗AML、Kymriah二线失败、TROP2 ADC、普克鲁胺、LEAP系列等。
- 2024年度：10个案例，包括四代EGFR-TKI、SHP2抑制剂、AKT抑制剂、TROP2 ADC、Xevinapant、mRNA个体化肿瘤疫苗等。
- 2025年度：第四季，目前已陆续更新贝玛妥珠单抗、IGNYTE等案例。

每一期基本都按照你想要的结构分析：

**疾病背景 → 作用机制 → 早期数据 → 关键试验设计 → 结果 → 统计和监管问题 → 失败原因 → 后续开发启示。**

这些内容多数标注为免费，而且比书更有价值，因为包括专家讨论、直播回放和问题解答。截至目前，我只查到2023年度正式结集出版；2022、2024和2025年度尚未看到对应的纸质书。

另一个很接近的资源是医药魔方的《2024全球临床试验失败案例研究报告》，共119页，覆盖肿瘤、神经精神等领域，分析MDMA治疗PTSD、BLU-945四代EGFR-TKI、IMbrave050、SHP2抑制剂等案例。[报告介绍与下载入口](https://bydrug.pharmcube.com/news/detail/9988d28f5a96b3616636a42ca9548862)

如果主要为了研究亚盛医药，我建议先看这四组：

1. **2023年CD47治疗AML失败**：学习血液瘤早期数据为何不能保证Ⅲ期成功。
2. **2024年四代EGFR-TKI失败**：理解激酶耐药、突变异质性和临床人群选择，对奥雷巴替尼最有借鉴意义。
3. **2024年Xevinapant失败**：这是凋亡通路药物，和亚盛的BCL-2、MDM2-p53研发思路最接近。
4. **2022年PARP抑制剂后线失利及撤回**：理解高ORR、加速批准与最终OS风险之间的冲突。

所以不必继续寻找多本纸质书：**2022—2025年度专题档案＋2023年度纸质书＋2024医药魔方报告**，基本就是目前中文世界最接近“历年临床失败案例库”的组合。
